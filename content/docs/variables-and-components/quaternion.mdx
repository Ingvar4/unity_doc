Но вы будете часто использовать его для установки и настройки вращения объектов через Quaternion `GameObject.transform.rotation`, который является частью
каждого GameObject. Кватернионы определяют вращения
таким образом, что позволяет избежать *gimbal lock*. Gimbal lock возникает, когда одна ось вращения совпадает с другой, что ограничивает возможности вращения и является проблемой
стандартных вращений по осям x, y, z (или вращений по Эйлеру). В
большинстве случаев вы будете определять кватернион, передавая
вращения по Эйлеру и позволяя Unity преобразовывать их в эквивалентный
кватернион:

```c#
Quaternion lookUp45Deg = Quaternion.Euler( -45f, 0f, 0f );
```

В таких случаях три числа с плавающей запятой, передаваемые в
`Quaternion.Euler()`, представляют собой количество градусов
поворота вокруг осей x, y и z (окрашенных в Unity соответственно в
красный, зеленый и синий цвета). GameObjects, включая главную камеру в
сцене, изначально ориентированы так, что смотрят вниз по положительной
оси z. Вращение в приведенном выше коде повернет камеру на –45
градусов вокруг красной оси x, в результате чего она будет смотреть вверх
под углом 45° относительно положительной оси z. Если последнее
предложение показалось вам непонятным, не беспокойтесь об этом
слишком сильно прямо сейчас. Позже вы можете попробовать зайти в Unity
и изменить значения поворота по осям x, y и z в инспекторе Transform для
GameObject и посмотреть, как это изменит ориентацию объекта.

**Переменные экземпляра и функции кватернионов**  

Вы также можете использовать переменную экземпляра `eulerAngles`,
чтобы заставить кватернион возвращать вам информацию о своем
вращении в углах Эйлера в виде Vector3:

```c#
print( lookUp45Deg.eulerAngles ); // ( -45, 0, 0 ), the Euler rotation as a Vector3
```

### Предупреждение [!toc]
**НЕ ОБРАЩАЙТЕСЬ НАПРЯМУЮ К ОСЯМ X, Y ИЛИ Z ВЕКТОРА QUATERNION**   
Значения `x`, `y` и `z` кватерниона на самом деле являются мнимыми числами (т. е. кратными квадратного корня из −1). Это дает ряд удивительных преимуществ, но означает, что нельзя писать что-то вроде `transform.rotation.x` и ожидать от этого каких-либо осмысленных данных.  

Если вы хотите получить углы поворота кватерниона
вокруг оси `x`, вам следует вместо этого использовать
`transform.rotation.eulerAngles.x`. Свойство
`eulerAngles` любого кватерниона
преобразует внутреннее представление кватерниона к
углам Эйлера, которые легче понять человеку. `eulerAngles`
— это Vector3, который можно как считывать, так и
устанавливать (хотя его нужно задавать как целый Vector3;
значения `x`, `y` и `z` нельзя задавать по отдельности).
Также важно отметить, что значения, которые вы получаете для
каждого измерения `eulerAngles`, находятся в диапазоне от
`0f` (включительно) до `360f` (исключительно). Если вы
привыкли рассматривать поворот как число от −180 до 180, вам,
возможно, захочется преобразовать это число. В данном
примере преобразование будет следующим:  

```c#
float rotX = transform.eulerAngles.x; // rotX = 325

if (rotX > 180) {
    rotX = rotX - 360f; // 325 - 360 = -35
}
print( rotX ); // -35
```
