<Callout>
## Camelcase [!toc]
CamelCase — это распространенный способ написания имен
переменных в программировании. Он позволяет программисту или
тому, кто читает его код, легко воспринимать длинные имена
переменных. Вот несколько примеров:
- `aVeryLongNameThatIsEasierToReadBecauseOfCamelCase`
- `variableNamesStartWithALowerCaseLetter`
- `ClassNamesStartWithACapitalLetter`  

Ключевая особенность camelCase заключается в том, что он позволяет
объединять несколько слов
объединять в одно слово с заглавной буквой в середине каждого
исходного слова. Он назван *camelCase*, потому что немного
напоминает горбы на спине верблюда.
</Callout>

2. Имена переменных должны начинаться с строчной буквы (например,
`someVariableName`).
3. Имена функций должны начинаться с заглавной буквы (например,
`Start()`, `FixedUpdate()`).
4. Имена классов должны начинаться с заглавной буквы (например, `GameObject`, `ScopeExample`).
5. Имена частных переменных могут начинаться с подчеркивания (например, `_hiddenVariable`).
6. Имена статических переменных могут быть написаны заглавными
буквами с использованием snake_case (например, `NUM_INSTANCES`).
Как видно, snake_case объединяет несколько слов с помощью
подчеркивания между ними.
