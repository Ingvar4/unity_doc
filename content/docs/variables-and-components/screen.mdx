---
title: Screen - информация об экране
description: Screen - это еще одна библиотека, подобная Mathf, которая может предоставить вам информацию о конкретном экране компьютера, который использует ваша игра Unity.
---

Это работает независимо от устройства,
поэтому Screen предоставит вам точную информацию, независимо от того,
используете ли вы ПК или компьютер macOS, устройство iOS или
планшет Android:

```c#
print( Screen.width ); // Prints the width of the screen in pixels
print( Screen.height ); // Prints the height of the screen in pixels
```
