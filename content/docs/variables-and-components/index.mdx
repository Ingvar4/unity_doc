## Введение в переменные

Переменная - это просто имя, которое можно определить для хранения
определенного значения. Это понятие напрямую связано с изучением
алгебры. Например, в алгебре вам может быть дано следующее
определение:  

**x = 5** 

Это определяет переменную `x` как равную значению `5`. Другими словами,
оно присваивает значение `5` имени `x`. Затем, если позже вы встретите
определение:  

**y = x + 2**  

Теперь вы знаете, что значение переменной `y` равно `7` (поскольку `x =
5`, а `5 + 2 = 7`). `x` и `y` называются переменными, потому что их значение
можно переопределить в любой момент, и порядок, в котором эти
определения встречаются, имеет значение. Взгляните на эти определения.
В следующих строках после двух косых черт ( // вот так ) добавлены
комментарии, чтобы помочь объяснить, что делает каждое выражение.  

```js
x = 10 // x is now equal to the value 10  
y = x – 4 // y is now 6 because 10-4 = 6  
x = 12 // x is now equal to the value 12, but y is still 6  
z = x + 3 // z is now 15 because 12+3 = 15  
```

После этой последовательности определений значения, присвоенные `x`, `y`
и `z`, равны `12`, `6` и `15` соответственно. Как видите, хотя значение `x`
изменилось, это не повлияло на `y`, поскольку `y` определено как значение
`6` до того, как `x` было присвоено новое значение `12`, и `y` не изменяется
задним числом. C# работает точно так же.  

## Статически типизированные переменные в C#

Вместо того чтобы иметь возможность присваивать любое значение любой
переменной, переменные C# являются статически типизированными, что
означает, что они могут принимать только определенный тип значения , и
этот тип должен быть объявлен до того, как переменная сможет быть
использована. Это необходимо, поскольку компьютеру нужно знать,
сколько места в памяти следует выделить для каждой переменной. Большое
изображение может занимать много мегабайт или даже гигабайт места,
тогда как значение типа Boolean (которое может принимать только 1 или 0)
на самом деле требует всего одного бита. Даже один мегабайт
эквивалентен 8 388 608 битам! Одно из главных преимуществ статической
типизации заключается в том, что она позволяет компилятору
обнаруживать многие виды ошибок на этапе компиляции (т. е. когда
компьютер преобразует код C# в машинный язык, который может
выполняться на компьютере с архитектурой x86), а не во время
выполнения (т. е. когда программа фактически работает).  

>Альтернативой статической типизации является динамическая типизация, при которой
компьютер пытается определить тип каждой переменной во время выполнения программы.
Такие языки, как Python и JavaScript, используют динамическую типизацию переменных. C#
может имитировать это с помощью ключевого слова `var`, но я сам почти никогда не
использую его, поскольку статическая типизация дает так много преимуществ.

### Объявление и определение переменных в C#

В C# переменная должна быть как объявлена, так и определена, чтобы
иметь применимое значение.  

*Объявление* переменной создает её, присваивает ей имя и тип, а также
выделяет для неё место в памяти. Однако это не присваивает переменной
значение.

```c#
bool bravo;
int india;
float foxtrot;
char charlie;
```

*Определение* переменной присваивает ей значение. Вот несколько
примеров использования этих объявленных переменных:

```c#
bravo = true;
india = 8;
foxtrot = 3.14f; // The f makes this numeric literal a float
charlie = 'c';
```

Всякий раз, когда вы записываете в коде конкретное значение (например,
`true`, `8` или `'c'`), это конкретное значение называется *литералом*. В
приведенном выше фрагменте кода `true` - это литерал типа `bool`, `8` - литерал типа `int`, `3.14f` - литерал типа `float`, а `'c'` -
литерал типа `char`. По умолчанию Visual Studio отображает числовые
литералы черным цветом, а текстовые - ярко-красным (а true
окрашивается в синий цвет по эзотерическим причинам). Для каждого типа
переменной также существуют определенные правила представления
литералов. Более подробную информацию об этом см. в разделах,
посвященных типам переменных.

### Объявление перед определением

Прежде чем определить переменную, необходимо сначала объявить ее, хотя
часто это делается в одной строке:

```c#
string sierra = "Mountain";
```

Как правило, Unity выдаст предупреждение и сгенерирует ошибку
компиляции, если вы попытаетесь получить доступ (т. е. прочитать) к
переменной, которая была объявлена, но еще не определена, или если вы
попытаетесь определить переменную, которая никогда не была объявлена.
Большинство ошибок компиляции отображаются в Visual Studio красной
волнистой подчеркиванием, указывающим точное местоположение
ошибки.
