Первый скрипт, который нужно добавить, предназначен для Slingshot: он заставит его реагировать на
ввод мыши, создавать экземпляр Projectile и запускать этот экземпляр. Вы будете писать этот
скрипт итеративно, добавляя понемногу код, тестируя его, а затем добавляя еще немного. Когда
вы начнете создавать собственные скрипты, это отличный подход: реализуйте что-то небольшое
и простое в кодировании, протестируйте, реализуйте еще одну мелочь, повторите.

### Создание класса Slingshot [!toc]

Выполните следующие шаги, чтобы создать класс Slingshot:
1. Создайте новый скрипт на C# и назовите его Slingshot (*Assets > Create > C# Script*).
    - a. Прикрепите скрипт *Slingshot* к GameObject Slingshot в иерархии.
    - b. Откройте скрипт C# «Slingshot» в Visual Studio и введите код из листинга

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class Slingshot : MonoBehaviour {

    void OnMouseEnter() {
        print( "Slingshot:OnMouseEnter()" );
    }

    void OnMouseExit() {
        print( "Slingshot:OnMouseExit()" );
    }

    // void Start() {…} // Please delete the unused Start() and Update() methods
    // void Update() {…}
}
```

2. Нажмите «Play» и наведите курсор мыши на Slingshot. Когда вы войдете в сферу коллайдера
Slingshot, в панели консоли появится сообщение `Slingshot:OnMouseEnter()`. При выходе
курсора мыши за пределы сферы коллайдера Slingshot появится сообщение
`Slingshot:OnMouseExit()`. Функции `OnMouseEnter()` и `OnMouseExit()` в
этом скрипте будут работать на любом GameObject с коллайдером или триггером, к которому
прикреплен данный скрипт.
3. Сохраните сцену.  

Это лишь первый шаг в написании скрипта для запуска снарядов. Важно начинать с малого и
постепенно развивать свои навыки!

### Отображение активности рогатки [!toc]

Теперь мы добавим подсветку, чтобы показать игроку, что рогатка активна:  

1. Выберите LaunchPoint в иерархии.
    - a. Добавьте компонент Halo к LaunchPoint (Component > Effects > Halo), что создаст
эффект светящейся сферы в точке запуска.
    - b. Установите размер ореола равным 1.
    - c. Установите для ореола светло-серый цвет, чтобы он был хорошо виден (мои настройки: [
r:191, g:191, b:191, a:255 ]).
2. Теперь добавьте код из листинга в скрипт Slingshot на C#. Как видите, сейчас также
подходящий момент, чтобы закомментировать операторы `print()` из предыдущего теста.  

**Листинг Slingshot.cs**

```c#
public class Slingshot : MonoBehaviour {
    public GameObject launchPoint;

    void Awake() {
        Transform launchPointTrans = transform.Find("LaunchPoint"); // a
        launchPoint = launchPointTrans.gameObject;
        launchPoint.SetActive( false ); // b
    }

    void OnMouseEnter() {
        //print("Slingshot:OnMouseEnter()");
        launchPoint.SetActive( true ); // b
    }

    void OnMouseExit() {
        //print("Slingshot:OnMouseExit()");
        launchPoint.SetActive( false ); // b
    }
}
```

    - a. `transform.Find("LaunchPoint")` ищет дочерний объект Slingshot с именем
LaunchPoint и возвращает его Transform. Вы должны убедиться, что «LaunchPoint» назван
правильно, иначе эта строка не сработает!  

        Следующая строка получает GameObject, связанный с этим Transform, и присваивает его
полю launchPoint объекта GameObject.
    - b. Метод `SetActive()` для GameObjects, таких как launchPoint, сообщает игре,
следует ли их игнорировать. Подробнее об этом вскоре.  

3. Сохраните скрипт Slingshot, вернитесь в Unity и нажмите Play.  

Вы увидите, что при входе и выходе курсора мыши из Sphere Collider Trigger рогатки ореол
включается и выключается, указывая на диапазон, в котором игрок может взаимодействовать с
рогаткой.  

Как упоминалось в `// b`, метод `SetActive()` для переменных GameObject, таких как
launchPoint, сообщает Unity, следует ли их игнорировать. Если для GameObject установлено
значение `active = false`, он не будет отображаться на экране и не будет получать вызовы
функций, таких как `Update()` или `OnCollisionEnter()`. Это не уничтожает GameObject, а
просто исключает его из активной части игры. В инспекторе GameObject флажок в верхней части
инспектора, расположенный слева от названия GameObject, указывает, активен ли GameObject

<img src="/unity_doc/images/ex70.jpeg" alt="1" style={{  height: 'auto' }} />

Флажок активности GameObject (красный) и флажок включения компонента
(синий)  

У компонентов есть аналогичный флажок. Он определяет, включен ли отдельный компонент.
Для большинства компонентов (например, Renderer и Colliders) это также можно
настроить в коде (например, Renderer.enabled = false), но по какой-то причине Halo не
является доступным компонентом в Unity, а это означает, что мы не можем легко повлиять на
компонент Halo из C#-кода. Время от времени вы будете сталкиваться с подобными
несоответствиями, и вам нужно будет найти обходной путь. В данном случае мы не можем
отключить Halo, поэтому вместо этого давайте деактивируем GameObject, который его
содержит.  

>Это почти наверняка связано с тем, что Halo - очень старый компонент в Unity, который не обновлялся много лет. Я использую его здесь, чтобы показать, что иногда вы будете сталкиваться с вещами, которые нарушают общепринятые правила в Unity, и вам просто нужно с этим смириться.

4. Сохраните сцену.
