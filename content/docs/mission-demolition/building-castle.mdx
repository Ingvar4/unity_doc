На рисунке (немного позже в этой главе) показано, как будет выглядеть готовый замок.

1. Настройте панель «Сцена» так, чтобы вы смотрели на сцену сзади в изометрическом виде.
(Фактически это то же самое, что и 2D-вид, но я хотел показать вам другой способ
перехода к нему.)
    - a. Сначала убедитесь, что сцена не находится в 2D-просмотре, нажимая кнопку 2D на
панели «Сцена», пока она не перестанет быть выделенной.
    - b. Щелкните по конусу на инструменте осей напротив оси z.
    - c. Если рядом со словом «Back» под инструментом «Оси» видна стрелка из трех линий
(подобно
такой в виде `<-`, которую можно увидеть рядом со словом «Persp» на рисунке),
щелкните эту стрелку, и она превратится в три параллельные линии (как показано на
рисунке), что означает переход от перспективного вида к изометрическому (т. е.
ортогональному).

<img src="/unity_doc/images/ex74.jpeg" alt="1" style={{  height: 'auto' }} />

Выбор вида «Сзади» (Примечание: это тот же вид, который вы видите, если
нажмете кнопку «2D»)  

2. Сейчас также самое время убрать вид «Skybox» на панели «Сцена» (если он там еще есть;
этот параметр сохраняется из одного проекта в другой). Для этого щелкните всплывающее
меню «Эффекты» в верхней части панели «Сцена» (показано под курсором мыши в правой
части рис) и убедитесь, что либо кнопка «Эффекты» не выделена, либо опция
«Скайбокс» не отмечена (если кнопка «Эффекты» выделена).
3. Дважды щелкните MainCamera в иерархии, чтобы увеличить панель «Сцена» до удобного
для просмотра размера, с которого можно будет строить замок.  

### Создание стен и плит [!toc]

Начните с создания префабов GameObject для элементов замка:  

1. Создайте дубликат материала Mat_Ground в панели Project и назовите его *Mat_Stone*.

    - a. Выберите *Mat_Ground* в панели Project.
    - b. Выберите *Edit > Duplicate* в панели меню Unity.
    - c. Измените название с *Mat_Ground 1* на *Mat_Stone*.
    - d. Выберите *Mat_Stone* и установите цвет альбедо на 50% (RGBA: [128, 128, 128, 255]).  

2. Создайте новый куб (GameObject > 3D Object > Cube) и переименуйте его в Wall.
    - a. Установите трансформацию Wall на P:[ 0, 0, 0 ] R:[ 0, 0, 0 ] S:[ 1, 4, 4 ].
    - b. Добавьте компонент Rigidbody к Wall (*Component > Physics > Rigidbody*).
    - c. В компоненте Rigidbody щелкните треугольник раскрытия рядом с Constraints, чтобы
увидеть доступные там параметры. Ограничение любого параметра Rigidbody
предотвращает его изменение.
    - d. Ограничьте положение по оси Z стены, установив для параметра Rigidbody Freeze Position Z
значение
`true`. Это не позволит Wall выйти за пределы плоскости Z=0, в которой происходит действие
игры.
    - e. Установите для параметров Freeze Rotation X и Y в true. Это по-прежнему позволяет
Rigidbody вращаться вокруг оси Z, что является единственным вращением, которое
хорошо видно с ортогональной
_MainCamera.
    - f. Установите для параметра Rigidbody Mass значение 4.
    - g. Перетащите материал Mat_Stone на объект Wall, чтобы окрасить его в серый цвет.  

3. Создайте новый скрипт в папке «Scripts» с именем *RigidbodySleep* и введите код из листинга:  

Листинг кода RigidbodySleep.cs  

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

[RequireComponent( typeof(Rigidbody) )] // a
public class RigidbodySleep : MonoBehaviour {
    private int sleepCountdown = 4; // b
    private Rigidbody rigid;

    void Awake() {
        rigid = GetComponent<Rigidbody>(); // c
    }

    void FixedUpdate() {
        if ( sleepCountdown > 0 ) { // d
            rigid.Sleep();
            sleepCountdown--;
        }
    }

    // void Start() {…} // Please delete the unused Start() and Update() methods
    // void Update() {…}
}
```

- a. Этот атрибут компилятора RequireComponent гарантирует, что любой GameObject, к
которому прикреплен этот скрипт, имеет компонент Rigidbody. Я часто использую его,
чтобы гарантировать, что любой вызов `GetComponent<Rigidbody>()` не вернет null
из-за отсутствия компонента.Если быть более точным, атрибут компилятора RequireComponent выполняет три функции: 

        - Когда к GameObject прикреплен скрипт с RequireComponent, к нему также
прикрепляется компонент требуемого типа.
        - Если вы попытаетесь удалить требуемый компонент из GameObject, Unity не позволит
вам это сделать.
        - Если атрибут компилятора RequireComponent добавляется в скрипт после того, как
скрипт был прикреплен к GameObject, вы получите предупреждение о том, что вам
необходимо добавить требуемый компонент вручную.
- b. Это целое число будет отсчитывать количество последовательных вызовов
`FixedUpdates()`, на время которых мы указали Rigidbody перейти в режим ожидания.
- c. Поскольку вызов `GetComponent<>()` является ресурсоемким (т. е. неэффективным), мы
не хотим выполнять его в каждом FixedUpdate. Вместо этого мы вызываем его один раз в
`Awake()` для каждой стены, а затем кэшируем результат.
- d. В каждом FixedUpdate вызывается `rigid.Sleep()`, а затем sleepCountdown
уменьшается на единицу. Когда это произойдет четыре раза (т. е. sleepCountdown раз),
процесс останавливается.  

Указание Rigidbody стены перейти в режим сна заставляет его изначально предполагать, что он не
должен двигаться, что поможет замкам изначально оставаться стабильными (в некоторых версиях
Unity были проблемы с тем, что замки рушились - или взрывались! - до того, как снаряд
попадал в них). Однако одного раза для этого недостаточно.  

Согласно Unity, при вызове `rigid.Sleep()` Rigidbody переходит в режим сна «как минимум
на один кадр». Однако, если что-то изменится вокруг Rigidbody, он снова проснется. Этого не
происходит с замком, просто стоящим на месте, но позже в этой главе, когда вы начнете
добавлять замки в сцену программно, одного вызова RigidbodySleep будет недостаточно, поэтому
этот код выполнит его четыре раза, что, судя по моим тестам, кажется достаточным.  

4. Сохраните скрипт RigidbodySleep и вернитесь в Unity.
5. Прикрепите скрипт RigidbodySleep к Wall.
6. Перетащите Wall в панель Project, чтобы сделать его префабом (обязательно поместите
его в папку _Prefabs), а после этого удалите экземпляр Wall из панели Hierarchy.
7. Выберите префаб Wall в папке _Prefabs панели Project и скопируйте его.  

    - a. Переименуйте «Wall 1» в «Slab».
    - b. Дважды щелкните «Slab» на панели «Project». Откроется панель «Scene» в режиме
«Prefab» (эта функция была добавлена в Unity версии 2018.3). Режим «Prefab» позволяет
редактировать префаб отдельно от всего остального и выполнять некоторые действия,
которые ранее можно было выполнять только с префабом в сцене.
    - c. Выберите Slab в иерархии режима Prefab Mode и установите масштаб его трансформации на
S: [4, 0.5, 4].
    - d. Чтобы вернуться из режима Prefab Mode в обычный вид сцены, нажмите на значок < в
левом верхнем углу панели иерархии или на слово Scenes рядом с логотипом Unity,
расположенным в левом верхнем углу окна сцены.
