title: Fixing Rigidbody’s Insomnia
description: Как только что упоминалось, когда снаряд запутывается среди стен и плит, он иногда никогда не переходит в режим сна, а это означает, что нам придется ждать очень долго, прежде чем мы сможем сделать следующий выстрел.
---

Нам нужно лучше контролировать, когда снаряд
переходит в режим сна, поэтому мы напишем собственный метод для отслеживания
расстояния, на которое снаряд переместился при каждом FixedUpdate, и если снаряд
переместился менее чем на 0,01 м в течение десяти кадров подряд, мы будем считать, что он
находится в режиме сна.  

1. Добавьте новый скрипт Projectile к префабу Projectile:
    - a. Выберите префаб *Projectile* на панели Project.
    - b. Нажмите кнопку *Add Component* внизу инспектора Projectile.
    - c. Введите *Projectile* в поле поиска Add Component и нажмите New script.
    - d. Нажмите *Create and Add*.  

Одна из проблем при добавлении новых скриптов таким способом заключается в том, что они помещаются в папку Assets, а не в её подпапку __Scripts.  

2. Переместите скрипт *Projectile* в папку *__Scripts*.
3. Откройте скрипт *Projectile* в Visual Studio и введите код:  

Листинг кода Projectile.cs

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

[RequireComponent( typeof(Rigidbody) )] // a
public class Projectile : MonoBehaviour {
    const int LOOKBACK_COUNT = 10; // b

    [SerializeField]
    private bool _awake = true; // c
    public bool awake {
        get { return _awake; }
        private set { _awake = value; }
    }

    private Vector3 prevPos;
    // This private List stores the history of Projectile’s move distance
    private List<float> deltas = new List<float>();
    private Rigidbody rigid;

    void Start() {
        rigid = GetComponent<Rigidbody>();
        awake = true;
        prevPos = new Vector3(1000,1000,0); // d
        deltas.Add( 1000 );
    }

    void FixedUpdate() {
        if ( rigid.isKinematic || !awake ) return; // e

        Vector3 deltaV3 = transform.position - prevPos; // f
        deltas.Add( deltaV3.magnitude );
        prevPos = transform.position;

        // Limit lookback; one of very few times that I’ll use while! // g
        while ( deltas.Count > LOOKBACK_COUNT ) {
            deltas.RemoveAt( 0 );
        }

        // Iterate over deltas and find the greatest one
        float maxDelta = 0;
        foreach ( float f in deltas ) {
            if ( f > maxDelta ) maxDelta = f;
        }

        // If the Projectile hasn’t moved more than the sleepThreshold // h
        if ( maxDelta <= Physics.sleepThreshold ) {
            // Set awake to false and put the Rigidbody to sleep
            awake = false;
            rigid.Sleep();
        }
    }

    // void Update() {…} // Please delete the unused Update() method
}
```  

  - a. Этот атрибут компилятора RequireComponent гарантирует, что любой GameObject,
к которому прикреплен этот скрипт, имеет компонент Rigidbody.
  - b. Константа `LOOKBACK_COUNT` хранит максимальную длину, которую мы хотим
разрешить списку дельт. Она является константой, поскольку одно и то же значение
используется всеми снарядами и никогда не изменится. Любые константы заменяются на числовой литерал при компиляции кода.  
  - c. Что касается значения в режиме awake, мы хотим, чтобы оно отображалось в
инспекторе, и чтобы другие скрипты могли считывать это значение, но не хотим, чтобы
другие скрипты могли его изменять. Этот фрагмент кода - распространенный способ
достижения этой цели. Дополнительную информацию см. в блоке «Публичные
свойства get, частные свойства set».
  - d. Мы устанавливаем начальные значения в `prevPos` и `deltas` на положение и расстояние,
удаленные от фактического положения снаряда. Это дает снаряду некоторое время, чтобы
начать движение, прежде чем начальное значение `delta` будет удалено из списка `deltas`,
на случай, если возникнут сбои в физике, из-за которых может показаться, что снаряд не
движется в первых кадрах.
  - e. Если Rigidbody является кинематическим (что имеет место при прицеливании) или `awake`
становится `false` (что задано в `// h`), остальная часть `FixedUpdate()` не будет
выполняться. Это означает, что остальная часть `FixedUpdate()` будет выполняться
только в промежутке между моментом выстрела снаряда и моментом, когда `asleep`
впервые становится `true`.
  - f. Мы вычисляем расстояние между текущим положением и последним положением только
один раз, а затем сохраняем это расстояние в списке `deltas`. (Можно было бы также
сохранять каждое положение, а затем пересчитывать расстояния между ними в каждом
кадре, но это было бы гораздо менее эффективно.)
  - g. Я очень редко использую циклы `while`, но этот случай настолько прост, что я не
беспокоюсь по этому поводу. Если в списке `deltas` содержится больше, чем
`LOOKBACK_COUNT` элементов, удалите 0-е значение дельты (то есть самое старое), пока не
останется ровно `LOOKBACK_COUNT` элементов.
  - h. Наконец, если максимальное расстояние, зафиксированное в `deltas`, меньше
`sleepThreshold`, который мы задали в настройках Physics (ранее в этой главе),
установите `awake` в `false` и дайте Rigidbody команду перейти в режим ожидания (хотя бы
на один кадр).  

Хотя компонент Rigidbody может снова «проснуться», если в него врежется другой объект, после
того как значение awake в скрипте Projectile однажды станет `false`, оно останется `false`, что
делает его более подходящим для наших целей.  

2. Сохраните скрипт Projectile и вернитесь в Unity.  

<Callout>
### Public get, Private set Properties [!toc]
В листинге кода мы определяем свойство `awake`, имеющее открытый (public) метод доступа для чтения (`get`) и закрытый (private) метод доступа для записи (`set`), что не позволяет другим скриптам изменять его значение. Это весьма распространенный шаблон проектирования, позволяющий любому классу считывать значение такого свойства, как `awake`, но не дающий возможности его изменять.  

Одна из специфических для Unity проблем заключается в том, что эти свойства нельзя
увидеть или изменить в инспекторе. Если мы хотим также взаимодействовать со
значением `awake` в инспекторе Unity, нам нужно создать частное поле-подложку для
этого свойства (в данном примере - `_awake`) и присвоить ему атрибут компилятора
`[SerializeField]`, который указывает Unity показывать это значение в инспекторе (и
позволять вам изменять его там), даже если `_awake` является частным.
</Callout>
