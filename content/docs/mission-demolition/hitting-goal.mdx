---
title: Попадание в цель
description: Цель в замке должна реагировать на попадание снаряда
---

1. Создайте новый скрипт на C# с именем *Goal*.
2. Прикрепите скрипт *Goal* к префабу *Goal* в папке *_Prefabs* на панели *Project*.  

Я знаю, что вам, наверное, уже надоело слышать о вложенных префабах, но благодаря
вложенным префабам экземпляр Goal внутри префаба Castle теперь также имеет прикрепленный
скрипт Goal. Раньше, когда префабы нельзя было вкладывать друг в друга, подобные вещи
доставляли огромные хлопоты.  

3. Откройте скрипт Goal в Visual Studio и введите код из листинга:  

Листинг кода Goal.cs  

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

[RequireComponent ( typeof(Renderer) )]
public class Goal : MonoBehaviour {
    // A static field accessible by code anywhere
    static public bool goalMet = false;

    void OnTriggerEnter( Collider other ) {
        // When the trigger is hit by something
        // Check to see if it’s a Projectile
        Projectile proj = other.GetComponent<Projectile>(); // a
        if ( proj != null ) {
            // If so, set goalMet to true
            Goal.goalMet = true;
            // Also set the alpha of the color to higher opacity
            Material mat = GetComponent<Renderer>().material; // b
            Color c = mat.color;
            c.a = 0.75f;
            mat.color = c;
        }
    }

    // void Start() {…} // Please delete the unused Start() and Update() methods
    // void Update() {…}
}
```  

- a. В Apple Picker мы использовали теги для определения того, что представляет собой
GameObject, но, честно говоря, я считаю это очень неаккуратным и подверженным
ошибкам (например, наличие скрытых пробелов в теге или опечатки). Я гораздо больше
предпочитаю метод, показанный здесь: попытаться получить скрипт-компонент искомого
GameObject (в данном случае скрипт Projectile), и если результат не равен null, то вы
точно знаете, что имеете дело с Projectile.
- b. Здесь мы можем получить компонент Renderer этого GameObject, не беспокоясь о
том, что его может не быть, благодаря атрибуту компилятора RequireComponent в
начале скрипта, который гарантирует, что компонент Renderer будет присоединен.  

4. Сохраните скрипт Goal, вернитесь в Unity и нажмите Play.  

Теперь, если вы сможете поразить цель снарядом, она станет ярко-зеленой. Чтобы пробить этот
замок, может потребоваться несколько выстрелов. Чтобы упростить задачу, вы можете выделить
многие стены замка и отключить их, сняв флажок прямо под словом «Inspector» в верхней части
панели Inspector. Только не забудьте включить их обратно после тестирования Goal.  

5. Сохраните сцену.  

Теперь, когда у вас есть цель и вы можете поразить ее снарядом, это то, что я бы назвал
полноценным прототипом. Ваша основная механика работает, и вы можете протестировать ее
самостоятельно или показать другим разработчикам игр для получения отзывов, но в этой игре в
настоящее время отсутствует много важных элементов, которые необходимы, чтобы
действительно показать ее кому-то, не связанному с разработкой игр (потому что их, скорее
всего, отвлечет отсутствие таких вещей, как пользовательский интерфейс, и, следовательно, они
не дадут вам полезных отзывов). Большинство разработчиков называют первую версию, которую
можно с уверенностью показать человеку, не связанному с разработкой, «первой играбельной
версией». В оставшейся части Части III этой книги большинство игровых уроков будут разделены
на две части:  

- Часть 1: это часть урока, в которой вы наладите работу основной механики. В конце у вас
будет черновой прототип. Это то, что вы вполне можете показать другим разработчикам игр
для получения отзывов, но это еще не та версия, которую вы бы показали кому-то, кто не
является разработчиком.
- Часть 2: Здесь вы добавите пользовательский интерфейс, уровни и другие элементы,
которые сделают игру гораздо более увлекательной и повторяемой, а также превратят ее в
первую играбельную версию, которую можно показать кому угодно.  

Далее давайте превратим Mission Demolition из прототипа в первую играбельную версию.
