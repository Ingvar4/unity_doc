### Концепция прототипа игры [!toc]

В этой игре игрок использует рогатку, чтобы стрелять снарядами по замку в надежде
разрушить его. У каждого замка есть целевая зона, которую должен задеть снаряд, чтобы
игрок смог перейти на следующий уровень.  

Вот желаемая последовательность событий:  

1. Когда указатель мыши игрока находится в радиусе действия рогатки, рогатка должна
светиться.
2. Если игрок нажмет левую кнопку мыши (кнопка мыши 0 в Unity), пока рогатка светится,
снаряд появится в месте нахождения курсора мыши.
3. Когда игрок перемещает и перетаскивает мышь, удерживая кнопку нажатой, снаряд
следует за ней, но остается на определенном расстоянии от рогатки.
4. От каждого плеча рогатки вокруг снаряда тянется белая линия, чтобы он выглядел как
резинка настоящей рогатки.
5. Когда игрок отпускает кнопку мыши 0, снаряд выстреливает из рогатки.
6. Цель игрока - сбить замок, находящийся в нескольких метрах, и попасть в целевую зону
внутри него.
7. У игрока есть в общей сложности три выстрела, чтобы поразить цель. Последний выстрел
оставляет след, чтобы игрок мог лучше рассчитать следующий выстрел.  

Многие из предыдущих шагов касаются механики, но один - исключительно эстетика: шаг 4.
Все остальные элементы, в которых упоминается графика, используют её для целей игровой
механики, но шаг 4 нужен только для того, чтобы игра выглядела красивее, поэтому он менее
важен для прототипа. Когда вы записываете свои концепции игр, это важно иметь в виду. Это не
значит, что вы не должны реализовывать в прототипе элементы, которые являются
исключительно эстетическими; вам просто нужно осознавать и отдавать приоритет элементам,
которые будут иметь наиболее прямое влияние на игровую механику. Из соображений экономии
времени и места этот прототип сосредоточен на других элементах, и я оставляю реализацию
шага 4 для вас, чтобы вы занялись ею позже.

### Графические ресурсы [!toc]

Теперь вам следует создать несколько графических ресурсов, чтобы подготовить проект к
программированию.

### Поверхность [!toc]

Чтобы создать землю, выполните следующие действия:  

1. Откройте *_Scene_0*. Убедитесь, что в панели «Иерархия» отображается содержимое *_Scene_0*, а
именно *Main Camera* и *Directional Light* (если вы их не видите, щелкните
треугольник раскрытия рядом с _Scene_0 в панели «Иерархия»).
2. Создайте куб (выберите *GameObject > 3D Object > Cube* в панели меню).
    - a. Переименуйте куб в Ground.
    - b. Чтобы сделать Ground прямоугольным телом, очень широким в направлении оси x,
установите для него следующие параметры трансформации (значения, которые
необходимо изменить):  

    Ground (Cube) P:[ 0, -10, 0 ] R:[ 0, 0, 0 ] S:[ 100, 1, 4 ]  

3. Создать новый материал (*Assets > Create > Material*) и назовите его
*Mat_Ground*.
    - a. Присвойте *Mat_Ground* коричневый цвет альбедо.
    - b. Также установите для параметра Smoothness материала значение 0 (земля не очень блестит).
    - c. Прикрепите материал *Mat_Ground* к GameObject «Ground» в иерархии. Возможно, вам понадобится уменьшить масштаб окна просмотра сцены, чтобы увидеть «Ground».
4. Сохраните сцену.

### Направленный свет [!toc]

В последних версиях Unity направленный свет по умолчанию присутствует в новой сцене, но вам
все равно нужно задать для него правильные настройки для вашего проекта.  

1. Выберите *Directional Light* в панели Hierarchy. Одна из особенностей направленного света
заключается в том, что его положение не имеет значения для сцены; учитывается только его
поворот. В связи с этим переместите его в сторону, установив следующие параметры
трансформации:  

    Направленный свет P:[ - 10, 0, 0 ] R:[ 30, -30, 0 ] S:[ 1, 1, 1 ]

2. Сохраните сцену.  

### Настройки камеры [!toc]

Далее перейдем к настройкам камеры:  

1. Выберите *Main Camera* в иерархии и переименуйте её в *_MainCamera*. Мне нравится
переименовывать её таким образом, чтобы это было одно слово и она сортировалась
первой по алфавиту.
2. Установите для *_MainCamera* следующие настройки трансформации (убедитесь, что
позиция Y установлена на 0):  

    *_MainCamera* P:[ 0, 0, -10 ] R:[ 0, 0, 0 ] S:[ 1, 1, 1 ] 

3. Задайте для компонента камеры *_MainCamera* следующие настройки:
- a. Установите для параметра «Clear Flags» значение «Solid Color».
- b. Выберите более светлый цвет фона, чтобы он больше походил на голубое небо. Я выбрал
цвет [ R: 75, G: 220, B: 255 ].
- c. Установите для параметра *Projection* значение *Orthographic*.
- d. Установите размер (Size) равным 10.  

Окончательные настройки должны выглядеть, как показано на рисунке. Настройки, которые
необходимо было изменить по сравнению со значениями по умолчанию, выделены на
изображении.

Хотя вы уже использовали ортографические камеры ранее, я раньше не разъяснял значение
параметра *Size*. В ортографической проекции параметр «Размер» задает расстояние от
центра до нижней границы поля обзора камеры, то есть «Размер» равен половине высоты того,
что камера способна увидеть. Ground находится в положении `-10` и идеально делится пополам нижней частью окна
Game. Попробуйте изменить соотношение сторон панели Game с помощью всплывающего
меню, выделенного под указателем мыши на рисунке. Вы увидите, что независимо от
выбранного соотношения сторон центр куба Ground по-прежнему идеально располагается в
нижней части панели Game.  

>Если вы не видите Ground внизу панели Game, проверьте еще раз, что y-координата _MainCamera равна `0`, а y-координата Ground `-10`.

5. Сохраните сцену. Всегда сохраняйте сцену.
