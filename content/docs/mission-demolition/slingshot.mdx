---
title: Рогатка
description: Теперь создайте простую рогатку из трех цилиндров
---

1. Создайте пустой GameObject (*GameObject > Create Empty*).
    - a. Измените имя пустого GameObject на *Slingshot*.
    - b. Установите для *Slingshot* следующие параметры трансформации (это также можно
сделать, нажав на три вертикальные точки ( ⋮ ) в правом верхнем углу компонента
Transform и выбрав Reset):  

    Slingshot (Empty) P:[ 0, 0, 0 ] R:[ 0, 0, 0 ] S:[ 1, 1, 1 ]
2. Создайте новый цилиндр (*GameObject > 3D Object > Cylinder*).
    - a. Измените имя цилиндра на *Base*.
    - b. Перетащите «Base» под «Slingshot» в иерархии, сделав «Slingshot» его родительским
объектом.
    - c. Щелкните треугольник раскрытия рядом с «Slingshot» и снова выберите «Base».
    - d. Установите трансформацию «Base» следующим образом:  

    Base (Cylinder) P:[ 0, 1, 0 ] R:[ 0, 0, 0 ] S:[ 0.5, 1, 0.5 ]  

3. Выбрав *Base*, щелкните три вертикальные точки ( ⋮ ) рядом с компонентом Capsule
Collider в инспекторе и выберите «Удалить компонент». Это
удалит компонент Collider из *Base*, что не даст Projectile врезаться в него.

<img src="/unity_doc/images/ex68.jpeg" alt="1" style={{  height: 'auto' }} />

4. Создайте новый материал с именем *Mat_Slingshot*.
    - a. Установите цвет альбедо светло-желтым (или любым другим цветом по вашему
усмотрению).
    - b. Установите значение Smoothness равным 0.
    - c. Перетащите *Mat_ Slingshot* на *Base*, чтобы применить материал к GameObject Base.
5. Выберите *Base* в панели Hierarchy и скопируйте Base, нажав Command-D на клавиатуре
(Ctrl+D на компьютерах с Windows; или выбрав *Edit > Duplicate* в строке меню).  

Дублируя объект, вы гарантируете, что новый экземпляр также будет дочерним объектом
Slingshot, сохранит материал Mat_Slingshot и не будет иметь коллайдера.

6. Измените имя нового дубликата с «Base (1)» на «LeftArm». Установите трансформацию
«LeftArm» в соответствии с  

    LeftArm (Cylinder) P:[ 0, 3, 1 ] R:[ 45, 0, 0 ] S:[ 0.5, 1.414, 0.5 ]  
    Это составляет одну из рук рогатки.

    >Масштаб оси Y для рук равен 1,414, поскольку это приблизительно соответствует коэффициенту пропорций (квадратный корень из 2). Согласно теореме Пифагора, если длина объекта равна 1,414, а угол наклона составляет 45°, то его длины по осям Y и Z будут равны 1.  

7. Выберите *LeftArm* в иерархии.
    - a. Скопируйте LeftArm (Command-D или Ctrl+D).
    - b. Переименуйте этот экземпляр с LeftArm (1) в RightArm. После этого ваша
иерархия должна выглядеть так, как показано на рисунке.
    - c. Установите трансформацию RightArm следующим образом:  
    RightArm (Cylinder) P:[ 0, 3, - 1 ] R:[ - 45, 0, 0 ] S:[ 0.5, 1.414, 0.5 ]
8. Выберите Slingshot в иерархии.
    - a. Установите трансформацию Slingshot следующим образом

<img src="/unity_doc/images/ex69.jpeg" alt="1" style={{  height: 'auto' }} />

Настройки компонента Sphere Collider для Slingshot слева; красный
прямоугольник относится к шагу 9e. Справа показан значок Launch Point Gizmo,
который вы установили в шаге 9e.  

Slingshot (Empty) P:[ - 10, - 10, 0 ] R:[ 0, - 15, 0 ] S:[ 1, 1, 1 ]  

Это привязывает его к левой стороне экрана, а поворот по оси y на -15° придает ему некоторую
объемность даже при использовании ортогональной камеры.  

    - b. Добавьте компонент Sphere Collider к Slingshot (*Component > Physics > Sphere
Collider*).
    - c. Установите для компонента Sphere Collider настройки, показанные на рисунке.
По завершении коллайдер будет выглядеть как зелёная сфера в виде каркаса.  

        - Установите для параметра *Is Trigger* значение true (флажок установлен).
        - Установите значение Y для параметра *Center* равным 4.
        - Установите значение *Radius* равным 3.  

Вы будете слышать о свойстве коллайдера - `Is Trigger = true` часто его называют просто
*Trigger*. Триггеры являются частью физической симуляции в Unity и отправляют уведомления,
когда другие Colliders или Triggers проходят через них. Однако другие объекты не отскакивают от
Triggers, как от обычных Colliders. Вы будете использовать этот большой сферический Trigger для
обработки взаимодействия мыши с рогаткой.  

9. Добавьте «точку запуска» к рогатке, чтобы задать конкретное место, откуда будут
выстреливать снаряды.
    - a. Выберите Slingshot в иерархии.
    - b. Создайте пустой GameObject в качестве дочернего объекта Slingshot (*GameObject > Create Empty
Child*).
    - c. Переименуйте новый пустой дочерний объект с GameObject в *LaunchPoint*.
    - d. Установите для «Transform» объекта «LaunchPoint» следующие
значения:  
    LaunchPoint (Empty) P:[ 0, 4, 0 ] R:[ 0, 15, 0 ] S:[ 1, 1, 1 ]  

Поворот на 15° по оси y приводит к выравниванию LaunchPoint по осям x, y и z в координатах
мира. (То есть это устраняет поворотна -15°,который был добавлен к Slingshot.)  

    - e. В верхней части инспектора *LaunchPoint* щелкните куб, обведенный красным
прямоугольником. В всплывающем меню выберите любой из ромбов в
нижнем ряду значков (я выбрал синий, как видно на рисунке).  

Теперь выбранный вами значок появится в виде манипулятора в окне «Сцена» в точке, где
находится невидимая точка запуска. После выполнения этих шагов
ваша иерархия должна выглядеть так, как показано на рисунке.

<img src="/unity_doc/images/70.jpeg" alt="1" style={{  height: 'auto' }} />

10. Сохраните сцену.
