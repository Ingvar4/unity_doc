Готовый замок (после изменения размера плит и добавления цели, что вы
сделаете в ближайшее время)

1. Создайте пустой GameObject, который станет корневым узлом замка (*GameObject > Create
Empty*).
    - a. Назовите его *Castle*.
    - b. Установите его трансформацию на  
    P:[ 10, - 9.5, 0 ] R:[ 0, 0, 0 ] S:[ 1, 1, 1 ].  
    Это обеспечит его
правильное расположение для строительства и позволит разместить его основание точно на
Ground, не допуская при этом соприкосновения с иконкой Camera.
2. Перетащите Wall из иерархии под Castle, сделав его дочерним элементом Castle.
3. Сделайте три дубликата Wall и установите позиции каждой из четырех стен следующим
образом:  

    Wall P:[ -6, 2, 0 ] Wall (1) P:[ -2, 2, 0 ]  

    Wall (2) P:[ 2, 2, 0 ] Wall (3) P:[ 6, 2, 0 ]  

4. Перетащите «Slab» из папки «_Prefabs» панели «Project» в «Castle», сделав его также
дочерним элементом.
5. Сделайте две копии Slab и установите положения трех Slab следующим образом:
Плита P:[ -4, 4.25, 0 ] Плита (1) P:[ 0, 4.25, 0 ] Плита (2) P:[ 4, 4.25, 0 ]
6. Прежде чем создавать следующий этаж замка, необходимо изменить настройки сетки.
    - a. В верхней части панели Scene нажмите на значок сетки (в элементе Grid Pop-up, обозначенном на рис), чтобы он подсветился ярко-серым цветом. Затем нажмите на направленный вниз треугольник этого элемента, чтобы открыть его меню.
    - b. Щелкните три точки ( ⋮ ) в правом верхнем углу всплывающего меню.
    - c. Выберите *Edit Grid and Snap Settings* .
    - d. В разделе *Increment Snap* убедитесь, что значение «Сдвиг по оси X» значение «Сдвиг
по оси X» равно 0, 25. Поскольку все три измерения привязаны друг к другу, настройка для
оси X также определит значения для осей Y и Z.
    - e. Закройте окно *Grid and Snap*.  

Внесение этого изменения в настройки сетки и привязки ограничит перемещение в Unity сеткой с
шагом 0,25 м, когда вы удерживаете клавишу Command (Ctrl в Windows) при использовании
инструмента «Перемещение».  

7. Чтобы создать второй этаж замка, выберите мышью три любые смежные стены и две
плиты над ними.
    - a. Скопируйте их (Command-D или Ctrl+D).
    - b. Убедитесь, что выбран инструмент «Перемещение» (нажмите W на клавиатуре или
щелкните второй инструмент на панели инструментов в левом верхнем углу окна Unity).
    - c. Удерживая клавишу Command (Ctrl в Windows), переместите их так, чтобы они
располагались непосредственно над другими, как показано на рисунке. Удерживая
Command, вы ограничиваете перемещение сеткой 0,25м, которую вы установили ранее,
что должно позволить вам точно расположить второй этаж. Если вам все же понадобится
подкорректировать их положения, окончательные координаты новых стен и плит должны
быть следующими:  

Wall (4) P:[ -4, 6.5, 0 ]  
Wall (5) P:[ 0, 6.5, 0 ]  
Wall (6) P:[ 4, 6.5, 0 ]  
Slab (3) P:[ -2, 8.75, 0 ]  
Slab (4) P:[ 2, 8.75, 0 ]  

8. Продолжайте дублировать и перемещать сетку, чтобы создать третий этаж, добавив еще
две стены и одну плиту:  

Wall (7) P:[ -2, 11, 0 ]  
Wall (8) P:[ 2, 11, 0 ]  
Slab (5) P:[ 0, 13.25, 0 ]  

9. Добавьте последнюю стену, чтобы завершить строительство замка:  

Wall (9) P:[ 0, 15.5, 0 ]  

10. Сделайте GameObject «Castle» префабом, перетащив «Castle» из панели «Hierarchy» в
папку «_Prefabs» панели «Project».  

Вы заметите, что значок Castle в иерархии становится синим, а значки всех дочерних объектов
Wall и Slab также остаются синими. Это означает, что они по-прежнему являются
экземплярами префабов Wall и Slab, что возможно благодаря вложенным префабам.  

Одно из главных преимуществ постройки замка из вложенных префабов заключается в том, что
вы можете легко изменить все Slab одновременно, изменив префаб Slab.  

11. Выберите префаб Slab на панели Project и установите его параметр `Transform Scale X` на
`3.5`. Каждая плита в вашем замке должна отразить это изменение. Теперь ваш замок должен
выглядеть, как показано на рисунке, за исключением того, что в вашем замке пока нет
зеленой цели.
