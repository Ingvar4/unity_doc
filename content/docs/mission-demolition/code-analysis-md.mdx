## Скрипт Slingshot.cs

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class Slingshot : MonoBehaviour {
    [Header("Inscribed")] 
    public GameObject projectilePrefab;
    public float velocityMult = 10f; 
    
    [Header("Dynamic")] 
    public GameObject launchPoint;
    public Vector3 launchPos; // Хранит 3D-координаты launchPoint в игровом мире
    public GameObject projectile; // Это ссылка на новый экземпляр Projectile, который создается
    public bool aimingMode; // Обычно имеет значение false, но устанавливается в true, когда игрок нажимает кнопку мыши 0 над Slingshot

    void Awake() {
        Transform launchPointTrans = transform.Find("LaunchPoint"); // Ищет дочерний объект Slingshot с именем LaunchPoint и возвращает его Transform
        launchPoint = launchPointTrans.gameObject; // Получает GameObject, связанный с этим Transform, и присваивает его полю launchPoint объекта GameObject
        launchPoint.SetActive( false ); // Метод SetActive() для GameObjects, таких как launchPoint, сообщает игре, следует ли их игнорировать
        launchPos = launchPointTrans.position; // Строка для установки launchPos
    }

    void OnMouseEnter() {
        //print("Slingshot:OnMouseEnter()");
        launchPoint.SetActive( true );
    }

    void OnMouseExit() {
        //print("Slingshot:OnMouseExit()");
        launchPoint.SetActive( false );
    }

    void OnMouseDown() { 
        // Игрок нажал кнопку мыши, находясь над рогаткой
        aimingMode = true;
        projectile = Instantiate( projectilePrefab ) as GameObject; // Создание экземпляра снаряда
        projectile.transform.position = launchPos; // Запуск снаряда в точке launchPoint
        projectile.GetComponent<Rigidbody>().isKinematic = true; // Установка isKinematic в true
    }

    void Update() {
        if (!aimingMode) return; // Если Slingshot не находится в режиме aimingMode, то осуществляется return, и остальная часть кода не выполняется
        // Получение текущего положение курсора мыши в 2D-координатах экрана
        Vector3 mousePos2D = Input.mousePosition; // Преобразование положения мыши из экранных координат в координаты мира
        mousePos2D.z = -Camera.main.transform.position.z;
        Vector3 mousePos3D = Camera.main.ScreenToWorldPoint( mousePos2D );
        // Найдите разницу между launchPos и ​​mousePos3D
        Vector3 mouseDelta = mousePos3D -launchPos;
        // Ограничить значение mouseDelta радиусом Slingshot SphereCollider 
        // Этот код ограничивает движение снаряда, чтобы его центр оставался в радиусе Sphere Collider на Slingshot
        float maxMagnitude = this.GetComponent<SphereCollider>().radius;
        if (mouseDelta.magnitude > maxMagnitude) {
            mouseDelta.Normalize();
            mouseDelta *= maxMagnitude;
        }
        // Перемещение снаряда в новое положение
        Vector3 projPos = launchPos + mouseDelta;
        projectile.transform.position = projPos;
        if ( Input.GetMouseButtonUp(0) ) {  // Здесь, вместо того чтобы запускать метод OnMouseUp(), мы считываем состояние кнопки мыши 0 с помощью Input.GetMouseButtonUp(0). Это вернет true только в том Update (т. е. кадре), в котором игрок отпустил кнопку мыши
            // Кнопка мыши отпущена
            aimingMode = false;
            Rigidbody projRB = projectile.GetComponent<Rigidbody>();
            projRB.isKinematic = false; // Установка isKinematic обратно в false позволяет снаряду теперь лететь в воздухе на основе физической симуляции
            projRB.collisionDetectionMode = CollisionDetectionMode.Continuous; // Устанавливаем режим обнаружения столкновений (Collision Detection Mode) в continuous
            projRB.velocity = -mouseDelta * velocityMult;
            projectile = null; // Установка поля projectile обратно в null разрывает связь между
            // этим экземпляром скрипта Slingshot и GameObject снаряда. Это хорошая задача 
            // по очистке. Если бы мы не разорвали эту связь, а позже код уничтожил этот 
            // снаряд, то оставшаяся ссылка на него помешала бы повторному использованию 
            // памяти компьютера, занимаемой снарядом, для других целей
        }
    }
}
```
<Callout>
### SetActive() [!toc]
Если для GameObject установлено значение `active = false`, он не будет отображаться на экране и не будет получать вызовы функций, таких как `Update()` или `OnCollisionEnter()`. Это не уничтожает GameObject, а просто исключает его из активной части игры. В инспекторе GameObject флажок в верхней части инспектора, расположенный слева от названия GameObject, указывает, активен ли GameObject
</Callout>

<Callout>
### OnMouseEnter() [!toc]
Это встроенное событие, которое автоматически вызывается в скрипте, когда курсор мыши впервые наводится на объект (пересекает границы его коллайдера)    

**Три важных условия для работы:**  
- Наличие Collider: На объекте обязательно должен быть компонент Collider (например, Box Collider, Mesh Collider и т.д.).
- Raycast Target: Этот метод не срабатывает, если объект находится на слое Ignore Raycast.
- По умолчанию работает и для триггеров (если в настройках физики Physics.queriesHitTriggers не установлено значение false).
</Callout>

<Callout>
### OnMouseExit() [!toc]
Это встроенное событие, которое автоматически вызывается скриптом, когда курсор мыши полностью покидает пределы коллайдера (Collider) или GUI-элемента объекта.  

- Событие-триггер: Срабатывает ровно один раз в момент, когда курсор «уходит» с объекта.
- С чем работает: Требует, чтобы на игровом объекте обязательно висел компонент коллайдера (например, BoxCollider, SphereCollider) и камера имела компонент PhysicsRaycaster.
</Callout>

<Callout>
### OnMouseDown() [!toc]
Будет вызван только в том единственном кадре, когда игрок нажмет кнопку мыши над компонентом Collider GameObject Slingshot, поэтому этот метод может быть вызван только в том случае, если мышь находится в допустимом начальном положении в пределах Collider GameObject Slingshot.   
</Callout>
