## Скрипт Hero.cs

- Считывание значений осей ввода с помощью `Input.GetAxis()` (метод считается устаревшим)
- Настройка перемещения объекта в зависимости от полученых значений с осей
- Добавление Rotation объекта при его движении

```c# title="C# Hero.cs"
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class Hero : MonoBehaviour {
    static public Hero S { get; private set; } // Объявляем синглтон где set приватный, что позволяет вносить в него изменения только из кода класса Hero

    [Header("Inscribed")]
    // Эти поля управляют движением корабля
    public float speed = 30;
    public float rollMult = -45;
    public float pitchMult = 30;

    [Header("Dynamic")] [Range(0,4)] // Атрибут [Range(0,4)] здесь добавляет ползунок в Инспектор и не позволяет нам использовать Инспектор для установки shieldLevel в значение меньше 0 или больше 4
    public float shieldLevel = 1;

    void Awake() {
        if (S == null) {
            S = this; // Выдает ошибку в панели Console, если вы попытаетесь установить Hero.S после того, как он уже был установлен
        } else {
            Debug.LogError("Hero.Awake() - Attempted to assign second Hero.S!");
        }
        // Это еще одна мера защиты от ошибок (например, если в одной сцене было два GameObject, 
        // к которым были прикреплены скрипты Hero, или два компонента Hero, прикрепленных к одному GameObject)
    }

    void Update(){
        // Получаем информацию из класса Input
        // Эти две строки используют класс Input Unity для извлечения информации из Unity Input Manager
        float hAxis = Input.GetAxis("Horizontal");
        float vAxis = Input.GetAxis("Vertical");

        // Изменяем transform.position в зависимости от осей
        Vector3 pos = transform.position; // Получаем позицию объекта
        pos.x += hAxis * speed * Time.deltaTime; // Позиции по оси Х присваиваем значение перемножения горизонтальной оси на заданную скорость и на время в секундах, которое прошло с момента показа предыдущего кадра (Time.deltaTime)
        pos.y += vAxis * speed * Time.deltaTime; // То же самое делаем с позицией по Y
        transform.position = pos; // Получившиеся значения присваиваем pos

        // Поворот корабля (Rotate), для большей динамики
        transform.rotation = Quaternion.Euler(vAxis * pitchMult, hAxis * rollMult, 0); //pitchMult и rollMult умножаются на vAxis и hAxis (каждый из которых находится в диапазоне от [-1..1]), чтобы наклонять корабль вперед и назад (от –30 до 30 градусов) и кренить его влево и вправо (от 45 до –45 градусов)
    }
}
```

<Callout>
### `Quaternion.Euler()` [!toc]
Это метод, который переводит привычные нам углы поворота по осям X, Y и Z (углы Эйлера) в специальный математический формат кватернионов, который движок использует для вращения объектов. Он принимает вектор Vector3 и возвращает готовый поворот.  
- Входные данные: Принимает три числа (или Vector3) — градусы поворота по осям X (pitch), Y (yaw) и Z (roll).
- Результат: Возвращает тип данных Quaternion, который понятен компоненту transform.rotation.
- Порядок вращения: Поворот происходит в порядке: сначала по оси Z, затем по оси X и в конце по оси Y.
</Callout>

## Скрипт Shield.cs

```c# title="C# Shield.cs"
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class Shield : MonoBehaviour {
    [Header("Inscribed")]
    public float rotationsPerSecond = 0.1f;

    [Header("Dynamic")]
    public int levelShown = 0; 

    // Эта переменная не будет отображаться в инспекторе
    Material mat; // Поле Material mat не объявлено как public, поэтому оно не будет отображаться в инспекторе и к нему не будет доступа за пределами класса Shield

    void Start() {
        mat = GetComponent<Renderer>().material; // В Start() mat определяется как материал компонента Renderer на этом GameObject (т. е. компонента Renderer Shield в иерархии). Это позволяет быстро установить смещение текстуры в строке mat.mainTextureOffset
    }

    void Update() {
        // Считываем текущий уровень щита у Hero Singleton
        int currLevel = Mathf.FloorToInt( Hero.S.shieldLevel ); // currLevel устанавливается на целое значение текущего числа Hero.S.shieldLevel. Округление shieldLevel к меньшему значению гарантирует, что щит переместится на новое смещение по оси X, а не покажет смещение между двумя участками текстуры щита
        // Если это отличается от levelShown...
        if (levelShown != currLevel) {
            levelShown = currLevel;
            // Отрегулируйте смещение текстуры, чтобы отображать разные уровни защиты
            mat.mainTextureOffset = new Vector2( 0.2f * levelShown, 0 ); // Настраивает смещение по оси X Mat_Shield, чтобы отобразить правильный уровень щита
        }
        // Поворот щита каждый кадр с задержкой по времени
        float rZ = -(rotationsPerSecond * Time.time * 360) % 360f; // Эта строка и следующая за ней заставляют GameObject Shield медленно вращаться вокруг оси z
        transform.rotation = Quaternion.Euler( 0, 0, rZ );
    }
}
```

## Скрипт BoundsCheck.cs

```c# title="C# BoundsCheck.cs"
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

// If you type /// in Visual Studio, it will automatically expand to a <summary>
/// <summary>
/// Keeps a GameObject on screen.
/// Note that this ONLY works for an orthographic Main Camera.
/// </summary>
// система интерпретирует текст между тегами <summary> как краткое описание назначения класса
public class BoundsCheck : MonoBehaviour {
    public enum eType { center, inset, outset }; // Позволяет нам контролировать, будет ли BoundsCheck центрированным, смещенным внутрь или наружу, а общедоступный eType boundsType можно установить в Инспекторе

    [Header("Inscribed")]
    public eType boundsType = eType.center; 
    public float radius = 1f;
    public bool keepOnScreen = true; // Компонент BoundsCheck принудительно удерживает игровой объект в пределах экрана

    [Header("Dynamic")]
    public bool isOnScreen = true; // принимает значение false, если игровой объект покидает пределы экрана. Точнее говоря, при типе границ outset значение isOnScreen становится false, если игровой объект выходит за край экрана на расстояние, превышающее радиус
    public float camWidth; 
    public float camHeight;

    void Awake() {
        camHeight = Camera.main.orthographicSize; // .orthographicSize возвращает значение Size из инспектора камеры (в данном случае 40). Таким образом, camHeight представляет собой расстояние от начала координат мира (позиция 0,0,0) до верхнего или нижнего края экрана в мировых координатах
        camWidth = camHeight * Camera.main.aspect; // Camera.main.aspect - это соотношение сторон камеры по ширине/высоте, определяемое соотношением сторон панели Game, что делает aspect равным 0.75f. Умножив camHeight на .aspect, можно получить расстояние от начала координат до левого или правого края экрана
    }

    void LateUpdate () { 
        // Нахождение значения checkRadius, которое позволит выбрать center, inset, или outset
        float checkRadius = 0;
        if (boundsType == eType.inset) checkRadius = -radius;
        if (boundsType == eType.outset) checkRadius = radius;

        Vector3 pos = transform.position;
        isOnScreen = true; // Изначально присваивается значение true, пока не будет доказано обратное. Это позволяет isOnScreen снова стать true, если в предыдущем кадре объект находился за пределами экрана, а в текущем - вернулся в его границы
        // Ограничение положения по оси X значением camWidth
        if ( pos.x > camWidth + checkRadius ) {
            pos.x = camWidth + checkRadius;
            isOnScreen = false;
        }
        if ( pos.x < -camWidth - checkRadius ) {
            pos.x = -camWidth - checkRadius;
            isOnScreen = false;
        }
        if ( pos.y > camHeight + checkRadius ) {
            pos.y = camHeight + checkRadius;
            isOnScreen = false;
        }
        if ( pos.y < -camHeight - checkRadius ) {
            pos.y = -camHeight - checkRadius;
            isOnScreen = false;
        }
        // Если условие в любой из этих четырех инструкций if выполняется, значит, игровой объект вышел 
        // за пределы допустимой зоны. В результате isOnScreen устанавливается в false, а переменная pos 
        // корректируется так, чтобы вернуть объект в границы экрана

        // Если keepOnScreen равен true, это означает, что вы пытаетесь удержать игровой объект в 
        // пределах экрана. Если keepOnScreen равен true, а isOnScreen - false, значит, объект вышел 
        // за границы и его необходимо вернуть обратно. В этом случае transform.position присваивается 
        // обновленное значение pos (находящееся в пределах экрана), а isOnScreen устанавливается в true, 
        // так как в результате присвоения новой позиции объект вернулся на экран
        if ( keepOnScreen && !isOnScreen ) { 
            transform.position = pos; 
            isOnScreen = true;
        }
    }
}
```

<Callout>
### `LateUpdate()` [!toc]
Вызывается в каждом кадре после того, как `Update()` был вызван для всех GameObjects. Если бы этот код находился в функции `Update()`, он мог бы выполняться либо до, либо после вызова `Update()` в скрипте Hero. Размещение этого кода в `LateUpdate()` позволяет избежать возникновения условия гонки между двумя функциями `Update()` и гарантирует, что `Hero.Update()` перемещает GameObject _Hero в новое положение в каждом кадре, прежде чем эта функция сохранит его на экране
</Callout>

<Callout>
### Race condition [!toc]
Cостояние гонки (race condition) - это ситуация, когда порядок выполнения двух фрагментов кода (т. е. A перед B или B перед A) имеет значение, но вы не можете контролировать этот порядок. Например, в этом коде, если `BoundsCheck.LateUpdate()` будет выполнена раньше `Hero.Update()`, GameObject _Hero потенциально может выйти за пределы границ (поскольку сначала будут ограничены границы, а затем будет перемещен корабль). Выполнение ограничения в виде `LateUpdate()` в BoundsCheck обеспечивает соблюдение порядка выполнения двух скриптов (где `Update()` всегда предшествует `LateUpdate()`), предотвращая состояние гонки.
</Callout>
