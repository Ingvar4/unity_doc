Классы являются важнейшим строительным
блоком современных игр и, в более широком смысле,
объектно-ориентированного
программировании. К концу этой главы вы поймёте, как
создавать и использовать классы, а также осознаете их
важность при разработке игр в Unity.

## Понимание классов [!toc]
Классы объединяют функциональность и данные. Иными словами, классы
состоят как из функций, так и из переменных (которые при использовании
внутри класса называются методами и полями соответственно). Классы
часто используются для представления объектов в мире вашего игрового
проекта. Например, рассмотрим персонажа в стандартной ролевой игре. У
него может быть несколько полей (или переменных):

```c#
string name; // The character’s name
float health; // The current amount of health she has
float healthMax; // The maximum amount of health she could have
List<Item> inventory; // A List of all Items in her inventory
List<Item> equipped; // A List of Items that she currently has equipped
```

Все эти поля применимы к любому персонажу в ролевой игре (RPG),
поскольку все персонажи имеют здоровье, снаряжение и имя. Кроме того,
этим персонажем или в отношении него могут использоваться несколько
методов (функций).  

Многоточие между фигурными скобками ( `{…}` ) в следующем фрагменте
кода показывает, где необходимо добавить код, чтобы функции
действительно работали:

```c#
void Move(Vector3 newLocation) {…} // Allows the character to move
void Attack(Character target) {…} // Attacks target Character with the
// currently equipped weapon or spell
void TakeDamage(float damageAmt) {…} // Causes this character to lose health
void Equip(Item newItem) {…} // Adds an Item to the equipped List
```

Конечно, в реальной игре у персонажа должно быть гораздо больше полей и
методов, чем описано здесь, но основная идея заключается в том, что все
персонажи в вашей RPG должны иметь эти функции и переменные.

Диаграмма, показывающая важные элементы класса  

- Включения позволяют вашим скриптам на C# использовать
различные классы, созданные другими разработчиками. Включения
активируются с помощью операторов use, а показанные здесь
включения включают все стандартные элементы Unity, а также
коллекции, такие как списки. Они должны быть первой частью вашего
скрипта.
- Объявление класса задает имя класса и определяет, какие другие
классы он расширяет (см. раздел «Наследование классов» далее в этой
главе). В данном случае класс `Enemy` расширяет класс
`MonoBehaviour` (что делает `MonoBehaviour` суперклассом
`Enemy`, а `Enemy` - подклассом `MonoBehaviour`). Эта концепция суперклассов и подклассов называется наследованием и является
основой объектно-ориентированного программирования. Мы
поговорим об этом подробнее далее в этой главе.
- Поля - это переменные, локальные для вашего класса, то есть
любая функция внутри класса может получить к ним доступ по
имени. Кроме того, к переменным с меткой public может
получить доступ любой другой объект, который видит этот класс
(см. раздел «Область видимости переменных» в Приложении B
«Полезные концепции»).
- Методы - это функции, содержащиеся внутри класса. Они могут
обращаться к любому из полей класса, а также могут содержать
локальные переменные (например, `Vector3 tempPos` в `Move()`),
которые существуют только в пределах этого одного метода. Именно
методы позволяют классам выполнять действия (например, перемещать
GameObject). Виртуальные методы - это особый тип методов,
который рассматривается в разделе «Наследование классов» далее в
этой главе.
- Свойства можно рассматривать как методы, маскирующиеся под
поля с помощью аксессоров get и set. Дополнительную
информацию см. в разделе «Свойства» далее в этой главе.
- Еще одним элементом стандартных классов C# является
конструктор класса - метод, вызываемый при создании класса. Я
не рассматриваю конструкторы в этой книге, поскольку попытка
использовать их в подклассах MonoBehaviour (к которым относятся
все классы, которые можно прикрепить к GameObject в Unity)
приводит к проблемам с библиотекой.
