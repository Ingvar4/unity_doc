1. В главном меню Unity выберите *Assets > Create > C# Script*.
Это поместит новый скрипт в папку Assets панели Project и даст вам
возможность присвоить ему имя.  

a. Назовите скрипт Enemy.  

b. Дважды щелкните скрипт, чтобы открыть его в Visual Studio.

2. В Visual Studio введите код из листинга.

```c#
using System.Collections; // Included automatically but rarely used
using System.Collections.Generic; // Required for Lists & Dictionaries
using UnityEngine; // Required for Unityspecific Classes

public class Enemy : MonoBehaviour {

    public float speed = 10f; // The speed in m/s
    public float fireRate = 0.3f; // Shots/second (Unused)

    // Update is called once per frame
    void Update() {
        Move();
    }

    public virtual void Move() {
        Vector3 tempPos = pos;
        tempPos.y -= speed * Time.deltaTime;
        pos = tempPos;
    }

    void OnCollisionEnter( Collision coll ) {
        GameObject other = coll.gameObject;
        switch ( other.tag ) {
            case "Hero":
            // Currently not implemented (this would destroy the hero)
            break;
            case "HeroLaser":
            // Destroy this Enemy
            Destroy( this.gameObject );
            break;
        }
    }

    // This is a Property: A method that acts like a field
    public Vector3 pos {
        get {
            return this.transform.position;
        }
        set {
            this.transform.position = value;
        }
    }

}
```

Большая часть этого должна показаться вам довольно простой и знакомой,
за исключением свойства и виртуальной функции, которые я рассмотрю в
этой главе.

### Создание свойств - методов, работающих как поля [!toc]

В листинге кода видно, что свойство `pos` обрабатывается как поле
как в строке 16, так и в строке 18 функции `Move()` - то есть `pos`
считывается в строке 16 и устанавливается в строке 18, как если бы это
было поле или переменная. Это достигается за счет использования
операторов доступа `get{}` и `set{}` в строках 36–41, которые позволяют
этому классу выполнять код каждый раз, когда вы считываете или
устанавливаете свойство pos. Вы можете создать свойство только с
аксессором `get{}`, чтобы сделать его доступным только для чтения (или
только с аксессором `set{}`, чтобы сделать его доступным только для
записи).  

Каждый раз при чтении свойства `pos` выполняется код внутри аксессора
`get{}`, и для того, чтобы быть корректным, аксессор `get{}` должен
возвращать значение того же типа, что и само свойство (например, в
данном случае аксессор `get{}` должен возвращать `Vector3`).
Код внутри блока-аксессора `set{}` выполняется каждый раз, когда
свойству pos присваивается значение, а ключевое слово `value`
используется в качестве неявной переменной, хранящей присвоенное
значение. Неявная переменная - это такая переменная, которая
существует без явного объявления со стороны программиста. Все блоки
`set{}` в свойствах имеют неявную переменную `value`. Например пример, в строке 18 переменной `pos` присваивается значение `tempPos`,
что вызывает аксессор `set{}` свойства pos в строке 39; затем в строке 40
неявная переменная `value` (содержащая значение `tempPos`)
присваивается `this.transform.position`.

**Использование get не только для возврата значения**  

В примере с свойством `pos` класса `Enemy` в листинге
переменная `pos` используется просто для доступа к полю
`this.transform.position`. Однако в последующем листинге приведен более
интересный пример.  

1. Создайте новый скрипт на C# с именем *CountItHigher*.
2. Прикрепите скрипт *CountItHigher* к объекту *Sphere* в сцене и
сохраните сцену.
3. Дважды щелкните скрипт *CountItHigher* на панели «Проект», чтобы
открыть его в Visual Studio, и введите код:

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class CountItHigher : MonoBehaviour {

    private int _num = 0; // a

    void Update() {
        Debug.Log( "The next num is: " + nextNum );
    }

    public int nextNum { // b
        get { _num++; // Increase the value of _num by 1
            return _num; // Return the new value of _num
        }
    }

    public int currentNum { // c
        get { return _num; } // d
        set { _num = value; } // d
    }

// void Start() {…} // Please delete the unused Start() method // e
}
```

a. Целочисленное поле `_num` является частным, поэтому доступ к
нему имеют только экземпляры класса `CountItHigher`. Другие
классы не могут видеть частные переменные экземпляра этого класса.  

>Любой экземпляр класса `CountItHigher` может видеть и устанавливать значения
частных полей любого другого экземпляра `CountItHigher`, поэтому поле _num
может быть установлено любым другим экземпляром `CountItHigher`, хотя эта
возможность используется очень редко.  

b. `nextNum` - это свойство, доступное только для чтения.
Поскольку нет оператора `set{}`, его можно только читать
(например, `int x = nextNum;`) и нельзя устанавливать
(например, `nextNum = 5;` вызовет ошибку).  

c. `currentNum` - это свойство, которое можно как читать, так и
устанавливать. Работать будут как `int x = currentNum;`, так и
`currentNum = 5;`.  

d. При желании оператор `get{}` или `set{}` можно записать в одной
строке, как показано в строках 21 и 22. Обратите внимание, что в
однострочном формате точка с запятой ( ; ) обязательна для
завершения оператора между фигурными скобками (`{}`), но не
требуется в конце строки.  

e. Если первый листинг кода нового
скрипта на C# не содержит метода `Start()` или `Update()`,
удалите все пропущенные методы из нового скрипта на C# . В листинге
кода используется `Update()`, но не `Start()`, поэтому метод
`Start()` следует удалить.  

4. Вернитесь в Unity и нажмите «Play». Поскольку функция `Update()`
вызывается Unity в каждом кадре, вывод оператора `Debug.Log(
"The next num is:" + nextNum );` увеличивается в каждом
кадре.  

Вывод первых пяти кадров выглядит следующим образом:  

```c#
The next num is: 1
The next num is: 2
The next num is: 3
The next num is: 4
The next num is: 5
```  

Каждый раз, когда считывается свойство `nextNum` (с помощью
`Debug.Log( The next num is: " + nextNum );`), оно увеличивает
значение частного поля
`_num`, а затем возвращает новое значение (строки 15 и 16 листинга кода).
Хотя это небольшой пример, аксессор `get` или `set` может делать все,
что может делать обычный метод, даже вызывать другой метод или
функцию.  

Аналогично, `currentNum` - это общедоступное свойство, позволяющее либо читать, либо устанавливать значение `_num`. Поскольку `_num` является закрытым полем,
публичный доступ к свойству `currentNum` позволяет отслеживать и проверять доступ к `_num`.  

>Чтобы продемонстрировать использование свойства `currentNum` для отслеживания доступа к
переменной `_num`, можно либо добавить оператор `Debug.Log()` в блок `set{}` свойства
`currentNum`, либо с помощью отладчика установить точку останова на 22-й строке, которая
будет приостанавливать выполнение при каждом присвоении значения `currentNum`. Любой
из этих способов поможет вам понять, когда происходит присвоение значения `currentNum`,
что облегчит отладку связанных с ним проблем.
