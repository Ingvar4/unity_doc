---
title: Выпадение случайных предметов
description: Вы также хотите реализовать возможность того, чтобы враги бросали случайный предмет.
---

Если для guaranteedDrop, не задан,то случайный предмет будет выбран из массива возможных
предметов, и список будет включать несколько нулевых записей, чтобы предмет не всегда
гарантированно появлялся.

>Хотя для некоторых типов данных в Инспекторе не допускается значение null, для GameObject guaranteedDrop можно установить значение None (GameObject), которое Unity преобразует в null. 

Сначала вам нужно выполнить некоторую подготовительную работу с предметами.  

#### Создание предмета Health PickUp [!toc]
Чтобы создать элемент здоровья, выполните следующие действия:  

1. На панели Project выберите оба спрайта Health_ 2 и Health_ 3 в папке Health Texture 2D в папке
Art by Andrew Dennis (щелкните один, а затем, удерживая Shift, щелкните другой).
2. Перетащите их в иерархию, чтобы создать новую анимацию и GameObject.
3. Назовите созданную анимацию Health.anim и сохраните её в папке _Animations.
4. Выберите GameObject Health_ 2 в иерархии и выполните следующие действия:
    - a. Имя: измените имя Health_2 на Health.
    - b. Слой: Установите для параметра «Слой» значение «Элементы» (вверху, справа от тега).
    - c. Трансформация: Установите положение Health на P:[ 28, 7, 0 ].
    - d. Sprite Renderer: в разделе «Дополнительные настройки» установите для параметра «Слой
сортировки» значение «Элементы».
    - e. Добавьте Capsule Collider 2D к Health (его размер должен автоматически подобраться правильно).
    - f. Capsule Collider 2D: установите для параметра «Is Trigger» значение «true» (установите флажок).
    - g. Добавьте компонент «PickUp (Script)» к Health.
    - h. PickUp (Script): Установите для параметра itemType значение Health.
5. Не снимая выделения с GameObject Health в иерархии, откройте панель «Анимация» (Window >
Animation > Animation).
    - a. Установите для анимации Health значение Samples равным 4 (это заставит элемент Health
мигать с приемлемой частотой в четыре кадра в секунду).
    - b. Обязательно нажмите Return (или Enter) после установки значения Samples. Иногда Unity
не принимает значения в текстовых полях, пока вы не нажмете Return.
    - c. Вы можете нажать кнопку «Воспроизвести» на панели «Анимация», чтобы посмотреть, как
мигает индикатор. Если результат вас не устраивает, измените настройки.
6. Перетащите GameObject «Health» из иерархии в папку _Prefabs на панели «Project», чтобы
создать префаб «Health».
7. Сохраните сцену и нажмите «Play».
8. Наведите Дрея на Skeletos пару раз, чтобы получить немного урона. Затем пройдите по
предмету Health, и вы должны восстановить полный круг (т. е. 2 очка) здоровья.

#### Реализация кода для случайного выпадения предметов [!toc]
Выполните следующие шаги, чтобы создать код для случайного появления предметов:  

1. Откройте скрипт Enemy в Visual Studio и внесите изменения в код.  
        Листинг кода Enemy.cs
```c#
public class Enemy : MonoBehaviour {
    …
    void Die() {
        GameObject go;
        if ( guaranteedDrop != null ) {
            go = Instantiate<GameObject>( guaranteedDrop );
            go.transform.position = transform.position;
        } else if ( randomItems.Count > 0 ) { // a
            int n = Random.Range(0, randomItems.Count);
            GameObject prefab = randomItems[n];
            if ( prefab != null) { // b
                go = Instantiate<GameObject>( prefab );
                go.transform.position = transform.position;
            }
        }
        Destroy(gameObject);
    }
}
```
    - a. Если guaranteedDrop отсутствует, а в списке randomItems есть записи, одна из них
будет выбрана и присвоена prefab.
    - b. Предполагается, что в randomItems будет несколько пустых элементов (чтобы предметы не
выпадали каждый раз, когда Дрей убивает врага). Поэтому выполняется проверка на то, является
ли prefab нулевым, и если prefab не нулевой, то создается экземпляр prefab.
2. Сохраните скрипт Enemy и вернитесь в Unity.
3. Выберите экземпляр Skeletos в иерархии и в инспекторе Skeletos (Script):
    - a. Удалите ключ из поля guaranteedDrop, оставив на его месте None (Game Object).
    - b. Откройте треугольник раскрытия рядом с randomItems в инспекторе Skeletos (Script).
    - c. Установите размер randomItems равным 1.
    - d. Присвойте префаб Health (из папки _Prefabs, а не из иерархии) элементу 0 randomItems.
4. Сохраните сцену и нажмите «Play» в Unity.  

Теперь, когда Dray убьет Skeletos, он будет сбрасывать Health PickUp каждые. Однако нам нужно,
чтобы Health сбрасывался только иногда.

>Если вы получили ключ вместо Health, вернитесь и убедитесь, что вы выполнили шаг 3a.  

5. Остановите воспроизведение в Unity.
6. Выберите экземпляр Skeletos в иерархии (в котором вы вносили все эти изменения).
    - a. В верхней части инспектора Skeletos находится кнопка Overrides (которая показана на рисунке *a*, обведенная красным прямоугольником с закругленными углами).
    - b. Нажмите кнопку Overrides и выберите Apply All, чтобы применить все изменения, внесенные
в экземпляр Skeletos, к префабу Skeletos в папке _Prefabs.
7. Выберите префаб Skeletos в папке _Prefabs панели Project (не в иерархии).
    - a. Вы должны увидеть, что все настройки экземпляра Skeletos в иерархии действительно
были применены обратно к этому префабу Skeletos.
    - b. Установите размер randomItems в инспекторе Skeletos (Script) равным 2 и нажмите
Return/Enter.
    - c. Удалите префаб Health из Element 1 (не из Element 0: удалите его из Element 1).
    - d. Установите значение параметра `randomItems` равным 4. Это добавит в `randomItems`
ещё две записи «None (Game Object)» (т. е. null), благодаря чему Skeletos (без параметра
`guaranteedDrop`) будет выпадать «Health» в 1/4 случаев. Окончательный вариант
`randomItems` и другие настройки компонента Skeletos (Script) на префабе Skeletos можно
увидеть на рисунке *b*.  

8. Еще раз выберите экземпляр Skeletos в иерархии, и вы должны увидеть, что эти изменения в
префабе Skeletos были автоматически применены к экземпляру Skeletos в иерархии. Изменение в
префабе не применяется к экземпляру только в том случае, если экземпляр уже переопределяет
это значение в поле.  

>Стоит отметить, что положение и поворот в «Трансформации» экземпляра обрабатываются особым образом: они всегда отображаются жирным шрифтом на экземпляре (как если бы они были переопределениями), но применить их обратно к префабу невозможно.  

Возможно, это показалось вам окольным способом редактирования настроек префаба и экземпляра
Skeletos, но я хотел, чтобы вы немного почувствовали, как изменения в одном могут повлиять на
другое. Я также хотел убедиться, что изменения переопределений, которые мы вносили в экземпляр
Skeletos, были правильно применены обратно к префабу.
