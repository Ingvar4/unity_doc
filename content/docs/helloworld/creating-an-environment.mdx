1. Нажмите Play еще раз, чтобы остановить воспроизведение.
2. В иерархии щелкните всплывающее меню «Создать» (оно выглядит
как «+») и выберите *«3D-объект» > Cube*. Переименуйте этот куб в
*Ground*.
3. Попробуйте переместить «Ground» в положение по оси Y на -4 и
установить его масштаб по осям X и Z равным 10. На протяжении всей
книги я буду указывать положения, повороты и масштабы в этом
формате.  
    **Ground (Cube) P:[ 0, -4, 0 ] R:[ 0, 0, 0 ] S:[ 20, 1, 20 ]**  
    В предыдущей строке:
    - *Ground* - это имя GameObject, а (*Cube*) - тип GameObject (если
это простой тип).
    - P: [ 0 , -4 , 0 ] означает, что положение по оси X устанавливается на 0,
по оси Y - на -4, а по оси Z - на 0.
    - R:[ 0 , 0 , 0 ] означает, что вращения по осям X, Y и Z остаются
равными 0.
    - S : [ 20 , 1, 20 ] означает, что масштаб по оси X установлен на 20, по
оси Y - на 1, а по оси Z - на 20.  

Вы можете либо ввести эти числа в компонент «Transform» объекта
«Ground» на панели «Inspector», либо использовать инструменты и гизмо,
описанные в шаге 4, чтобы внести эти изменения.  

4. Выбрав *Ground* (или любой другой GameObject) в панели «Сцена»
или «Иерархия», вы можете нажать клавиши W, E или R, чтобы
отобразить инструменты, позволяющие перемещать (Translate),
вращать (Rotate) или масштабировать (Scale) GameObject. Эти
инструменты - стрелки, круги и другие элементы, показанные на
рисунке, - можно использовать для изменения
трансформации Ground.  

Вы также можете выбрать эти инструменты, нажав соответствующую
кнопку на панели инструментов, которая появляется в левом верхнем углу
окна Unity

**Инструменты трансформации на панели инструментов Unity**  

Панель инструментов Unity содержит несколько различных инструментов
для изменения трансформации GameObjects. Вы можете выбрать каждый
инструмент, щелкнув кнопку на панели инструментов или нажав
соответствующую клавишу на клавиатуре (когда выбран GameObject).  

- **Инструмент «Рука» (Q)**: См. боковую панель «Изменение вида
сцены» для получения информации об использовании
инструмента «Рука».
- **Инструмент «Перемещение» (W)**: позволяет перемещать GameObject.
При нажатии на красную, зелёную или синюю стрелку-ручку
перемещение будет ограничено только этой осью (например, нажатие
на красную стрелку ограничит перемещение только по оси X). Если
при перемещении удерживать клавишу Command в macOS (или Ctrl в
Windows), объект будет привязываться к сетке. Кнопка правее с
изображением магнита также может использоваться для включения
привязки к сетке.
- **Инструмент «Поворот» (E)**: Поворачивает GameObject. Щелчок по
красному, зеленому или синему дуговому гизмо ограничит поворот
только одной осью (например, щелчок по красной дуге ограничит
поворот только осью X). Удерживая клавишу Command (или Ctrl),
поворот будет привязываться с шагом 15° .
- **Инструмент «Масштаб» (R)**: изменяет масштаб GameObject. Как и
в других инструментах, цветные гизмо ограничивают
масштабирование одной осью. Щелчок по белому кубу посередине
приведет к равномерному масштабированию по всем осям.
- **Инструмент RectTransform (T)**: Инструмент RectTransform
используется в основном для позиционирования элементов
графического интерфейса пользователя (GUI), что вы будете делать в
последующих главах.
- **Инструмент «Трансформация» (Y)**: этот относительно новый
инструмент предоставляет гизмо, которые позволяют перемещать,
вращать или масштабировать с помощью одного инструмента.
- **Инструмент «Редактор»**: Последней кнопкой в первой группе
является инструмент «Редактор», который был добавлен в Unity 2020.
Если выбранный GameObject содержит компонент с пользовательским
гизмо редактора, нажатие на этот инструмент «Редактор» позволит вам
выбрать и использовать любое доступное пользовательское гизмо
редактора (например, когда выбран Ground, инструмент «Редактор»
может активировать гизмо «Edit Box Collider» для изменения
компонента Box Collider объекта Ground).  

<Callout>
Первый инструмент на панели инструментов, показанной на
рисунке — известный как инструмент «Рука» —
используется для управления видом, отображаемым в панели
«Сцена». Панель «Сцена» имеет собственную невидимую камеру
сцены, которая отличается от главной камеры в иерархии.
Инструмент «Рука» обладает несколькими различными
возможностями. Выберите инструмент «Рука» (либо щелкнув по
нему, либо нажав клавишу Q на клавиатуре) и попробуйте следующее:  

- Перетаскивание влево (т. е. щелчок и перетаскивание с
помощью левой кнопки мыши) в панели «Сцена» перемещает
положение камеры сцены влево, вправо, вверх или вниз без
изменения положения каких-либо объектов в сцене. С
технической точки зрения камера сцены перемещается в
плоскости, перпендикулярной направлению, в котором смотрит
камера (т. е. перпендикулярной вектору направления движения
камеры).
- Перетаскивание вправо в панели «Сцена» поворачивает
камеру сцены в направлении перетаскивания. При
перетаскивании вправо камера сцены остается в том же
положении.
- Удерживая клавишу Option в macOS (клавишу Alt на ПК),
курсор над панелью «Сцена» меняет вид с руки на глаз, а
перетаскивание влево с удерживаемой клавишей Option
приводит к вращению вида сцены вокруг объектов на панели
«Сцена». Это называется вращением камеры вокруг сцены. При
вращении
меняется положение камеры сцены, но не меняется точка обзора
камеры.
- Прокрутка колесиком мыши приводит к увеличению и
уменьшению масштаба сцены камерой. Вы также можете
изменять масштаб, удерживая клавишу Option и перетаскивая
курсор вправо в панели «Сцена».  

Лучший способ освоить инструмент «Рука» — попробовать
перемещаться по сцене, используя различные методы, описанные в
этой боковой панели. После того как вы немного попрактикуетесь,
это станет для вас привычным делом.
</Callout>

Не стесняйтесь поэкспериментировать с этим и добавьте больше объектов,
включая сферы, капсулы и другие кубы (как показано на рисунке).
Попробуйте изменить вращение и масштаб объектов. Экземпляры
«Cube Prefab» будут отскакивать от этих статических объектов, которые
вы поместили в сцену. Пока вы не добавите Rigidbody ни к одной из новых
фигур, они они должны оставаться статичными (т. е. твердыми и неподвижными).
Когда закончите, не забудьте сохранить сцену!  

>Когда вы масштабируете Cube, Box Collider на нем масштабируется правильно вместе с ним;
однако, если вы масштабируете Sphere или Capsule неравномерно (т. е. если масштабы по осям X,
Y и Z не одинаковы), то коллайдер может не смочь правильно соотнестись с новым масштабом
Sphere или Capsule. Это связано с тем, как работают столкновения, и просто нужно иметь это в
виду. Попробуйте масштабировать сферу до S: [ 1, 4, 1 ], а затем выделите её, чтобы понять, о чём
я говорю. Когда сфера будет выделена, вы увидите, что зелёный коллайдер сферы по-прежнему
масштабируется равномерно, хотя графика сферы масштабируется неравномерно.

### Добавление цвета [!toc]

Последнее интересное занятие, которое требует немного больше кода, но
доставляет много удовольствия, — это добавление случайного цвета к
экземплярам CubePrefab. Для этого:

1. Откройте скрипт CubeSpawner в Visual Studio.
2. Замените существующий код `Update()` следующими
строками:

```c#
void Update()
{
    // Instantiate( cubePrefabVar ); // Use // to comment out this line!
    GameObject cubeGO = Instantiate<GameObject>(cubePrefabVar);
    Material mat = cubeGO.GetComponent<Renderer>().material;
    mat.color = Random.ColorHSV( 0, 1, 0.5f, 1, 0.75f, 1);
}
```

Я не хочу слишком долго останавливаться на том, что делает этот код, но
вкратце можно сказать, что функция `cubeGO` сохраняет ссылку на новый
экземпляр `CubePrefab`, создаваемый в каждом кадре. Затем мы присваиваем
материал (Material) рендерера (Renderer) этого нового экземпляра
`CubePrefab` переменной `mat` с помощью функции `Random.ColorHSV()`. После этого мы
устанавливаем для `mat` новый случайный цвет.

>Функция Random.ColorHSV() использует цветовую модель Hue, Saturation, Value (или HSV).
Аргументы, которые мы передаем в функцию, указывают ей, что оттенок должен быть в
диапазоне от 0 до 1, насыщенность — от 0.5f до 1, а яркость — от 0.75f до 1. Для получения
дополнительной информации вы можете обратиться к
https://docs.unity3d.com/2020.2/Documentation/ScriptReference/Random.ColorHSV.html.  

3. Сохраните CubeSpawner в Visual Studio и вернитесь в Unity.
4. Нажмите «Play».
5. Как всегда, сохраните сцену.
