---
title: Создание нового скрипта на C#
description: Пришло время. Теперь вы напишете свой первый фрагмент кода.
---

1. Нажмите кнопку *«Создать»* (Create), которая выглядит как знак «+»,
в панели «Проект» (Project) и выберите «Скрипт C# » (Script (меню «+»
обведено красным прямоугольником на рисунке). Это добавит
новый скрипт в папку Assets панели Project, и его имя автоматически
будет выделено, чтобы вы могли его изменить.

<img src="/unity_doc/images/example2.jpeg" alt="1" style={{  height: 'auto' }} />

2. Назовите этот скрипт *HelloWorld* (убедитесь, что между двумя словами
нет пробела) и нажмите Return, чтобы установить имя.
На протяжении всей книги я упоминаю файлы скриптов по их полному
имени с расширением (например, HelloWorld.cs), но в Unity вы не
увидите этого расширения. В Unity файл скрипта C# HelloWorld.cs
будет отображаться как *HelloWorld* с иконкой C# рядом.
3. Дважды щелкните имя или значок скрипта HelloWorld (в панели
Project), чтобы запустить Visual Studio - наш редактор C#.
4. Щелкните мышью по строке 10, чтобы установить курсор в этом
месте, и введите код print("Hello World"); в строку 10
вашего скрипта в Visual Studio, как показано на рисунке. Убедитесь, что все слова написаны правильно, с
соблюдением регистра, и что в конце строки стоит точка с запятой (;).

Теперь ваш скрипт HelloWorld должен выглядеть точно так же, как в
листинге кода. Во всех листингах кода всё, что вам
нужно ввести, выделено жирным шрифтом, а уже имеющийся код -
обычным.  

Каждая строка в приведенном ниже коде также имеет номер строки,
стоящий перед ней. Как видно на рисунке, Visual Studio
автоматически показывает номера строк вашего кода, поэтому вам не
нужно вводить их самостоятельно. Номера строк приведены
только для того, чтобы облегчить чтение листингов кода.  

**Code Listing** HelloWorld.cs:

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class HelloWorld : MonoBehaviour
{
    // Start is called before the first frame update
    void Start()
    {
      print("Hello World!");
    }

    // Update is called once per frame
    void Update()
    {

    }
}
```

5. Сохраните этот скрипт, выбрав *«Файл» > «Сохранить»* в строке
меню Visual Studio и вернитесь в Unity (в Windows вы увидите
*«Файл» > «Сохранить HelloWorld.cs»*).
6. Щелкните и удерживайте курсор на названии скрипта HelloWorld в
панели «Проект», перетащите его на объект *Main Camera* в панели
«Иерархия» сцены и отпустите кнопку мыши, как показано на рисунке. При перетаскивании скрипта в macOS надпись «HelloWorld
(MonoScript)» будет следовать за курсором, а после отпускания кнопки
мыши над *Main Camera* надпись «HelloWorld (MonoScript)» исчезнет.
При перетаскивании скрипта в Windows вы увидите кружок с косой
чертой, пока не дойдете до GameObject, к которому можно прикрепить
скрипт, после чего курсор превратится в прямоугольник со стрелкой (в
Windows название не следует за курсором). После этого появится
звездочка, которую я выделил красным прямоугольником на рисунке, чтобы показать вам, что необходимо сохранить сцену.

<img src="/unity_doc/images/HelloWorldYourFirstProgram2.jpeg" alt="1" style={{  height: 'auto' }} />

7. Сохраните сцену, выбрав *File > Save* в главном меню Unity.
После этого звездочка исчезнет.

<Callout>
Перетаскивание скрипта HelloWorld на Main Camera привязывает скрипт к
Main Camera в качестве компонента. Все объекты, отображаемые в панели
«Иерархия» сцены (например, Main Camera), называются GameObjects, а
GameObjects состоят из компонентов.
</Callout>

8. Щелкните *Main Camera* на панели «Иерархия», и вы должны
увидеть HelloWorld (Script) в списке компонентов Main Camera на
панели «Инспектор».  

Как видно на рисунке, панель «Инспектор» показывает несколько
компонентов Main Camera, включая компоненты Transform, Camera, Audio
Listener и HelloWorld (Script). В последующих главах GameObjects и
компоненты будут рассмотрены гораздо подробнее.

<img src="/unity_doc/images/HelloWorldYourFirstProgram3.jpeg" alt="1" style={{  height: 'auto' }} />

9. Нажмите кнопку «Play» (треугольник, обращенный вправо, в верхней
части окна Unity) и наблюдайте за волшебством!

Скрипт вывел надпись Hello World! в панель «Консоль», как показано на
рисунке. Обратите внимание, что он также вывел надпись «Hello World!» на
небольшую серую полосу в левом нижнем углу экрана. Возможно, это не
самое волшебное событие в вашей жизни, но с чего-то же надо начинать.
Как однажды сказал один мудрый старик: «Вы сделали первый шаг в
большой мир».

<img src="/unity_doc/images/HelloWorldYourFirstProgram4.jpeg" alt="1" style={{  height: 'auto' }} />

> «Hello World» выведено в панель консоли. При нажатии на сообщение оно выделяется синим цветом, и в нижней половине консоли отображается дополнительная информация.

10. Нажмите кнопку «Play» в Unity еще раз, чтобы выйти из режима
воспроизведения.
