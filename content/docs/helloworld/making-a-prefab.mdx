---
title: Создание префаба (Prefab)
description: Пришло время превратить «Cube» в Prefab.
---

Префаб - это многоразовый
элемент проекта, который можно создавать (клонировать) любое количество
раз. Можно представить себе префаб как форму для GameObject, и каждый
GameObject, созданный из этого префаба, называется экземпляром префаба
(instance of the prefab). Чтобы создать префаб, щелкните
Cube на панели Hierarchy, перетащите его на панель Project и отпустите
кнопку мыши.

<img src="/images/example5.jpeg" alt="1" style={{  height: 'auto' }} />

Вы увидите, что произошло несколько вещей:
- В панели Project был создан префаб с именем *Cube*. О том, что это
префаб, можно судить по синему значку в виде куба рядом с ним.
(Значок префаба всегда представляет собой куб, независимо от
формы самого префаба.)
-  Имя GameObject «Cube» в иерархии стало синим. Если у GameObject в
иерархии синее имя, это означает, что этот GameObject является
экземпляром префаба (то есть копией, созданной по шаблону
префаба).

Для ясности переименуйте префаб Cube в панели Project в Cube Prefab.

1. Щелкните один раз по префабу *«Cube»* в панели «Project», чтобы
выбрать его. Затем щелкните второй раз, чтобы переименовать его
(вы также можете нажать клавишу Return (macOS) или F2 (Windows)
после выбора, чтобы переименовать его), и измените название на
*«Cube Prefab»*.
2. Теперь, когда префаб настроен, вам больше не нужен экземпляр *Cube* в
сцене. Щелкните Cube в панели Hierarchy (не в панели Project!).
Выберите *Edit > Delete* в строке меню; куб исчезнет
из вашей сцены.
3. Сохраните сцену, выбрав *File > Save* в главном меню Unity.
4. Выберите *Assets > Create > C# Script* в главной панели меню и
переименуйте вновь созданный скрипт в *CubeSpawner* (убедитесь,
что в названии две заглавные буквы и нет пробелов).
5. Дважды щелкните скрипт *CubeSpawner*, чтобы открыть Visual Studio, и
добавьте выделенный жирным шрифтом код, показанный в листинге.

Листинг CubeSpawner.cs

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class CubeSpawner : MonoBehaviour
{
    public GameObject cubePrefabVar;

    // Start вызывается перед обновлением первого кадра
    void Start()
    {
        Instantiate( cubePrefabVar );
    }

    // Update вызывается один раз за кадр
    void Update()
    {

    }
}
```

6. Сохраните скрипт CubeSpawner в Visual Studio (*Файл > Save*) и
вернитесь в Unity.
7. Как и в случае с предыдущим скриптом, вы должны прикрепить этот
скрипт к GameObject в сцене, чтобы код этого скрипта был выполнен.
В Unity перетащите скрипт *CubeSpawner* на Main Camera.
8. Щелкните Main Camera на панели Hierarchy. Вы увидите, что к
GameObject Main Camera добавлен компонент Cube Spawner
(Script).

<img src="/images/example6.jpeg" alt="1" style={{  height: 'auto' }} />

В этом компоненте также можно увидеть переменную с именем *Cube
Prefab Var* (хотя на самом деле она должна называться cubePrefabVar). Это связано с оператором
`public GameObject cubePrefabVar;`, который вы ввели в строке 7.
В общем случае, если переменная скрипта помечена как `public`, она
будет отображаться в панели Inspector.  

9. Как видно в инспекторе, переменной `cubePrefabVar` в данный
момент не присвоено никакого значения. Щелкните по круглой
мишени справа от значения переменной `cubePrefab`, чтобы открыть диалоговое окно
*«Select GameObject»*, в котором можно выбрать префаб для присвоения
этой переменной.
    - Убедитесь, что выбрана вкладка A вкладка «Assets» (Ассеты)
выбрана. (На вкладке «Assets» отображаются GameObjects в панели
«Project», тогда как на вкладке «Scene» — в иерархии.)
    - Дважды щелкните Cube Prefab, чтобы выбрать его

<img src="/images/ex1.jpeg" alt="1" style={{  height: 'auto' }} />
Выбор Cube Prefab для переменной cubePrefabVar скрипта CubeSpawner  

10. Теперь в инспекторе видно, что значением `cubePrefabVar` является
*Cube Prefab* (а выбор его на вкладке Assets гарантировал, что это
именно тот префаб, что и в панели Project). Чтобы перепроверить это,
щелкните значение *Cube Prefab* в инспекторе, и вы увидите, что
*Cube Prefab* выделен желтым цветом в панели Project.
11. Нажмите кнопку *«Play»*. Вы увидите, что в иерархии создана одна
инстанция GameObject *«Cube Prefab(Clone)»*. Так же, как вы видели в сценарии Hello World, функция `Start()` вызывается один раз и создает один экземпляр (или клон) Cube Prefab.
12. Переключитесь в Visual Studio и отредактируйте код, как показано в
листинге кода
    - Закомментируйте вызов `Instantiate( cubePrefabVar )` в
строке 12 функции `Start()`.
    - Добавьте оператор `Instantiate( cubePrefabVar );` в строку
18 функции `Update()`.  

Листинг CubePrefabVar.cs

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class CubeSpawner : MonoBehaviour
{
    public GameObject cubePrefabVar;

    // Используйте это для инициализации
    void Start()
    {
        // Instantiate( cubePrefabVar );
    }

    // Update вызывается один раз за кадр
    void Update()
    {
        Instantiate( cubePrefabVar );
    }
}
```

13. Сохраните скрипт CubeSpawner и вернитесь в Unity.
14. Сохраните сцену, а затем нажмите «Play». Как показано на рисунке, в результате вы получите множество кубов. Вероятно, вам понадобится уменьшить масштаб в окне «Scene», чтобы увидеть то же,
что показано на рисунке. Для этого поместите указатель мыши в панели «Scene» и воспользуйтесь колесиком прокрутки.

>Возможно, вы задаетесь вопросом, почему эти кубики разлетаются по всему пространству, а
не падают прямо вниз. Если да, то это хороший вопрос! Это происходит потому, что кубики
появляются прямо друг на друге, и физическая система PhysX решает, что ей нужно
раздвинуть их друг от друга (поскольку коллайдеры Unity не должны занимать одно и то же пространство), поэтому она придает им скорость, заставляющую их быстро удаляться
друг от друга.
