Теперь попробуем перенести вызов функции **print()** из метода **Start()** в **Update()**.

1. Вернитесь в Visual Studio и отредактируйте код, как показано в
листинге.

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class HelloWorld : MonoBehaviour
{
    // Start is called before the first frame update
    void Start()
    {
    // print("Hello World!"); // This line is now ignored.
    }

    // Update is called once per frame
    void Update()
    {
        print("Hello World!");
    }
}
```

>Добавление двух косых черт (//) в начало 10-й строки преобразует всё в 10-й строке, что следует за косыми чертами, в комментарий. Комментарии полностью игнорируются компьютером и используются либо для отключения кода (как вы сейчас делаете со строкой 10), либо для оставления сообщений другим людям, читающим код (как вы можете видеть в строках 7 и 13). Добавление двух косых черт перед строкой (как вы сделали со строкой 10) называется закомментированием строки.

2. Сохраните скрипт (заменив исходную версию) и попробуйте снова
нажать кнопку «Play».

Вы увидите, что *Hello World!* теперь выводится много-много раз в быстрой
последовательности. Вы можете снова нажать кнопку
«Play», чтобы остановить выполнение, и увидите, что Unity перестанет
генерировать сообщения Hello World!

<img src="/unity_doc/images/example3.jpeg" alt="1" style={{  height: 'auto' }} />

<Callout type='idea'>
**Update()** вызывает вывод «Hello World!» один раз в каждый кадр.
</Callout>

**Start()** и **Update()** - это специальные функции в версии языка C#,
используемой в Unity. **Start()** вызывается один раз в первом кадре,
когда объект появляется, тогда как **Update()** вызывается в каждом
кадре, отсюда и отличие в количестве сообщений. В Unity есть целый список таких
специальных функций, которые вызываются в разное время.

<Callout type='idea'>
Кадр возникает каждый раз, когда Unity перерисовывает экран, что обычно происходит от 30 до 600 раз в секунду.
</Callout>

### Сделаем программу интереснее [!toc]

Теперь пришло время добавить в вашу первую программу больше стиля
Unity. В этом примере вы создадите множество копий куба. Каждая из этих
копий куба будет независимо от других отскакивать и реагировать на
физику. Это упражнение демонстрирует как скорость работы Unity, так и
простоту, с которой она позволяет создавать контент.  

Начните с отключения скрипта HelloWorld на Main Camera:  

1. Выберите Main Camera в панели Hierarchy.
2. Снимите флажок слева от названия компонента *HelloWorld*
(Script) в панели Inspector (щелкнув по нему). Это называется
отключением скрипта, и оно останавливает вызов методов `Start()` и
`Update()` в скрипте HelloWorld; если теперь вы нажмете Play, вы
больше не увидите сообщение Hello World! в консоли. Однако перед
тем, как перейти к шагу 3, необходимо остановить воспроизведение.
3. Выберите *«GameObject» > 3D Object > Cube* в главной
панели меню Unity, чтобы разместить GameObject с именем Cube в
панели «Сцена» (и в панели «Иерархия»). У вас появится возможность
переименовать куб, но вы можете просто щелкнуть по фону панели
«Иерархия», чтобы выйти из режима переименования.

<Callout>
Если куб трудно разглядеть в панели «Сцена», попробуйте дважды
щелкнуть его строку в панели «Иерархия» — это должно сфокусировать
сцену на кубе. Для получения дополнительной информации прочтите
боковую панель «Изменение вида сцены» далее в этой главе, где
рассказывается о том, как управлять видом панели «Сцена».
</Callout>

4. Щелкните по Cube в панели «Иерархия», и вы должны увидеть, что он
выделен оранжевой рамкой в панели «Сцена». Его компоненты также
появятся в панели «Инспектор». Основное назначение
панели «Инспектор» — дать вам возможность просматривать и
редактировать компоненты, составляющие любой GameObject. Этот
GameObject Cube имеет компоненты Transform, Mesh Filter, Box
Collider и Mesh Renderer:

<img src="/unity_doc/images/example4.jpeg" alt="1" style={{  height: 'auto' }} />

*Новый GameObject «Cube», видимый в панелях «Scene» и «Hierarchy»*  

- **Transform**: компонент Transform задает положение, поворот и
масштаб GameObject. Это единственный компонент, который
необходим в каждом GameObject.
- **Cube (Mesh Filter)**: Компонент Mesh Filter придает GameObject его
трехмерную форму, которая моделируется как сетка, состоящая из
треугольников. 3D-модели в играх, как правило, представляют собой
поверхность, которая внутри полая. В отличие от настоящего яйца
(которое заполнено желтком и белком), 3D-модель яйца будет просто
сеткой, имитирующей пустую яичную скорлупу. Компонент Mesh
Filter привязывает 3D-модель к GameObject. В случае с Cube
компонент Mesh Filter использует простую 3D-модель куба,
встроенную в Unity, но вы также можете импортировать сложные 3D-
модели в панель Project, чтобы добавить в игру более сложные сетки.
- **Box Collider**: Компоненты Collider позволяют GameObject
взаимодействовать с другими объектами в физической симуляции,
запускаемой Unity. Физический движок PhysX в Unity использует
несколько различных видов коллайдеров, включая Sphere, Capsule, Box и Mesh (в порядке
возрастания вычислительной сложности; то есть вычисление Mesh
Collider для компьютера гораздо сложнее, чем Box Collider).
GameObject с компонентом коллайдера (и без компонента Rigidbody)
действует как неподвижный объект в пространстве, в который могут
врезаться другие GameObjects.
- **Mesh Renderer**: в то время как Mesh Filter предоставляет
фактическую геометрию GameObject, компонент Mesh Renderer
делает эту геометрию видимой. Без рендерера в Unity на экране
ничего не отобразится. Рендереры работают с Main Camera,
преобразуя 3D-геометрию Mesh Filter в пиксели, которые вы
фактически видите на экране.
- **Default–Material (Material)**: на самом деле это не компонент. Скорее,
это небольшой редактор, который показывает вам детали материала,
прикрепленного к MeshRenderer (под треугольником раскрытия
«Materials»). Default–Material не поддается редактированию, но если
бы вы прикрепили другой материал к Mesh Renderer этого куба, вы
могли бы отредактировать его здесь. Обратите внимание, что его
редактирование здесь приведет к изменению для всех GameObjects,
которые его используют, а не только для этого куба.

5. Посмотрите на компонент Transform в инспекторе и убедитесь, что все
поля X, Y и Z Position установлены на 0 (как показано на рисунке).
Unity добавляет новые GameObjects в текущий центр окна просмотра
сцены, который часто не совпадает с точкой [0, 0, 0], поэтому мне часто
приходится сбрасывать эти координаты при первом добавлении
GameObject. Если после этого изменения вы больше не видите куб,
просто дважды щелкните его имя в иерархии. Вы также можете
сбросить положение, поворот и масштаб
любого Transform, щелкнув три вертикальные точки ( ⋮ ) в правом
верхнем углу компонента Transform и выбрав Reset из
всплывающем меню.

6. Вы добавите еще один компонент к этому GameObject: *Rigidbody*.
Не снимая выделения с Cube в иерархии, выберите *Component >
Physics > Rigidbody* в панели меню (убедитесь, что
вы выбрали Physics > Rigidbody, а не Physics 2D >
Rigidbody 2D), и вы увидите, что в Inspector добавлен компонент
Rigidbody:

- **Rigidbody**: Компонент Rigidbody сообщает Unity, что вы хотите,
чтобы для этого GameObject симулировалась физика. Сюда входят
такие физические силы, как гравитация, трение, столкновения и
сопротивление. Rigidbody позволяет GameObject с компонентом Collider перемещаться в
пространстве. Без Rigidbody, даже если GameObject перемещается
путем изменения его трансформации, компонент Collider этого
GameObject не будет двигаться надежно (хотя объект будет казаться
движущимся). Вам следует прикрепить компонент Rigidbody к
любому GameObject, который вы хотите как перемещать, так и
правильно сталкивать с другими коллайдерами.

7. Нажмите кнопку «Play», и после короткой паузы, пока Unity
готовится к запуску, коробка упадет под действием силы тяжести.

    Все физические симуляции в Unity основаны на метрической системе. Это означает, что:
    - 1 единица расстояния = 1 метр (например, единицы измерения
для Position в Transform).
    - 1 единица массы = 1 килограмм (например, единицы измерения Mass в Rigidbody).
    - По умолчанию ускорение свободного падения составляет –9,8 = 9,8 м/с² в направлении вниз (отрицательная ось y).
    - Средний рост персонажа-человека составляет около 2 единиц (2 метра).

8. Нажмите кнопку «Play» еще раз, чтобы остановить симуляцию.

В вашей сцене уже есть направленный свет. Именно поэтому коробка так
ярко освещена, а небо голубое. На данный момент это все, что вам нужно.
Вы узнаете больше о различных типах освещения в последующих главах.
