---
title: Attractor GameObject
description: Далее мы создадим GameObject «Attractor». Attractor - это объект, к которому стремятся все Boids. Без него они бы слетались друг с другом, но стая в целом улетела бы за пределы экрана.
---

1. В панели меню Unity выберите *GameObject > 3D Object > Sphere*, чтобы создать
новую сферу.
2. Переименуйте эту сферу в Attractor.
3. Выберите Attractor и настройте его Transform, как показано на рисунке:

<img src="/unity_doc/images/ex28.jpeg" alt="1" style={{  height: 'auto' }} />
Настройки GameObject «Attractor»  

- Attractor Transform: P:[ 0, 0, 0 ] R:[ -90, 0, 0 ] S:[ 4, 4, 0.1 ]  

Поворот на –90 вокруг оси X выравнивает локальную ось Z объекта «Attractor» с глобальной осью
Y, которую мы будем использовать в шаге 5d.  

4. На панели Inspector для Attractor удалите компонент Sphere Collider, щелкнув три
вертикальные точки ( ⋮ ) в правом верхнем углу компонента Sphere Collider и
выбрав Remove Component из всплывающего меню.
5. В строке меню Unity выберите *«Component» > «Effects» > «Trail Renderer»*. В компоненте
«Trail Renderer» инспектора «Attractor» выполните следующие действия (как показано на
рисунке):  

    - a. В разделе «Width» компонента «Trail Renderer»:
        - Измените максимальную ширину с 1 на 0,5 (под курсором мыши на рисунке). Это
устанавливает максимальную ширину следа.
        - Дважды щелкните по правому концу красной линии. Это создаст новую конечную точку.
        - Щелкните и перетащите эту конечную точку в правый нижний угол графика
Width. Это создаст сужающуюся линию Trail Renderer, которая будет выглядеть
красиво.

    - b. Установите значение «Time» компонента Trail Renderer равным 4.
    - c. Установите для параметра «Выравнивание» (Alignment) Trail Renderer значение
«Трансформировать по Z» (Transform Z). Это приведет к тому, что многоугольники,
составляющие след, будут перпендикулярны локальной оси Z Attractor. Поскольку
локальная ось Z направлена вверх (параллельно глобальной оси Y), след будет лежать плоско, чтобы
соответствовать максимальным размерам сферы Attractor.  

    - d. Щелкните треугольник раскрытия рядом с «Materials», чтобы открыть этот раздел, и в нем:
        - Щелкните маленький кружок с точкой справа от «Element 0 None (Material)».
        - Выберите «Default-Line» из появившегося списка материалов.  

    - e. В разделе «Освещение»:
        - Установите для параметра «Cast Shadows» значение «Выкл.».
        - Установите для параметра «Принимать тени» значение «false» (не отмечено).  
    - f. Щелкните образец (т. е. белый прямоугольник) справа от «Color», и вы увидите, что на
самом деле это градиент, и откроется окно «Редактор градиентов».  

6. Нам нужно, чтобы след «Аттрактора» плавно исчезал со временем и расстоянием. Во
всплывающем окне «Редактор градиента» выполните следующее:
    - a. Щелкните по верхнему левому пятиугольному маркеру (под курсором мыши и
обведенному синим). Эти верхние маркеры задают значение альфа
градиента, тогда как нижние - цвет.
    - b. Выбрав верхний левый маркер, установите значение альфа на ползунке равным 127 (что
составляет половину максимального значения, 255), чтобы задать началу следа
непрозрачность 50%.
    - c. Выберите правый верхний маркер.
    - d. Установите значение альфа на ползунке равным 0, чтобы задать непрозрачность конца следа
равной 0% (т. е. полностью прозрачным).
    - e. Убедитесь, что для параметра «Режим» градиента выбран вариант «Blend», и
закройте окно «Gradient Editor».  

Когда вы закончите с шагом 6, настройки компонента «Trail Renderer» вашего аттрактора
должны выглядеть, как показано на рисунке. Теперь вы можете использовать инструмент
«Move», чтобы перетаскивать аттрактор по сцене, и след должен выглядеть так же, как
на рисунке. Обратите внимание, что я показываю гизмо локальных осей (выделено
красным прямоугольником) для Attractor (а не гизмо глобальных осей, которое я использую почти
всегда), чтобы продемонстрировать, как локальная ось Z Attractor (синяя стрелка) совмещена с
глобальной осью Y. Если вы это сделаете, не забудьте переключить его обратно на «Глобальный».
Я рекомендую, чтобы эти две кнопки рядом с панелью инструментов Unity всегда были
установлены в положение «Pivot» и «Global».  

7. Сохраните сцену.
