### Создание простой модели Boid [!toc]

Чтобы создать модель для каждого Boid, мы построим что-то из комбинации вытянутых
кубов. Когда работа будет завершена, префаб GameObject Boid будет похож на тот, что
показан на рисунке:

<img src="/unity_doc/images/ex23.jpeg" alt="1" style={{  height: 'auto' }} />
Простая модель отдельного Boid, вид с четырех разных ракурсов. Выполните
следующие шаги:  

1. Выберите *GameObject > Create Empty* в панели меню Unity.  

    - a. Переименуйте новый GameObject в Boid.  

    - b. Щелкните по фону панели «Hierarchy», чтобы отменить выделение Boid.  

2. Выберите *GameObject > Create Empty* в панели меню Unity.  

    - a. Переименуйте этот GameObject в Fuselage.  

    - b. Щелкните и удерживайте кнопку мыши на Fuselage и перетащите Fuselage на
Boid в панели Hierarchy.  

Таким образом Fuselage становится дочерним объектом Boid. Рядом с Boid появляется новый
треугольник раскрытия, щелкнув по которому можно отобразить дочерние объекты Boid. При раскрытом треугольнике ваша иерархия должна
выглядеть, как показано на рис.

<img src="/unity_doc/images/ex24.jpeg" alt="1" style={{  height: 'auto' }} />
Вложение GameObjects в иерархии (т. е. превращение одного в дочерний объект
другого)  

3. Щелкните правой кнопкой мыши по Fuselage и выберите *3D Object > Cube* из
появившегося всплывающего меню. Это создаст новый объект Cube в качестве
дочернего элемента Fuselage (если он не появится под Fuselage, вам следует
перетащить Cube под Fuselage вручную).
4. Как показано на рисунке, настройте трансформации Fuselage (a) и Cube (b) в
соответствии с приведенными ниже значениями.

<img src="/unity_doc/images/ex25.jpeg" alt="1" style={{  height: 'auto' }} />

Настройки трансформации для «Фюзеляжа» и его дочернего объекта «Куб»  

- Fuselage Transform: P:[ 0, 0, 0 ] R:[ 7.5, 0, 0 ] S:[ 0.5, 0.5, 2 ]
- Cube Transform: P:[ 0, 0, 0 ] R:[ 45, 0, 45 ] S:[ 1, 1, 1 ]  

Сочетание масштабирования и поворота родительского объекта Fuselage приводит к тому, что
дочерний объект Cube принимает обтекаемую форму (вы можете повернуть вид, чтобы это
увидеть).  

5. Выберите куб в разделе «Fuselage» и удалите компонент «Box Collider»:
    - a. В правом верхнем углу компонента «Box Collider» в инспекторе нажмите на три точки ( ⋮ )
и выберите «Remove Component» (Удалить компонент) из всплывающего меню.  

Это удалит Box Collider с куба, что позволит другим объектам проходить сквозь него. Еще одна
причина для удаления коллайдера заключается в том, что коллайдеры не растягиваются так же,
как кубы, поэтому физические границы коллайдера не будут совпадать с визуальными
размерами куба.  

6. Выберите Fuselage в иерархии:
    - a. Выберите *«Edit» > «Duplicate»* в панели меню. В иерархии должен появиться второй
объект «Fuselage» с именем «Fuselage (1)» в качестве дочернего элемента «Boid».
>Мы используем здесь «Дублировать», а не создаем новый объект, по нескольким причинам: 1) настройки
«Трансформации» для «Крыла» будут очень похожи на настройки «Фюзеляжа», и 2) дублированный дочерний
объект «Куб» уже настроен именно так, как нам нужно (включая как настройки «Трансформации», так и удаление
компонента «Box Collider»).
    - b. Переименуйте GameObject Fuselage (1) в Wing.
    - c. Установите для «Wing» следующие значения «Transform», как показано на рисунке.
Значения, которые необходимо изменить, выделены жирным шрифтом.

<img src="/unity_doc/images/ex26.jpeg" alt="1" style={{  height: 'auto' }} />
Настройки трансформации для Wing и Main Camera  

- Wing Transform: P:[ 0, -0.125, 1 ] R:[ 7.5, 0, 0 ] S:[ 2, 0.2, 1 ]  

7. Выберите Main Camera в иерархии и установите для Main Camera следующие значения
трансформации, как показано на рисунке. Это даст Main Camera удаленный ракурс,
который позволит нам видеть много Boids одновременно.
    - Main Camera Transform: P:[ 0, 20, -80 ] R:[ 0, 0, 0 ] S:[ 1, 1, 1 ]  

8. Когда вы убедитесь, что ваша модель Boid выглядит так же, как на рисунке, сохраните
сцену, выбрав *«File > Save»* в главном меню Unity (это удалит звездочку рядом с именем
*_Scene_0* в иерархии).
9. Создайте материал, чтобы сформировать след за каждым Boid, когда он движется в
пространстве. Вы можете увидеть окончательную версию настроек для этого Mat_Boid_Trail
на последующем рисунке (с выделенными значениями, которые вам нужно изменить).
        - a. В панели меню Unity выберите *Assets > Create > Material*.
        - b. Назовите новый материал *Mat_Boid_Trail*.
        - c. Выберите *Mat_Boid_Trail* на панели Project, а в верхней части панели Inspector выберите
*Particles > Standard Unlit* в раскрывающемся меню *Shader*.
        - d. В панели «Инспектор» в разделе «Blending options» установите для параметра «Rendering Mode» значение «Additive».  

10. Щелкните Boid на панели «Иерархия», чтобы выделить его.
11. Выберите *Component > Effects > Trail Renderer* в панели меню. Это
добавит компонент «Trail Renderer» к Boid. Вы можете увидеть окончательные настройки компонента «Trail Renderer» на последующем рисунке, где выделены элементы, которые необходимо изменить. Для внесения этих
изменений выполните следующие действия:  

    - a. Установите максимальную ширину Trail Renderer равной 0, 25. Это устанавливает максимальную ширину следа. (Если ваш Инспектор
довольно узкий, Unity может отобразить это значение, округленное до 0,3, но на самом
деле оно по-прежнему будет 0,25.)

<img src="/unity_doc/images/ex27.jpeg" alt="1" style={{  height: 'auto' }} />
Настройки инспектора для Mat_Boid_Trail и компонентов Trail Renderer, Sphere
Collider и Rigidbody объекта Boid. Любое значение, которое необходимо изменить, выделено,
в то время как остальные неизменённые значения слегка затемнены.  

    - b. Установите значение Time для Trail Renderer равным 1.
    - c. Щелкните треугольник раскрытия рядом с Materials, чтобы открыть его.
    - d. Щелкните кружок с точкой ( ⊙ ) справа от Element 0 None (Material).
    - e. Выберите только что созданный нами Mat_Boid_Trail из появившегося списка материалов.
    - f. В разделе «Освещение»(Lighting):  

        - Установите для параметра «Cast Shadows» значение «off».
        - Установите для параметра «Receive Shadows» значение «false» (не отмечено галочкой).
        >Эта настройка, вероятно, не нужна; поскольку мы используем шейдер Unlit для материала Mat_Boid_Trail, он, скорее всего, все равно игнорировал бы тени.  

Теперь, если вы используете инструмент «Move» для перемещения Boid в окне «Scene», он
должен оставлять след. (Убедитесь, что вы выбрали Boid, а не какой-либо из его дочерних
объектов; иногда, если вы щелкаете непосредственно на GameObject в панели «Сцена», вы выберете крыло или фюзеляж вместо Boid.)  

12. Пока Boid все еще выделен в иерархии, в панели меню Unity выберите *Component >
Physics > «Sphere Collider»*. Это добавит к Boid компонент
«Sphere Collider». (Обратите внимание: если вы оставили след с помощью Trail
Renderer, «Sphere Collider» по умолчанию может быть масштабирован так,
чтобы включать этот след.)
13. Окончательные настройки Sphere Collider показаны на рисунке. В компоненте
Sphere Collider инспектора Boid:
    - a. Установите для параметра Is Trigger значение true (флажок установлен).
    - b. Установите для параметра Center значение [ 0, 0, 0 ].
    - c. Установите Radius равным 4 (это значение будет скорректировано позже с помощью кода).  

14. Пока элемент «Boid» по-прежнему выделен в иерархии, в панели меню Unity выберите
*(Component > Physics > Rigidbody)*. (Убедитесь, что вы выбрали Physics > Rigidbody, а не
Physics 2D > Rigidbody 2D.)
15. В компоненте Rigidbody инспектора Boid обязательно установите для параметра Use
Gravity значение false (не отмечено). Окончательные настройки Rigidbody показаны на
рисунке.  

На следующем шаге этот единственный GameObject Boid превращается в префаб, из которого
можно создать сотни экземпляров GameObject.  

16. Перетащите Boid из панели Hierarchy в панель Project, что создаст префаб с именем
Boid.
17. Удалите синий экземпляр Boid из панели Hierarchy. Теперь, когда у вас есть префаб
Boid в панели Project, Boid в панели Hierarchy больше не нужен.
18. Выберите *GameObject > Create Empty* в строке меню.
    - a. Переименуйте этот новый GameObject в BoidAnchor.
    - b. Убедитесь, что трансформация BoidAnchor центрирована в точке P:[ 0, 0, 0 ] с поворот и
масштаб по умолчанию, щелкнув три вертикальные точки ( ⋮ ) в правом верхнем
углу компонента «Трансформация» в инспекторе и выбрав «Сброс» в всплывающем меню.  

Этот пустой GameObject BoidAnchor будет выступать в качестве родителя для всех экземпляров
Boid, добавляемых в сцену, что позволит максимально очистить панель «Иерархия».  

19. Сохраните сцену! Вы внесли много изменений, и я не хотел бы, чтобы вы потеряли
всю эту работу.
