---
title: Ловля яблок
description: Мы будем определять столкновения яблок с корзинами с помощью метода OnCollisionEnter()
---

Который вызывается физическим движком Unity при каждом
столкновении двух GameObjects (при условии, что оба имеют компоненты Collider и Rigidbody).  

`OnCollisionEnter()` будет вызван как для яблока, так и для корзины, но только один из них
должен действительно что-то с этим делать, поэтому, корзины будут отвечать за ловлю яблок (а не скрипт
яблока, выполняющий эту задачу).

>На самом деле все немного сложнее, но в целом, если вы хотите реагировать на столкновение, вам нужно реализовать
OnCollisionEnter() в подклассе MonoBehaviour (например, Apple и Basket), прикрепленном к GameObject,
имеющему компонент Collider. Если он движется или вы хотите, чтобы он реагировал на столкновения со своими
дочерними объектами, ему также нужен компонент Rigidbody.  

1. Добавьте строки, указанные в листинге кода, в скрипт Basket.cs  

```c#
public class Basket : MonoBehaviour {

    void Update () { … }

    void OnCollisionEnter( Collision coll ) { // a
        // Find out what hit this basket
        GameObject collidedWith = coll.gameObject; // b
        if ( collidedWith.CompareTag("Apple") ) { // c
            Destroy( collidedWith );
        }
    }
}
```
- a. Метод `OnCollisionEnter` вызывается всякий раз, когда другой GameObject
сталкивается с этой корзиной, и ему передается аргумент Collision с информацией о
столкновении, включая ссылку на GameObject, который ударил Collider этой корзины.
- b. Эта строка присваивает столкнувшийся GameObject временной локальной переменной
`collidedWith`.
- c. Проверьте, является ли `collidedWith` яблоком, найдя тег «Apple», который был
присвоен префабу GameObject «Apple». Если `collidedWith` является яблоком, оно
уничтожается. Теперь, если яблоко ударит по этой корзине, оно будет уничтожено. Кроме
того, одним из приятных преимуществ метода `CompareTag()` является то, что он
запишет ошибку в консоль, если вы неправильно напишете имя тега (например, «Tag: Appel
is not defined»). 

2. Сохраните скрипт Basket, вернитесь в Unity и нажмите Play.
3. Сохраните сцену!  

На данный момент игра работает очень похоже на классическую игру Kaboom! . В ней пока нет
элементов графического интерфейса пользователя (GUI), таких как счет или индикатор
оставшихся у игрока жизней. Однако даже в своем нынешнем виде, без этих элементов, Apple
Picker уже является удачным прототипом! В таком виде он доказывает, что игра может быть
увлекательной, и позволяет настроить несколько аспектов игры, чтобы придать ей нужный
уровень сложности - две основные цели прототипа.
