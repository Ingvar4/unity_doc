## Скрипт AppleTree.cs 

- Объявление группы переменных для последующей настройки поведения AppleTree
- Использование метода `Invoke()` для вызова функций через время
- Функция создания объекта с присвоением ему местоположения 
- Поиск местоположения объекта и присвоение ему скорости движения + изменение направления
- Создание функции случайной смены местоположения

```c# title="C# AppleTree.cs"
using System.Collections;
using System.Collections.Generic;
using UnityEngine; //Подключение библиотек

public class AppleTree : MonoBehaviour {
    [Header("Inscribed")] //Добавляет заголовок в Inspector для групп переменных, которые не изменяются во время выполнения скрипта
    public GameObject applePrefab; //Объявление переменной префаба для последующего подключения к ней GameObject префаба яблока в Inspector
    public float speed = 1f; //Скорость движения AppleTree
    public float leftAndRightEdge = 10f; //Расстояние, на котором AppleTree меняет направление
    public float changeDirChance = 0.1f; //Вероятность того, что AppleTree сменит направление
    public float appleDropDelay = 1f; //Интервал в секундах между созданием экземпляров Apple

    void Start () { //Метод Start вызывается перед обновлением первого кадра.
        Invoke( "DropApple", 2f ); //1й параметр - название кастомной функции, 2й - время ожидания перед вызовом
    }

    void DropApple() { // Это пользовательская функция для создания экземпляра Apple в местеположение AppleTree
        GameObject apple = Instantiate<GameObject>( applePrefab ); // Создает экземпляр applePrefab и присваивает его локальной переменной GameObject apple
        apple.transform.position = transform.position; // Положение яблони присваивается положению яблока (иначе яблоко будет использовать положение своего префаба)
        Invoke( "DropApple", appleDropDelay ); // Рекурсия? DropApple() вызывает себя каждый раз, когда ее вызывают, в результате яблоко будет падать каждую секунду, пока игра работает
    }
    
    void Update () { // Метод Update вызывается один раз за кадр (так быстро, как компьютер может прорисовывать кадры)
        // Базовое движение
        Vector3 pos = transform.position; // Получает положение AppleTree в данный момент и присваивает значение pos.
        pos.x += speed * Time.deltaTime; // позиция по X увеличивается на скорость, умноженную на Time.deltaTime (которая является мерой количества секунд, прошедших с момента последнего кадра).
        transform.position = pos; // Присваивает измененное значение pos обратно transform.position (что перемещает AppleTree в новое положение)

        // Изменение направления
        if ( pos.x < -leftAndRightEdge ) { // проверяет, меньше ли новое значение pos.x, отрицательного предела по горизонтали, заданного leftAndRightEdge
            speed = Mathf.Abs( speed ); // Движение вправо до тех пор, пока pos.x меньше leftAndRightEdge
        } else if ( pos.x > leftAndRightEdge ) { // Если pos.x больше leftAndRightEdge, то speed устанавливается равным отрицательному значению Mathf.Abs(speed), что гарантирует, что AppleTree будет двигаться влево
            speed = -Mathf.Abs( speed ); // Движение влево
    }

    void FixedUpdate() { // Вызывается ровно 50 раз в секунду, независимо от того, на каком компьютере он выполняется 
        // Случайная смена направления привязана к времени благодаря FixedUpdate()
        if ( Random.value < changeDirChance ) { // Если это случайное число меньше, чем changeDirChance
            speed *= -1; // AppleTree изменит направление движения, установив скорость, равную отрицательному значению самой скорости
        }
    }
}
```

<Callout>
### `Invoke()` [!toc]
Вызывает именованную функцию после ожидания в течение заданного количества секунд. Имеет два параметра. В данном случае она вызывает новую функцию `DropApple()`.
</Callout>

<Callout>
### `Instantiate<GameObject>()` [!toc]
Данный метод используется для динамического создания (клонирования) объектов прямо во время игры. Он принимает исходный объект или префаб и возвращает его точную копию, часто применяясь для спавна врагов, выстрелов или бонусов. 

Пример с позиционированием при спавне:
```c#
Vector3 spawnPosition = new Vector3(0, 2, 0);
Quaternion spawnRotation = Quaternion.identity; // Без поворота

GameObject newObj = Instantiate<GameObject>(myPrefab, spawnPosition, spawnRotation);
```
</Callout>

<Callout>
### Time.deltaTime [!toc]
Это время в секундах, которое прошло с момента отрисовки предыдущего кадра до текущего. Эта переменная нужна для того, чтобы сделать движение объектов плавным и одинаковым на любых компьютерах и телефонах, независимо от их мощности и частоты кадров.  

Без Time.deltaTime код в методе Update выполняется каждый кадр. На мощном ПК объект сдвинется в 10 раз быстрее, чем на слабом.  

Умножение скорости на Time.deltaTime переводит измерение из «единиц за кадр» в «единицы за секунду».  

**Использовать** внутри метода `Update()` или `LateUpdate()` для плавного перемещения, вращения или изменения цвета.  

**Нельзя использовать** в `FixedUpdate()`, так как физический метод уже работает с фиксированным шагом времени (Time.fixedDeltaTime).
</Callout>

<Callout>
### `Mathf.Abs()` [!toc]
Метод `Mathf.Abs()` в Unity C# возвращает абсолютное значение (модуль) числа. Иными словами, он убирает знак «минус», если число отрицательное, делая его положительным, а положительное оставляет без изменений.  
Применяется, к примеру для вычисление расстояния: чтобы узнать, насколько далеко объект находится от другого по одной из осей (например, Mathf.Abs(player.position.x - enemy.position.x)). 
</Callout>

<Callout>
### `Random.value` [!toc]
Random.value в Unity C# - это статическое свойство, которое возвращает случайное число с плавающей запятой (тип float) в диапазоне от 0.0 до 1.0 (включительно). Это стандартный инструмент для генерации вероятностей, выбора случайных цветов или создания эффектов плавного изменения. 
</Callout>

## Скрипт Apple.cs 

- Удаление объекта из сцены с помощью метода `Destroy()` при заданном условии
- Пример получения ссылки на другой компонент и вызова из него функций

```c# title="C# Apple.cs"
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class Apple : MonoBehaviour {
    public static float bottomY = -20f; //Объявление и определение статической переменной с именем bottomY (статические поля являются общими для всех экземпляров класса)
    //public (модификатор доступа): Переменная видна из любых других скриптов и классов проекта. В Unity это также означает, что данная переменная будет отображаться в панели Inspector (если она не является static).
    //static (модификатор): Делает переменную «глобальной» для этого класса. Она принадлежит самому классу, а не какому-то конкретному объекту. Вам не нужно создавать экземпляр (копию) скрипта, чтобы обратиться к ней - достаточно написать имя класса.
    //По итогу переменная существует в единственном экземпляре, не отображается в Инспекторе
    void Update () {
        if ( transform.position.y < bottomY ) { // Если позиция Apple по Y меньше заданного значения -20f, то
            Destroy( this.gameObject ); //Удаляет из игры все, что ей передается

            ApplePicker apScript = Camera.main.GetComponent<ApplePicker>(); // Получение ссылки на компонент ApplePicker в Main Camera
            apScript.AppleMissed(); // Вызов публичного метода AppleMissed() из apScript
            //Сам метод AppleMissed() находится в скрипте ApplePicker
        }
    }
}
```

<Callout>
### `Destroy()` [!toc]
Удаляет из игры все, что ей передается, и может использоваться для уничтожения как компонентов, так и GameObjects. В данном случае необходимо использовать `Destroy(this.gameObject)`, поскольку `Destroy(this)` просто удалит компонент *Apple (Script)* из экземпляра GameObject *Apple*. В любом скрипте `this` относится к текущему экземпляру класса C#, в котором он вызывается (в данном листинге кода он относится к этому экземпляру компонента *Apple (Script)*), а не ко всему GameObject. Всякий раз, когда вы хотите уничтожить весь GameObject изнутри присоединенного класса компонента, вы должны вызывать `Destroy(this.gameObject)`.
</Callout>

## Скрипт ApplePicker 

- Подключение коллекций списка к скрипту с последующей инициализацией
- Пример цикла создания объектов из префаба с позиционированием и добавлением в список
- Создание публичной функции по поиску объектов по тегам, добавление их в массив и удаления через `foreach` 
- Пример сброса сцены с помощью SceneManagement при определённых условиях

```c# title="C# ApplePicker.cs"
using System.Collections;
using System.Collections.Generic; // Библиотека для использования коллекций
using UnityEngine;
using UnityEngine.SceneManagement; // Позволяет этому коду перезагрузить сцену, когда все корзины будут потеряны

public class ApplePicker : MonoBehaviour {
    [Header("Inscribed")]
    public GameObject basketPrefab; // Поле для префаба корзины GameObject
    public int numBaskets = 3; // Число корзин
    public float basketBottomY = -14f; // Положение корзины по оси Y
    public float basketSpacingY = 2f; // Расстояние между корзинами по оси Y
    public List<GameObject> basketList; // Объявление списка коллекции

    void Start () {
        basketList = new List<GameObject>(); // Эта строка инициализирует basketList как новый List<GameObject>(). Инициализация превращает его в реальный, готовый к использованию список.
        for (int i = 0; i < numBaskets; i++) { //Цикл создания корзин
            GameObject tBasketGO = Instantiate<GameObject>( basketPrefab ); //Создание корзины и присвоение результата tBasketGO (теперь tBasketGO содержит ссылку на новую корзину)
            Vector3 pos = Vector3.zero; // pos присваивается позиция (0,0,0) (то есть х=0, y=0 и z=0). Это эквивалентно new Vector3(0,0,0);
            pos.y = basketBottomY + ( basketSpacingY * i ); //Вычисление высоты корзины
            //1. i = 0 (-14 + (2 × 0) = -14) итог: (0, -14, 0)
            //2. i = 1 (-14 + (2 × 1) = -12) итог: (0, -12, 0)
            //3. i = 2 (-14 + (2 × 2) = -10) итог: (0, -10, 0)
            tBasketGO.transform.position = pos; //Установка позиции (Basket → Transform → Position → (0,-14,0) и так далее по циклу)
            basketList.Add( tBasketGO ); // Добавляет каждую корзину в basketList. Корзины добавляются в том порядке, в котором они создаются, то есть снизу вверх, поэтому 0- я корзина в basketList - самая нижняя.
        }
    }

    public void AppleMissed() { // Метод AppleMissed() должен быть объявлен как public, чтобы другие классы (такие как Apple) могли его вызывать
        // Уничтожение всех падающих яблок
        GameObject[] appleArray = GameObject.FindGameObjectsWithTag("Apple"); // Возвращает массив всех существующих GameObjects с тегом Apple. Последующий цикл foreach проходит по каждому из них и уничтожает их
        foreach ( GameObject tempGO in appleArray ) {
            Destroy( tempGO );
        }

        // Раздел кода по уничтожению одной из корзин
        int basketIndex = basketList.Count -1; //Получение индекса последней корзины в basketList
        GameObject basketGO = basketList[basketIndex]; // Получаем ссылку на объект "Корзина"
        basketList.RemoveAt( basketIndex ); // Удаляем корзину из списка и уничтожаем игровой объект
        Destroy( basketGO );
        
        if ( basketList.Count == 0 ) { // Если корзин не осталось, перезапуск игры
            SceneManager.LoadScene( "_Scene_0" ); // Фактически сбрасывает игру в начальное состояние
        }
    }
}
```

### Vector3 [!toc]
Одна из самых часто используемых структур в Unity. Она хранит три числа: (x,y,z). По сути это просто контейнер для трёх координат. Например:

```c#
Vector3 pos = new Vector3(3, 5, 10);

//x = 3, y = 5, z = 10  
```
Использование как позиции:

```c#
transform.position = new Vector3(5,3,0);

// Объект переместится вправо на 5, вверх на 3, вперёд на 0
```

Использование как направления:

```c#
Vector3.right  // (1,0,0)
Vector3.left  // (-1,0,0)
Vector3.up  // (0,1,0)
Vector3.down // (0,-1,0)
Vector3.forward  // (0,0,1)
Vector3.back  // (0,0,-1)
Vector3.zero  // (0,0,0)
Vector3.one  // (1,1,1)
```
</Callout>

## Скрипт Basket.cs 

- Сохранение ссылки на экземпляр другого скрипта, для последующей передачи в него данных из текущего скрипта
- Получение текущего положение курсора мыши на экране
- Обработка столкновений объектов с помощью `OnCollisionEnter()`

```csharp title="C# Basket.cs"
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class Basket : MonoBehaviour {
    public ScoreCounter scoreCounter; // Это сохранит ссылку на экземпляр скрипта ScoreCounter, прикрепленного к GameObject ScoreCounter

    void Start() {
        // Поиск объекта GameObject с именем ScoreCounter в иерархии сцены
        GameObject scoreGO = GameObject.Find( "ScoreCounter" ); // Это делается в Start(), потому что GameObject.Find() работает очень медленно, поэтому, по возможности, это следует делать только один раз на скрипт. 
        // Получите компонент ScoreCounter (script) из библиотеки scoreGO
        scoreCounter = scoreGO.GetComponent<ScoreCounter>(); // scoreGO.GetComponent<ScoreCounter>() ищет компонент ScoreCounter (Script) в GameObject scoreGO и присваивает его публичному полю (переменной) scoreCounter
    }

    void Update () {
        // Получение текущего положение курсора мыши на экране из поля ввода
        Vector3 mousePos2D = Input.mousePosition; // Это значение выражается в координатах экрана, то есть оно показывает, на каком расстоянии в пикселях находится курсор мыши от левого верхнего угла экрана. Координата z для Input.mousePosition всегда равна 0, поскольку это, по сути, двумерное измерение.
        // Положение камеры по оси Z определяет, насколько сильно нужно перемещать курсор мыши в трехмерном пространстве
        mousePos2D.z = -Camera.main.transform.position.z; // Эта строка устанавливает координату z mousePos2D равной отрицательному значению координаты Z главной камеры
        //В игре главная камера находится на Z = -10, поэтому mousePos2D.z устанавливается на 10. Это указывает последующей функции ScreenToWorldPoint(), на какое расстояние нужно сдвинуть mousePos3D в 3D- пространство (от положения главной камеры), помещая конечную точку мира на плоскость Z=0

        // Преобразование точки из двухмерного экранного пространства в трехмерное игровое пространство
        Vector3 mousePos3D = Camera.main.ScreenToWorldPoint( mousePos2D ); // Преобразует mousePos2D в точку в 3D-пространстве внутри сцены

        // Перемещение координаты X этой корзины в положение X курсора мыши
        Vector3 pos = this.transform.position;
        pos.x = mousePos3D.x;
        this.transform.position = pos;
    }

    void OnCollisionEnter( Collision coll ) { // Вызывается всякий раз, когда другой GameObject сталкивается с этой корзиной, и ему передается аргумент Collision с информацией о столкновении, включая ссылку на GameObject, который ударил Collider этой корзины
        // Узнайте, что попало в эту корзину
        GameObject collidedWith = coll.gameObject; // Присваивает столкнувшийся GameObject временной локальной переменной collidedWith
        if ( collidedWith.CompareTag("Apple") ) { // Проверьте, является ли collidedWith яблоком, найдя тег «Apple», который был присвоен префабу GameObject «Apple». 
            Destroy( collidedWith ); //Если collidedWith является яблоком, оно уничтожается. Теперь, если яблоко ударит по этой корзине, оно будет уничтожено
             
            scoreCounter.score += 100; // Увеличение счёта и присвоение значения обратно scoreCounter.score
            HighScore.TRY_SET_HIGH_SCORE( scoreCounter.score );
        }
    }
}

```

### `GetComponent<>()` [!toc]
Так же, как и для других компонентов (например, Rigidbody и Text), `GetComponent<>()` можно использовать для поиска ссылок на компоненты скриптов, которые вы создаете, поместив имя класса в угловые скобки метода (например, `<ScoreCounter>`).
</Callout>

<Callout>
### `Camera.ScreenToWorldPoint()` [!toc]
Преобразует 2D-координаты экрана (например, позицию курсора мыши или тапа) в 3D-координаты игрового мира. Он часто используется для привязки объектов к указателю или бросания предметов.  

Метод принимает Vector3, где ось Z - это расстояние (глубина) в единицах измерения мира (Units) от камеры до нужной точки.  

- Для 2D-игр: ось Z должна быть равна расстоянию до вашей плоскости объектов (например, 0, если камера на -10), иначе координаты будут искажены.  
- Для 3D-игр: чаще используют рейкастинг (Raycast), чтобы узнать точное расстояние до объекта под курсором.
</Callout>

<Callout>
### `OnCollisionEnter()` [!toc]
Это встроенный метод событий в Unity на C#, который автоматически срабатывает в момент, когда объект начинает соприкасаться (сталкиваться) с другим физическим объектом.
- Условия работы: Хотя бы у одного из двух сталкивающихся объектов должен быть компонент Rigidbody (твердое тело), и оба объекта должны иметь Collider (коллайдер) с отключенной галочкой Is Trigger.
- Один вызов: Метод срабатывает ровно один раз в кадре, когда происходит первоначальный контакт.
- Аргумент Collision: Метод принимает параметр (например, Collision collision), который хранит данные о столкновении: точку соприкосновения, силу удара и информацию о другом объекте.
</Callout>

## Скрипт ScoreCounter.cs

```c# title="C# ScoreCounter.cs"
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI; // Позволяет этому скрипту работать с классом Text

public class ScoreCounter : MonoBehaviour {
    [Header("Dynamic")] // Этот динамический заголовок появится в инспекторе, указывая на то, что поле score изменяется во время игры (в отличие от публичных полей Inscribed, которые не изменяются при запущенной игре)
    public int score = 0;
    private Text uiText; // Частное поле Text uiText используется для хранения ссылки на компонент Text в этом GameObject ScoreCounter

    void Start() {
        uiText = GetComponent<Text>(); // GetComponent<Text>() ищет компонент Text в GameObject, к которому прикреплен скрипт ScoreCounter, а затем присваивает этот компонент Text uiText.GetComponent()
    }

    void Update() {
        uiText.text = score.ToString( "#,0" );
        // Каждый кадр вызывается Update(), и uiText.text (текст, отображаемый на GameObject ScoreCounter) 
        // устанавливается в строковое представление целого числа score. 
        // Метод ToString() с аргументом score.ToString("#,0") возвращает строковое представление значения score, 
        // а параметр "#,0" указывает ToString() форматировать строку как целое число с запятыми,
        // разделяющими каждые три цифры (например, 1,000,000), и отображать ноль, если значение равно нулю 
        // ("#,#" не отобразило бы ничего, если бы значение было нулевым в формате ).
    }
}
```

## Скрипт HighScore.cs

```c# title="C# HighScore.cs"
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI; // Эта строка необходима для корректной работы графического интерфейса пользователя (uGUI)

public class HighScore : MonoBehaviour {
    // static - становится общим для всех экземпляров класса HighScore
    // private - скрывает переменную от других классов (в случае неожиданного поведения можно будет сразу понять в каком классе искать проблему)
    static private Text _UI_TEXT;  
    static private int _SCORE = 1000; // Является поле-подложкой для свойства SCORE. Большинству свойств требуется private поле-подложка для хранения значения, которое они оборачивают

    private Text txtCom; // txtCom - это ссылка на текстовый компонент этого модуля GO.

    void Awake() { // Вызывается сразу же при первом создании экземпляра класса HighScore
        _UI_TEXT = GetComponent<Text>(); // Text этого экземпляра HighScore присваивается статическому частному полю _UI_TEXT
        // Если таблица рекордов PlayerPrefs уже существует, прочтите её
        if (PlayerPrefs.HasKey("HighScore")) { // PlayerPrefs - это словарь значений, на которые ссылаются через строковые ключи
            SCORE = PlayerPrefs.GetInt("HighScore");
        }
        // Присвойте наивысший балл HighScore
        PlayerPrefs.SetInt("HighScore", SCORE); // Эта строка присваивает текущее значение HighScore.SCORE ключу HighScore в PlayerPrefs. Если HighScore в PlayerPrefs уже существует, это перезапишет значение обратно в PlayerPrefs;
    }

    static public int SCORE { // Доступно для просмотра любому классу. Любой другой скрипт может прочитать значение _SCORE, просто введя HighScore.SCORE
        get { return _SCORE; }
        private set { // Хотя любой класс может получить значение SCORE, только класс HighScore может его установить (потому и private)
            _SCORE = value; // value - это специальная переменная, которая хранит число, переданное в SCORE
            PlayerPrefs.SetInt("HighScore", value); // Теперь при каждом вызове оператора set для SCORE также устанавливается значение HighScore в PlayerPrefs
            if ( _UI_TEXT != null ) { // Прежде чем пытаться установить значение _UI_TEXT.text, нам следует дважды проверить, чтобы убедиться, что _UI_TEXT не равен null
                _UI_TEXT.text = "High Score: " + value.ToString( "#,0" );
            }
        }
    }

    static public void TRY_SET_HIGH_SCORE( int scoreToTry ) {
        if ( scoreToTry <= SCORE ) return;
        SCORE = scoreToTry;
    }
    // Поскольку поле _SCORE является закрытым (private), другим скриптам необходим способ 
    // попытаться установить новый рекорд. Статический открытый (public) метод 
    // TRY_SET_HIGH_SCORE() позволяет любому скрипту передать значение счета в HighScore
    // (например, вызвав HighScore.TRY_SET_HIGH_SCORE(100)). 
    // Переданный параметр scoreToTry сравнивается с текущим значением SCORE, 
    // и если он больше, то SCORE присваивается значение scoreToTry. Это защищает HighScore 
    // от установки более низкого значения другим скриптом.

    // Следующий код позволяет легко сбросить рекорд игрока в PlayerPrefs
    [Tooltip( "Check this box to reset the HighScore in PlayerPrefs" )]
    public bool resetHighScoreNow = false; // В Инспекторе появится общедоступный флажок типа bool с именем resetHighScoreNow
    void OnDrawGizmos() { // Вызывается редактором Unity практически каждый раз, когда GameObject отображается на экране, редактор постоянно вызывает метод OnDrawGizmos()
        if ( resetHighScoreNow ) {
            resetHighScoreNow = false;
            PlayerPrefs.SetInt( "HighScore", 1000 );
            Debug.LogWarning( "PlayerPrefs HighScore reset to 1,000." );
        }
    }
}
```

<Callout>
### `Awake()` [!toc]
Встроенный метод Unity (подобно `Start()` или `Update()`), который вызывается сразу же при первом создании экземпляра класса HighScore (поэтому `Awake()` всегда выполняется до `Start()`). Я часто использую метод `Awake()`, чтобы присвоить ссылки на компоненты GameObject, такие как `_UI_TEXT`, до того, как произойдет что-либо другое, в том числе до вызова `Start()` в любых других скриптах!
</Callout>
