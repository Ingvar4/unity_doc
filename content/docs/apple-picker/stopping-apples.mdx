---
title: Остановка яблок, если они падают слишком далеко
description: Если оставить текущую версию игры работать некоторое время, вы заметите, что в иерархии появилось много яблок.
---

Это происходит потому, что код каждую секунду создаёт новое яблоко,
но никогда не удаляет старые. Вместо того чтобы писать сложный код в классе AppleTree
для отслеживания и удаления каждого яблока, упавшего слишком далеко, мы создадим скрипт
на префабе Apple, который позволит каждому яблоку самостоятельно решать эту проблему.  

1. В панели меню Unity выберите *Assets > Create > C# Script*. Это создаст новый скрипт C# с именем
*NewBehaviourScript*, но имя будет выделено, чтобы вы могли его изменить.
        - Пока имя скрипта *NewBehaviourScript* все еще выделено - прежде чем щелкнуть в любом
другом месте - измените имя скрипта на Apple.
12. Если вы измените имя скрипта, пока текст еще выделен, Unity автоматически изменит имя класса на новое
выбранное вами (в данном случае Apple). Если вы щелкните за пределами поля, а затем выберете скрипт и измените имя, имя класса внутри скрипта останется NewBehaviourScript, что приведет к проблемам.
2. Откройте скрипт Apple на C# и добавьте код, чтобы уничтожать яблоки, когда они достигают глубины
`transform.position.y <= -20` (что находится достаточно далеко за пределами экрана):

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class Apple : MonoBehaviour { // a  
    public static float bottomY = -20f; //b

    void Update () {
        if ( transform.position.y < bottomY ) {
            Destroy( this.gameObject ); //c
        }
    }

    // void Start() {…} // Please delete the unused Start() method
}
```

- a. Если в этой строке написано `public class NewBehaviourScript`, значит, вы стали
жертвой одной из классических ошибок. Дополнительную информацию см. в сноске. Чтобы исправить это, просто измените имя класса на Apple, как показано в
этом листинге кода.
- b. Строка `public static float` объявляет и определяет
статическое поле с именем `bottomY`. Как упоминалось в главе «Переменные и
компоненты», статические поля являются общими для всех экземпляров класса, поэтому
каждый экземпляр Apple будет иметь одинаковое значение для `bottomY`. Если значение
`bottomY` когда-либо изменится для одного экземпляра, оно одновременно изменится для
всех экземпляров. Однако также важно отметить, что статические поля, такие как
`bottomY`, не отображаются в Инспекторе.
- c. Функция `Destroy()` удаляет из игры все, что ей передается, и может использоваться для
уничтожения как компонентов, так и GameObjects. В данном случае необходимо
использовать `Destroy(this.gameObject)`, поскольку `Destroy(this)` просто
удалит компонент Apple (Script) из экземпляра GameObject Apple. В любом скрипте `this`
относится к текущему экземпляру класса C#, в котором он вызывается (в данном листинге
кода он относится к этому экземпляру компонента Apple (Script)), а не ко всему GameObject.
Всякий раз, когда вы хотите уничтожить весь GameObject изнутри присоединенного класса
компонента, вы должны вызывать `Destroy(this.gameObject)`.  

3. Сохраните скрипт Apple в Visual Studio.
4. Чтобы этот код работал в игре, необходимо прикрепить скрипт Apple на C# к префабу
GameObject Apple на панели «Проект». Из предыдущих глав вы уже знаете, как перетащить
скрипт на GameObject, чтобы прикрепить его, поэтому вот еще один способ сделать это:
    - a. Выберите префаб Apple в панели Project.
    - b. Прокрутите вниз до нижней части панели Inspector и нажмите кнопку Add Component.
    - c. В появившемся всплывающем меню выберите *Scripts > Apple*. Если вы внимательно
следили за этим руководством, то, скорее всего, в строке поиска всплывающего окна Add
Component все еще будет отображаться текст «AppleTree». Если вы нажмете на значок `×`
справа от строки поиска, то появятся все варианты компонентов, и вы сможете выбрать
*Scripts > Apple*.  

>Когда вы перейдете в подменю «Скрипты» всплывающего окна «Добавить компонент», вы, скорее всего, увидите
несколько скриптов, которые не писали вы (например, TMPro, UnityEngine.EventSystems и т. д.). Это встроенные скрипты из некоторых пакетов, которые Unity автоматически включает при создании нового проекта. Вы можете увидеть их в папке «Packages» на панели «Project», и в большинстве случаев их можно смело игнорировать.  

Теперь, если вы нажмете «Play» в Unity и уменьшите масштаб на панели «Scene», вы увидите,
что яблоки падают за нижнюю границу кадра камеры, а затем исчезают, когда достигают
положения по оси Y равного -20. Вы также можете увидеть, как они появляются и исчезают в
иерархии.  

Это все, что нужно сделать для яблок. Теперь сохраните сцену!
