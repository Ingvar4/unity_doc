Здесь вы увидите несколько новых концепций, включая статические(static) свойства и методы. Как
и во всем остальном, существует множество способов реализации скрипта HighScore. Этот код
сопровождается подробными пояснениями, поскольку я выбрал интересный способ его
реализации, который вы определенно сможете использовать в будущем.  

1. Создайте новый скрипт C# с именем HighScore и прикрепите его к GameObject HighScore в
панели Hierarchy (если вы не видите GameObject HighScore в Hierarchy, это потому, что он
является дочерним элементом Canvas, и вам нужно раскрыть треугольник рядом с Canvas).
2. Откройте скрипт HighScore в Visual Studio и добавьте код:

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI; // We need this line for uGUI to work.

public class HighScore : MonoBehaviour {
    static private Text _UI_TEXT; // a
    static private int _SCORE = 1000; // b

    private Text txtCom; // txtCom is a reference to this GO’s Text
    component

    void Awake () { // c
        _UI_TEXT = GetComponent<Text>(); // d
    }

    static public int SCORE { // e
        get { return _SCORE; }
            private set { // f
            _SCORE = value;
            if ( _UI_TEXT != null ) { // g
                _UI_TEXT.text = "High Score: " + value.ToString( "#,0" );
            }
        }
    }

    static public void TRY_SET_HIGH_SCORE( int scoreToTry ) { // h
        if ( scoreToTry <= SCORE ) return; // If scoreToTry is too low,
        return
        SCORE = scoreToTry;
    }

    // void Start() {…} // Please delete the unused Start() & Update()
    methods
    // void Update() {…}
}
```

- a. Ключевое слово static приводит к тому, что текстовый объект `_UI_TEXT`
становится общим для всех экземпляров класса HighScore (хотя на самом деле будет
только один экземпляр). Мы делаем это здесь для того, чтобы все методы в этом классе
могли быть статическими, за исключением метода Awake() (см. // c). Обозначение
`_UI_TEXT` частным скрывает его от других классов, что обычно считается хорошей
практикой, так что если `_UI_TEXT` изменится неожиданным образом, мы будем знать, что
это произошло из-за этого класса, а не из-за чего-то в другом классе.
- b. `static private int _SCORE` является поле-подложкой для свойства SCORE
в // e. Большинству свойств требуется private поле-подложка для хранения
значения, которое они оборачивают. Я подробнее расскажу об этом в // e.
- c. `Awake()` - это встроенный метод Unity (подобно `Start()` или `Update()`),
который вызывается сразу же при первом создании экземпляра класса HighScore
(поэтому `Awake()` всегда выполняется до `Start()`). Я часто использую метод
`Awake()`, чтобы присвоить ссылки на компоненты GameObject, такие как `_UI_TEXT`,
до того, как произойдет что-либо другое, в том числе до вызова `Start()` в любых
других скриптах!
- d. Здесь компонент Text этого экземпляра HighScore присваивается статическому
частному полю `_UI_TEXT`. Это позволяет использовать один и тот же `_UI_TEXT` в
любом статическом или нестатическом методе любого экземпляра HighScore.
- e. `static public int SCORE` доступно для просмотра любому
классу. Поскольку оно является статическим и публичным, любой другой скрипт может
прочитать значение `_SCORE`, просто введя HighScore.SCORE, что использует строку `get { return _SCORE; }` здесь для возврата значения `_SCORE`. Обратите внимание на
расположение точки с запятой внутри фигурных скобок в блоке `get`.
- f. В свойстве можно установить для блока `get` или `set` более высокий уровень защиты, чем
у самого свойства. Здесь мы сделали блок `set` частным, поэтому, хотя любой класс
может получить значение SCORE, только класс HighScore может его установить.
Внутри этого оператора `set` сначала мы устанавливаем `_SCORE = value`. Неявно
объявленная переменная value - это специальная переменная, которая хранит число,
переданное в SCORE. Таким образом, если вызывается HighScore.SCORE = 100, то
value будет равна 100 на время выполнения оператора `set`.
- g. Прежде чем пытаться установить значение `_UI_TEXT.text`, нам следует дважды
проверить, чтобы убедиться, что
`_UI_TEXT` не равен `null`. Если бы это было так, попытка установить `_UI_TEXT.text`
вызвала бы исключение NullReferenceException, остановила бы выполнение остальной части
скрипта, устанавливающего SCORE, и вывела бы красную ошибку в консоль Unity. Если
`_UI_TEXT` не равен `null`, следующая строка использует тот же формат
ToString("#,0"), который мы видели в листинге кода для отображения SCORE в текстовом поле `_UI_TEXT`.
- h. Поскольку поле SCORE является закрытым (private), другим скриптам необходим способ попытаться установить новый рекорд. Статический открытый (public) метод `TRY_SET_HIGH_SCORE()` позволяет любому скрипту передать значение счета в HighScore (например, вызвав HighScore.TRY_SET_HIGH_SCORE(100)). Переданный параметр `scoreToTry` сравнивается с текущим значением SCORE, и если он больше, то SCORE присваивается значение `scoreToTry`. Это защищает HighScore от установки более низкого значения другим скриптом.  

Одно из преимуществ использования свойства SCORE для установки значения
`_UI_TEXT.text` заключается в том, что это происходит только при установке нового
рекорда, а не при каждом вызове `Update()`, как это делает `ScoreCounter`. Такие мелочи не
сильно влияют на производительность, но о них стоит знать.  

Теперь давайте добавим код в Basket, чтобы он мог пытаться установить рекорд.  

3. Откройте скрипт Basket на C# и добавьте код:

```c#
public class Basket : MonoBehaviour {
    …
    void OnCollisionEnter( Collision coll ) {
        // Find out what hit this basket
        GameObject collidedWith = coll.gameObject;
        if ( collidedWith.CompareTag("Apple") ) {
            Destroy( collidedWith );
            // Increase the score
            scoreCounter.score += 100;
            HighScore.TRY_SET_HIGH_SCORE( scoreCounter.score );
        }
    }
}
```

Это все, что нам нужно сделать в Basket, чтобы функция high score работала. Если бы вы
установили здесь точку останова (следуя инструкциям из главы «Отладка»), вы бы увидели,
что любое значение `scoreCounter.score` передается в
`HighScore.TRY_SET_HIGH_SCORE()`, а затем метод `TRY_SET_HIGH_SCORE()`
проверяет, действительно ли оно выше, прежде чем установить его в качестве рекорда. Итак, мы
проделали большую работу в скрипте HighScore, чтобы значительно упростить нашу работу в
Basket. Когда вы работаете в одиночку, это немного упрощает вам жизнь, но при совместной
работе с другими программистами очень важно упростить то, что им приходится делать для
использования ваших скриптов.  

4. Сохраните все скрипты в Visual Studio, вернитесь в Unity и нажмите «Play».  

Теперь, если вы будете играть, пока ваш счет не превысит 1 000, вы увидите, что HighScore тоже
начнёт увеличиваться. Однако каждый раз, когда сцена перезагружается (например, если вы
проиграли или остановили игру, нажав кнопку «Play», а затем перезапустили её, нажав «Play»
снова), `HighScore._SCORE` будет сброшен до 1 000.
