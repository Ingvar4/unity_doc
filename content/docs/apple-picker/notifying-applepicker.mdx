---
title: Уведомление ApplePicker о том, что яблоко не попало
description: Еще один аспект, делающий Apple Picker более похожим на игру, - это завершение раунда и удаление корзины, если игрок промахивается по яблоку, и оно падает за пределы экрана.
---

В этот момент яблоки сами управляют своим уничтожением, если падают за пределы экрана, что
нормально, но яблоко также должно уведомить скрипт ApplePicker об этом событии, чтобы тот мог
завершить раунд и уничтожить остальные яблоки. Это предполагает вызов одной функцией
другой.  

Как и в случае с корзиной, изменяющей счет в ScoreCounter, есть несколько способов сделать это.
На этот раз внутри скрипта Apple мы получим ссылку на скрипт ApplePicker на главной камере,
используя то же поле `public static Camera.main`, которое мы использовали для определения положения мыши в строках `// b` и `// c` листинга кода (когда мы добавляли возможность перемещения в класс Basket).  

1. Начните с внесения изменений Apple.cs

```c#
public class Apple : MonoBehaviour {
    public static float bottomY = -20f;

    void Update () {
        if ( transform.position.y < bottomY ) { // a
            Destroy( this.gameObject );

            // Get a reference to the ApplePicker component of Main Camera
            ApplePicker apScript = Camera.main.GetComponent<ApplePicker>(); // b
            // Call the public AppleMissed() method of apScript
            apScript.AppleMissed(); // c
        } // a
    }
}
```

- a. Обратите внимание, что все эти добавленные строки находятся в фигурных скобках этого
оператора if (между верхней строкой `// a` и второй строкой `// a` ниже).
- b. Это позволяет получить ссылку на скриптовый компонент ApplePicker на Main Camera.
Поскольку класс Camera имеет встроенную статическую публичную переменную
Camera.main, которая ссылается на Main Camera, нет необходимости использовать
GameObject.Find("Main Camera") для получения ссылки на Main Camera. Затем
с помощью `GetComponent<ApplePicker>()` получается ссылка на компонент
ApplePicker (Script) на Main Camera и присваивает его apScript. После этого становится
возможным доступ к публичным переменным и методам экземпляра класса ApplePicker,
прикрепленного к Main Camera.
- c. Это вызывает еще не написанный метод `AppleMissed()` класса ApplePicker.
Поскольку этот метод еще не существует, Visual Studio подчёркнет имя метода
красной волнистой линией, и скрипт Apple не скомпилируется.  

2. Добавьте общедоступный метод `AppleMissed()` в скрипт ApplePicker, открыв
скрипт ApplePicker  

```c#
public class ApplePicker : MonoBehaviour {
    …

    void Start () { … }

    public void AppleMissed() { // a
        // Destroy all of the falling Apples
        GameObject[] appleArray=GameObject.FindGameObjectsWithTag("Apple"); // b
        foreach ( GameObject tempGO in appleArray ) {
            Destroy( tempGO );
        }
    }
}
```

- a. Метод `AppleMissed()` должен быть объявлен как public, чтобы другие классы
(такие как Apple) могли его вызывать. Если опустить обозначение public, то по
умолчанию все методы будут protected и их нельзя будет вызывать (или даже видеть)
из других классов.
- b. `GameObject.FindGameObjectsWithTag("Apple")` вернет массив всех
существующих GameObjects с тегом Apple. Последующий цикл foreach проходит
по каждому из них и уничтожает их.  

>Функция GameObject.FindGameObjectsWithTag() на самом деле довольно ресурсоемкая, поэтому я бы не рекомендовал использовать её внутри методов Update() или FixedUpdate(). Однако, поскольку это происходит только тогда, когда игрок теряет корзину (а игровой процесс в этот момент и так замедляется), в данном случае её вполне можно использовать.  

Если вы вернетесь в Unity и нажмете «Play», то, возможно, увидите, что ничего не изменилось. Я
не просил вас явно сохранять скрипты Apple или ApplePicker после внесения этих изменений, и
если вы их не сохранили, то, конечно, ничего не изменится. Это напоминание о том, что всегда
нужно сохранять, даже если я явно не прошу вас об этом. Остановите воспроизведение в Unity и
вернитесь в Visual Studio.  

3. В строке меню Visual Studio выберите *File > Save All*, чтобы одновременно
сохранить скрипты Apple и ApplePicker. Если пункт «Сохранить все» неактивен, значит, все
ваши файлы уже сохранены. Ура!
4. Вернитесь в Unity и нажмите «Play».  

Теперь вы должны увидеть, что при промахе по одному яблоку все остальные яблоки исчезают с
экрана.
