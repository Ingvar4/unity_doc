title: Начисление очков за каждое пойманное яблоко
description: Помимо уничтожения яблока, скрипт Basket должен также увеличивать текущий счет, отображаемый в ScoreCounter.
---

Однако на данный момент между скриптами ScoreCounter и Basket нет никакой связи.  

Существует несколько способов реализации этой связи. Вы увидите один из них для объекта
ScoreCounter (с использованием метода GameObject.Find(«ScoreCounter») и
общедоступного поля типа int под названием score), а для объекта HighScore я
покажу вам другой способ (с использованием общедоступного статического поля типа
int под названием SCORE). В целом я предпочитаю использовать метод со статическим
полем для прототипирования, поскольку он проще, но тут я постараюсь показать вам
несколько различных способов решения задач.  

>Оба этих метода не приветствуются при разработке коммерческого программного обеспечения, поскольку объявление полей score и SCORE общедоступными (public) позволяет любому скрипту изменять их. Однако для простого прототипа, который мы создаем в этой главе, они вполне подходят.  

1. Создайте новый скрипт на C# с именем ScoreCounter и прикрепите его к GameObject
ScoreCounter в иерархии (теперь вы знаете несколько разных способов сделать это).
2. Откройте скрипт ScoreCounter в Visual Studio и приведите его в соответствие с кодом,
приведенным в листинге  

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI; // This line enables use of uGUI classes like Text. // a

public class ScoreCounter : MonoBehaviour {
    [Header("Dynamic")] // b
    public int score = 0;

    private Text uiText; // c

    void Start() {
        uiText = GetComponent<Text>(); // d
    }

    void Update() {
        uiText.text = score.ToString( "#,0" ); // This 0 is a zero! // e
    }
}
```

    - a. Использование UnityEngine.UI; позволяет этому скрипту работать с классом Text.
По мере укрепления практик кодирования Unity Technology, они переходят к модели,
подобной этой, где необходимо вручную включать библиотеки кода для новых функций.
    - b. Этот динамический заголовок появится в инспекторе, указывая на то, что поле score
изменяется во время игры (в отличие от публичных полей Inscribed, которые не изменяются
при запущенной игре).
    - c. Частное поле Text uiText используется для хранения ссылки на компонент Text на
этом GameObject ScoreCounter.
    - d. Здесь `GetComponent<Text>()` ищет компонент Text в GameObject, к которому
прикреплен скрипт ScoreCounter, а затем присваивает этот компонент Text uiText.GetComponent() - относительно медленный метод, поэтому мы вызываем
его только один раз - в методе `Start()` - и сохраняем найденную ссылку в поле
uiText для быстрого доступа в дальнейшем (вместо того, чтобы вызывать
`GetComponent()` в каждом кадре в методе `Update()`).
    - e. Каждый кадр вызывается `Update()`, и uiText.text (текст, отображаемый на
GameObject ScoreCounter) устанавливается в строковое представление целого числа score.
Метод `ToString()` с аргументом score.ToString("#,0") возвращает строковое
представление значения score, а параметр "#,0" указывает `ToString()`
форматировать строку как целое число с запятыми, разделяющими каждые три цифры
(например, 1,000,000), и отображать ноль, если значение равно нулю ("#,#" не
отобразило бы ничего, если бы значение было нулевым в формате ).  

При желании вы можете нажать «Play» в Unity, выбрать ScoreCounter, а затем настроить
общедоступное(public) поле score в инспекторе, чтобы увидеть, как запятая добавляется к числам,
превышающим 1 000.  

### Настройка Basket для увеличения значения ScoreCounter [!toc]

Теперь нам нужно позволить Basket обращаться к public полю score, которое мы
добавили в ScoreCounter. В скрипте Basket на C# уже есть метод OnCollisionEnter(),
поэтому в следующих шагах вы добавите код в скрипт Basket, чтобы начислять игроку очки за
каждое пойманное яблоко. Сто очков за яблоко кажется разумным числом (хотя лично я всегда
считал немного нелепым наличие лишних нулей в конце результатов).  

1. Откройте скрипт Basket в Visual Studio и добавьте строки

```c#
public class Basket : MonoBehaviour {
    public ScoreCounter scoreCounter; // a

    void Start() {
        // Find a GameObject named ScoreCounter in the Scene Hierarchy
        GameObject scoreGO = GameObject.Find( "ScoreCounter" ); // b 
        // Get the ScoreCounter (Script) component of scoreGO
        scoreCounter = scoreGO.GetComponent<ScoreCounter>(); // c
    }

    void Update () { … }

    void OnCollisionEnter( Collision coll ) {
        // Find out what hit this basket
        GameObject collidedWith = coll.gameObject;
        if ( collidedWith.CompareTag("Apple") ) {
            Destroy( collidedWith );
            // Increase the score
            scoreCounter.score += 100; // d
        }
    }
}
```

    - a. Это сохранит ссылку на экземпляр скрипта ScoreCounter, прикрепленного к GameObject
ScoreCounter. Обратите внимание на разницу в регистре и цвете между классом
ScoreCounter и полем scoreCounter.
    - b. GameObject.Find( "ScoreCounter" ) просматривает все GameObjects в сцене
в поисках объекта с именем «ScoreCounter» и присваивает его локальной
переменной scoreGO. Это делается здесь, в методе Start(), потому что
GameObject.Find() работает очень медленно (т. е. может занять миллисекунду),
поэтому, по возможности, это следует делать только один раз на скрипт.
    - c. `scoreGO.GetComponent<ScoreCounter>()` ищет компонент ScoreCounter (Script)
на GameObject scoreGO и присваивает его публичному полю scoreCounter. Так же,
как и для других компонентов (например, Rigidbody и Text), `GetComponent<>()`
можно использовать для поиска ссылок на компоненты скриптов, которые вы создаете,
поместив имя класса в угловые скобки метода (например, `<ScoreCounter>`).
    - d. Теперь, когда у нас есть ссылка на правильный экземпляр класса ScoreCounter, очень легко
получить доступ к общедоступному int score из листинга кода и изменить его.
Мы даже можем использовать +=, чтобы получить значение scoreCounter.score,
увеличить его на 100, а затем присвоить это значение обратно scoreCounter.score.  

2. Вы изменили уже несколько разных скриптов. Не забыли ли вы сохранять их после
каждого изменения? Если нет - или если вы не уверены, как это часто бывает со мной
- вы можете выбрать *File > Save All* в панели меню Visual Studio, чтобы
сохранить все измененные, но несохраненные скрипты. Если пункт «Сохранить все»
неактивен, то поздравляю - все ваши скрипты уже сохранены.  

Теперь вернитесь в Unity и запустите сцену; вы должны увидеть, что счет увеличивается на 100
очков каждый раз, когда вы ловите яблоко.
