---
title: Корзина
description: Серия из трех корзин будет ловить яблоки, падающие с дерева. Как и другие арт-ресурсы, арт-объект корзины очень прост.
---

1. Выберите *GameObject > 3D Object > Cube* в панели меню Unity.
    - a. Переименуйте Cube в Basket.
    - b. Установите трансформацию Basket следующим
образом:   

    Basket (Cube) P:[ 0, 0, 0 ] R:[ 0, 0, 0 ] S:[ 4, 1, 4 ]  

В результате у вас должен получиться плоский широкий прямоугольный объект.  

2. Создайте новый материал с именем *Mat_Basket*.
    - a. В инспекторе *Mat_Basket* установите цвет альбедо на светло-желтый, лишенный
насыщенности (похожий на солому).
    - b. В верхней части инспектора *Mat_Basket* установите для параметра Shader значение *Unlit >
Color* (после
выбора он будет отображаться в инспекторе как Unlit/ Color).
    - c. Примените материал *Mat_Basket* к корзине.  

Обратите внимание, что цвет альбедо перенесся из шейдера Standard в поле Main Color
(Основной цвет) Unlit/Color при его изменении. Шейдеры Unlit обходят большинство вычислений
освещения в Unity и просто отображают объект на экране с полной яркостью. В данном случае я
хотел, чтобы корзины хорошо были видны на экране, поэтому выбрал шейдер Unlit.  

3. Добавьте компонент Rigidbody к корзине. Выберите корзину в иерархии и выберите
*Component > Physics > Rigidbody* в меню Unity.
a. В инспекторе Rigidbody корзины установите для параметра Use Gravity значение false (не
отмечено).
b. В инспекторе Rigidbody объекта Basket установите для параметра *Is Kinematic* значение true (флажок установлен)  

>Установка для Rigidbody параметра «Is Kinematic» сообщает физическому движку Unity, что вы будете перемещать объект с помощью кода, и предотвращает автоматическое перемещение корзины системой физики.  

4. Сделайте Basket префабом, перетащив Basket из панели Hierarchy в панель Project и удалив
оставшийся экземпляр Basket из Hierarchy (так же, как вы делали для Apple).
5. Обязательно сохраните сцену. Если вы используете систему контроля версий, не забудьте также опубликовать все в системе контроля версий.
