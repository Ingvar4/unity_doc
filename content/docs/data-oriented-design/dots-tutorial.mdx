После завершения первоначального создания проекта нам потребуется импортировать несколько пакетов, необходимых для работы системы заданий C# и компилятора Burst. В более ранних версиях Unity почти весь функционал был включен в каждый проект. Однако к 2019 году Unity полностью перешла на использование менеджера пакетов (Package Manager), инструмента, позволяющего выбирать, загружать ли определенные пакеты программного обеспечения, тем самым активируя необходимые функции и уменьшая избыточность, вызванную ненужными функциями.  

Менеджер пакетов показан на рисунке, а шаги по импорту
необходимых пакетов выделены буквами, которые указаны в следующих
шагах:

1. Импортируйте пакет Burst (компилятор Burst):
    - a. В меню Unity выберите *Window > Package Manager*, чтобы
открыть окно.
    - b. По умолчанию здесь обычно отображаются только те пакеты, которые
уже есть в вашем проекте, поэтому нажмите кнопку с надписью
*Packages: In Project* и выберите из списка *Unity Registry*.
Теперь вы увидите все «Проверенные» (т. е. не «Предварительные»)
пакеты, предлагаемые Unity.
    - c. В длинном списке слева выберите пакет Burst.
    - d. Под заголовком Burst справа нажмите кнопку «Установить» внизу. Подождите несколько секунд, пока Unity установит и скомпилирует пакет Burst.
    - e. Обратите внимание на три синих ссылки в описании каждого пакета.
Под названием Burst, названием компании и информацией о версии
находится ссылка «View documentation», которая очень полезна,
если вы хотите узнать больше о каком-либо из пакетов.  

2. Включите предварительные версии пакетов в диспетчере пакетов.
Надеюсь, к моменту, когда вы будете читать эту книгу, в этом уже не
будет необходимости, но на момент написания этой книги система заданий C#Job System все еще находится в
стадии предварительной версии, поэтому вам нужно указать Unity
показывать пакеты, которые еще не вышли из этой стадии.  

    - a. Щелкните значок шестеренки в окне «Менеджер пакетов», а
затем выберите «Расширенные настройки проекта», чтобы открыть
панель «Менеджер пакетов» в окне «Настройки проекта».
    - b. В разделе *Advanced Settings* внизу окна «Настройки
проекта» установите флажок *Enable Preview Packages*. Появится всплывающее окно с вопросом, понимаете ли вы,
что пакеты предварительной версии иногда могут работать
некорректно. Нажмите «Я понимаю».
    - c. *Optional*: вы можете установить флажок «Показывать
зависимости», если хотите увидеть, какие другие пакеты будут
добавлены для поддержки устанавливаемых вами пакетов (например,
пакет Burst требует пакет Mathematics, а Job System — пакеты
Mathematics и Collections).
    - d. Закройте окно «Настройки проекта».  

3. Импортируйте пакет «Jobs» (система заданий C#):
    - a. Вернувшись в окно «Менеджер пакетов», выберите «Jobs» в списке
слева.
    - b. Под заголовком «Jobs» справа нажмите кнопку «Install» внизу.
Подождите еще несколько секунд, пока Unity установит и
скомпилирует пакет «Jobs».
    - c. Закройте окно «Package Manager».
Теперь проект Unity должен быть настроен для этого примера.

### Настройка сцены

Давайте настроим шаблон сцены, который вы будете использовать для обеих
версий кода:  

1. Создайте объект Quad для отображения изображения. Мы используем Quad, потому что он
состоит всего из двух треугольников (в то время как Plane состоит из 200 треугольников) и
не требует холста пользовательского интерфейса (который необходим для RawImage).  

    - a. В главном меню Unity выберите *GameObject > 3D Object > Quad*.
    - b. В панели «Инспектор четырехугольников» внесите следующие изменения в раздел *Transform*:
        - Position: [ - 3.5, 0, 0 ]. Он смещен влево, чтобы вы могли видеть
одновременно и Quad, так и меню Stats
        - Rotation: [ 0, 0, 0 ]
        - Scale: [ 10, 10, 1 ]

2. Создайте материал для отображения изображения:

    - a. В главном меню Unity выберите *Assets > Create > Material*.
    - b. Переименуйте новый материал в *UnlitTexture* и выберите UnlitTexture на
панели Project.
    - c. В верхней части панели инспектора *UnlitTexture (Material)* щелкните
всплывающее меню Shader и выберите *Unlit > Texture*. Это создаст
материал, который будет отображать изображение без использования
каких-либо источников света в сцене.

3. Перетащите материал «UnlitTexture» из панели «Проект» на «Quad» (в
«Иерархии» или «Сцене»). Это присвоит материал объекту Quad,
и вы должны увидеть, как цвет Quad
изменится с темно-серого на ярко-белый в панели Game.
4. Установите разрешение панели Game на Full HD (1920 x 1080), выбрав его из
всплывающего меню Aspect Ratio в верхней части панели Game, слева от
ползунка Scale (в данный момент там может быть указано Free Aspect).  

Это должно быть все, что вам нужно для настройки сцены. Сохраним две
копии: одну для OOP, а другую для DOTS. Если при создании этого проекта вы
выбрали шаблон 2D Core, то теперь левую часть панели Game должен
заполнять большой белый квадрат.  

5. Сохраните сцену для OOP:
    - a. В главном меню Unity выберите *File > Save As…*..
    - b. В диалоговом окне «Сохранить сцену» назовите сцену *_Scene_OOP* и
сохраните ее в папке Scenes.
6. Сохраните сцену для OOP:
    - a. В главном меню Unity выберите *File > Save As…*..
    - b. В диалоговом окне «Сохранить сцену» назовите сцену *_Scene_DOTS* и
сохраните ее в папке Scenes.  

По завершении у вас должно быть три сцены в папке *Assets > Scenes*
панели Project: _Scene_DOTS, _Scene_OOP и SampleScene.
