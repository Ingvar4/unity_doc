---
title: Возврат void
description: Большинство функций, которые мы написали до сих пор, имели тип возвращаемого значения void, что означает, что функция не возвращает никакого значения.
---

Хотя эти функции не возвращают конкретного значения,
все же бывают случаи, когда вам может понадобиться вызвать `return`
внутри них.  

Всякий раз, когда `return` используется внутри функции, он
останавливает выполнение функции и возвращает управление на строку, с
которой была вызвана функция. Таким образом, `return`
похож на то, как `break` выходит из цикла или case в `switch`, но он выходит
из всей функции.  

Возврат из функции, чтобы избежать выполнения оставшейся части
функции, часто бывает полезен. Например, если у вас есть список из более
чем 100 000 GameObjects, и вы хотите переместить GameObject с именем "Phil" в начало
координат (Vector3.zero), но не хотите выполнять ничего другого, вы
можете написать следующую функцию:

```c#
public class FunctionsEx : MonoBehaviour {
    public List<GameObject> reallyLongList; // Defined in the Inspector // a

    void Start() {
        MoveToOrigin("Phil"); // b
    }

    void MoveToOrigin(string theName) {
        foreach (GameObject go in reallyLongList) { // c
            if (go.name == theName) { // d
                go.transform.position = Vector3.zero; // e
                return; // f
            }
        }
    }
}
```

**a.** `List<GameObject> reallyLongList` — это очень длинный
список GameObjects, который, как мы себе представляем, был заранее
определен в инспекторе Unity и содержит 100 000 GameObjects.
Поскольку этот заранее определенный список на самом деле не
существует, ввод этого кода в Unity не сработает, если вы не
определите `reallyLongList` самостоятельно (и не включите в него
GameObject с именем "Phil").  

**b.** Функция `MoveToOrigin()` вызывается со строковым литералом
"Phil" в качестве аргумента.  

**c.** Оператор `foreach` выполняет итерацию по `reallyLongList`.  

**d.** Если найден GameObject с именем "Phil" (т. е. theName)…  

**e.** …то он перемещается в точку [ 0, 0, 0 ].  

**f.** Строка 16 возвращает выполнение к строке 9. Это позволяет избежать
перебора остальной части списка.  

В `MoveToOrigin()` вам действительно не нужно проверять другие
GameObjects после того, как вы нашли тот, который называется Phil,
поэтому лучше прервать выполнение функции и вернуться, прежде чем
тратить вычислительные ресурсы на проверку остальной части списка.
Если Phil — последний GameObject в списке, вы не сэкономили время;
однако, если Phil — первый GameObject, вы сэкономили много времени.
