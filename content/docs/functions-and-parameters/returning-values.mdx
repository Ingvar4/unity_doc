---
title: Возврат значений
description: Помимо получения значений в качестве параметров, функции также могут возвращать одно значение, известное как результат функции.
---

```c#
public class FunctionsEx : MonoBehaviour {
    void Start() {
        int num = Add( 2, 5 );
        print( num ); // Prints the number 7 to the Console
    }

    int Add( int numA, int numB ) {
        int sum = numA + numB;
        return sum;
    }
}
```

В этом примере функция `Add()` имеет два параметра: целые числа `numA`
и `numB`. При вызове она сложит два переданных целых числа, а затем
вернет результат. Ключевое слово `int` в начале определения функции в
строке 11 объявляет, что `Add()` будет возвращать целое число в качестве
результата. Так же, как вы должны объявить тип любой переменной, чтобы
она работала, вы также должны объявить тип возвращаемого значения
функции, чтобы его  использовалась в других местах кода. И если вы объявляете тип
возвращаемого значения функции как что-то другое, кроме `void`, то вы
должны возвращать значение этого типа, иначе ваш код не
скомпилируется.
