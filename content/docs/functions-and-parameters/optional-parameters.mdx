---
title: Необязательные параметры
description: Иногда требуется, чтобы функция имела необязательные параметры, которые можно либо передать, либо опустить.
---

В последующем листинге кода  мы сделаем параметр `float newX` функции `SetX()` необязательным. Если в
определении функции значение по умолчанию в определении функции, компилятор будет
интерпретировать этот параметр как необязательный (например, в листинге кода, где для `float newX` задано значение по умолчанию `0.0f`).

```c#
public class FunctionsEx : MonoBehaviour {
    void Start() {
        SetX( this.gameObject, 25 ); // b
        print( this.gameObject.transform.position.x ); // Вывод: "25"
        SetX( this.gameObject ); // c
        print( this.gameObject.transform.position.x ); // Вывод: "0"
    }

    void SetX( GameObject go, float newX=0.0f ) { // a
        Vector3 tempPos = go.transform.position;
        tempPos.x = newX;
        go.transform.position = tempPos;
    }
}
```

**a.** Переменная типа `float newX` определена как необязательный
параметр со значением по умолчанию `0.0f`. Присвоение `newX`
значения по умолчанию в объявлении функции (часть =0.0f) и делает
`newX` необязательным параметром. Если для параметра `newX` не
передано никакого аргумента, будет использовано значение по
умолчанию.  

**b.** Поскольку тип `float` может содержать любое целое значение, передача
`int` в `float` вполне допустима. (Например, целочисленный литерал 25 в
строке 7 передается в качестве аргумента в параметр float newX в
строке 13.)  

>Если быть более точным, тип float может содержать большинство значений типа int. Тип float теряет точность при работе с
очень большими и очень маленькими числами, поэтому очень большое целое число может
быть округлено до ближайшего числа, которое может быть представлено типом float. Судя
по эксперименту, который я провёл в Unity, тип float, похоже, способен представлять любое
целое число в диапазоне до ± 16 777 217, после чего он теряет точность при представлении
целых чисел.  

**c.** В строке 9 аргумент `newX` не передается в метод `SetX()` (хотя для
обязательного параметра go аргумент передается). Если для
необязательного параметра аргумент не передается, используется
значение по умолчанию. В данном случае значение по умолчанию для
newX было определено как 0.0f в строке 13.  

При первом вызове из `Start()` параметр `newX` устанавливается в
`25.0f`, что переопределяет значение по умолчанию `0.0f`. Однако при
втором вызове параметр `newX` опущен, в результате чего `newX`
принимает значение по умолчанию `0.0f`.  

Необязательные параметры должны идти после всех обязательных
параметров в определении функции.
