title: Рекурсивные функции
description: Иногда функция создается так, чтобы вызывать саму себя повторно; это называется рекурсивной функцией.
---

Простой пример — вычисление факториала числа.  

В математике 5! (факториал числа 5) — это произведение этого числа на
каждое натуральное число, меньшее его. (Натуральные числа — это целые
числа, большие 0.)  

```
5! = 5 * 4 * 3 * 2 * 1 = 120
```  

Особым случаем в математике является то, что 0! равно 1.  

`0! = 1`  

Для наших целей давайте возвращать 0 всякий раз, когда в функцию
факториала передается отрицательное число, то есть:  

`-5! = 0`  

В коде показана рекурсивная функция `Fac()`, которая может
вычислять факториал любого целого числа:  

>Строго говоря, эта функция может вычислять факториал только положительных целых чисел от 1
до 12. Это связано с тем, что 13! (что равно 6 227 020 800) превышает максимальное значение типа
int (2 147 483 647). Еще одним ограничением рекурсии является то, что в Unity рекурсивные
функции могут вызываться не более 255 раз.  

```c#
public class FunctionsEx : MonoBehaviour {
    void Start() {
        print( Fac(5) ); // Outputs: "120" // a
        print( Fac(0) ); // Outputs: "1"
        print( Fac(-5) ); // Outputs: "0"
        print( Fac(10).ToString("#,##0") ); // Outputs: "3,628,800" // h
    }

    int Fac( int num ) { // b, d
        if (num < 0) return( 0 ); // This handles the case if num<0
        if (num == 0) return( 1 ); // This is the "terminal case" // e

        int result = num * Fac( num-1 ); // c, f
        return( result ); // g
    }
}
```

a. Когда вызывается функция `Fac()` с целочисленным параметром 5…  

b. …это запускает первую итерацию `Fac()` с `num = 5`.  

c. В строке 19 num (равное 5) затем умножается на результат вызова
`Fac()` со значением 4 (т. е. num–1). Этот процесс, при котором
функция вызывает саму себя, называется рекурсией…  

d. …что запускает вторую итерацию `Fac()` с `num = 4`. Процесс
продолжается до шестой итерации `Fac()`, где `num = 0`.  

e. Поскольку num равен 0, в пятую итерацию возвращается 1. Такой
случай, который завершает рекурсию, называется конечным случаем.
Здесь конечный случай наступает, когда `num = 0`.  

Обратите внимание, что оператор `if` может занимать одну строку
без фигурных скобок, если он достаточно короткий.  

f. Возвращенное из конечного случая значение 1 затем умножается на 1 *
1…  

g. …и передает 1 обратно в четвертую итерацию и так далее, пока не
завершатся все рекурсии `Fac()`, и первая итерация `Fac()` не вернет
значение 120 в строку 7.  

h. Всякий раз, когда вызывается `print()` для типа переменной,
который не является строкой, для этой переменной автоматически
вызывается `ToString()`; однако здесь мы использовали явный
формат числа «#,##0», чтобы указать `ToString()` ставить запятые
в разряде тысяч числа .  

>Существует несколько форматов чисел для `ToString()`, которые я всегда забываю
(например, «N0» даст нам тот же формат, что и «#,##0» (Примечание: все 0 здесь
означают нули) ), поэтому я часто обращаюсь к странице Microsoft по этой теме по адресу
https://docs.microsoft.com/en-us/dotnet/standard/base-types/standard-numeric-format-strings.  

Цепочка всех этих рекурсивных вызовов Fac() работает примерно так:  

```c#
Fac(5) // 1st Iteration
5 * Fac(4) // 2nd Iteration
5 * 4 * Fac(3) // 3rd Iteration
5 * 4 * 3 * Fac(2) // 4th Iteration
5 * 4 * 3 * 2 * Fac(1) // 5th Iteration
5 * 4 * 3 * 2 * 1 * Fac(0) // 6th Iteration
(Terminal case)
5 * 4 * 3 * 2 * 1 * 1 // 5th Iteration
5 * 4 * 3 * 2 * 1 // 4th Iteration
5 * 4 * 3 * 2 // 3rd Iteration
5 * 4 * 6 // 2nd Iteration
5 * 24 // 1st Iteration
120 // Final Return Value
```
Лучший способ по-настоящему понять, что происходит в этой рекурсивной
функции, — это изучить ее с помощью отладчика, функции Visual Studio,
которая позволяет наблюдать за каждым шагом выполнения ваших
программ и видеть, как ваш код влияет на различные переменные. Процесс
отладки является темой следующей главы.
