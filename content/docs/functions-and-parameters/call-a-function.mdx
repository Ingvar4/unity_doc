---
title: Что происходит при вызове функции?
description: Вызов функции приводит к ее выполнению, и когда функция завершается, выполнение возвращается к точке, из которой она была вызвана.
---

Таким образом, в классе `FunctionsEx` (из листинга кода предыдущей статьи) в каждом кадре происходит следующее:

1. В каждом кадре движок Unity вызывает функцию `Update()`
(строка 10).
2. В строке 11 увеличивается значение `numTimesCalled`.
3. В строке 12 вызывается `PrintUpdates()`.
4. Затем выполнение переходит к началу функции `PrintUpdates()`
на строке 15.
5. Выполняются строки 16 и 17.
6. Когда Unity доходит до закрывающей фигурной скобки
`PrintUpdates()` в строке 16, выполнение возвращается к
строке 12 (строке, из которой была произведена вызов).
7. Выполнение продолжается до строки 13, которая завершает функцию
`Update()`.  

Остальная часть этой главы посвящена как простому, так и сложному
использованию функций, а также представляет собой введение в
некоторые довольно сложные концепции. По мере прохождения учебных
примеров, представленных далее в этой книге, вы гораздо лучше поймете,
как работают функции, и получите больше идей для создания собственных
функций, поэтому если что-то не будет понятно при первом прохождении
этой главы - ничего страшного. Вы сможете вернуться к ней после того,
как прочитаете еще немного книги.

### Использование кода из этой главы в Unity [!toc]
Хотя в листинге кода в предыдущей статье приведены все строки скрипта `FunctionsEx`, в
последующих примерах кода их нет. Если вы хотите запустить
остальную часть кода из этой главы в Unity, вам необходимо
поместить его в класс. Раздел «Классы», подробно описывает
классы, но пока что вы можете сделать это, добавив строки в каждом листинге кода между
строками, которые начинают и заканчивают определение класса.

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class FunctionsEx : MonoBehaviour {
…     // All code listings in this chapter replace this comment
}
```  

```c#
public class FunctionsEx : MonoBehaviour {
    public int numTimesCalled = 0;// a

    void Update() {
        numTimesCalled++;// b
        PrintUpdates();// c
    }

    void PrintUpdates() {// d
        string outputMessage = "Updates: " + numTimesCalled; // e
        print( outputMessage ); // Output example: "Updates: 1" // f
    }
}
```
