---
title: Перегрузка функций
description: Перегрузка функций - это сложный термин, обозначающий способность функций в C# действовать по-разному в зависимости от типа и количества передаваемых им параметров.
---

Далее в коде демонстрируется перегрузка функций:

```c#
public class FunctionsEx : MonoBehaviour {
    void Start() {
        print( Add( 1.0f, 2.5f ) ); // a
        // ^ Prints: "3.5"
        print( Add( new Vector3(1, 0, 0), new Vector3(0, 1, 0) ) ); // a
        // ^ Prints "(1.0, 1.0, 0.0)"
        Color colorA = new Color( 0.5f, 1, 0, 1);
        Color colorB = new Color( 0.25f, 0.33f, 0, 1);
        print( Add( colorA, colorB ) ); // a
        // ^ Prints "RGBA(0.750, 1.000, 0.000, 1.000)"
    }

    float Add( float f0, float f1 ) { // b1
        return( f0 + f1 );
    }

    Vector3 Add( Vector3 v0, Vector3 v1 ) { // b2
        return( v0 + v1 );
    }

    Color Add( Color c0, Color c1 ) { // b3
        float r, g, b, a;
        r = Mathf.Clamp01( c0.r + c1.r ); // c
        g = Mathf.Clamp01( c0.g + c1.g ); // c
        b = Mathf.Clamp01( c0.b + c1.b ); // c
        a = Mathf.Clamp01( c0.a + c1.a ); // c
        return( new Color( r, g, b, a ) );
    }
}

```

**a.** Функция `Add()` вызывается с тремя различными типами
аргументов: сначала с числами с плавающей запятой, затем с
Vector3 и, наконец, с цветами.  

**b.** Здесь объявлены и определены три разных функции `Add()`, и
каждая из них вызывается в зависимости от аргументов,
передаваемых различными строками функции `Start()`.
- b1 Когда передаются два числа с плавающей запятой, используется версия `Add()` для чисел с плавающей запятой `Add() ` 
- b2 Когда передаются два объекта Vector3, используется
версия Vector3  
- b3 Когда передаются два объекта Color, используется
версия Color  

**c.** В версии `Add()` для Color принимаются меры, чтобы r, g, b или `a` не
превышали 1, поскольку красный, зеленый, синий и альфа-каналы
объекта Color ограничены значениями от 0 до 1. Это достигается с
помощью функции `Mathf.Clamp01()`. `Mathf.Clamp01()`
принимает в качестве аргумента одно число с плавающей запятой.
Если это число меньше 0, она вернет 0. Если это число больше 1, она
вернет 1. В противном случае будет возвращено исходное число. Для
значения зеленого `0.33f + 1` будет равно `1.33f`, но `Clamp01()`
уменьшит его до 1.
