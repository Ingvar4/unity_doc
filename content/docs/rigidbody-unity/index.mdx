### Параметры Rigidbody: [!toc]
- Use Gravity - false (предмет не будет падать)
- Is Kinematic - true (Установка для Rigidbody параметра «Is Kinematic» сообщает физическому движку Unity, что вы будете перемещать объект с помощью кода, и предотвращает автоматическое перемещение объекта системой физики)
