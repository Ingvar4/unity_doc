---
title: Более интересный подход к перемещению
description: Поскольку вы используете целое значение dirHeld, лежащее в диапазоне от 0 до 3, можно применять dirHeld весьма интересными способами.
---

Например, блок switch case, помеченный `//b` в листинге кода, носит весьма повторяющийся характер и использует значение dirHeld
для выбора одного из четырёх направлений. Посмотрите на листинг, чтобы увидеть, как мы
можем использовать значение dirHeld от 0 до 3 для обработки скорости менее повторяющимся способом.  

1. Откройте скрипт Dray в Visual Studio и добавьте код:  
        Листинг Dray.cs

```c#
public class Dray : MonoBehaviour {
    …
    [Header("Dynamic")]
    public int dirHeld = -1; // Direction of the held movement key

    private Rigidbody2D rigid;

    private Vector2[] directions = new Vector2[] {
        Vector2.right, Vector2.up, Vector2.left, Vector2.down }; // a


    void Awake () { … }

    void Update () { // Note: This is the entire current Update method
        dirHeld = -1;
        if ( Input.GetKey(KeyCode.RightArrow) ) dirHeld = 0;
        if ( Input.GetKey(KeyCode.UpArrow ) ) dirHeld = 1;
        if ( Input.GetKey(KeyCode.LeftArrow ) ) dirHeld = 2;
        if ( Input.GetKey(KeyCode.DownArrow ) ) dirHeld = 3;

        Vector2 vel = Vector2.zero;
        // Delete the entire switch clause that was here in Code Listing 35.4
        // switch (dirHeld) { … }
        if (dirHeld > -1) vel = directions[dirHeld]; // b

        rigid.velocity = vel * speed;
    }
}
```

- a. Этот массив Vector2[] directions позволяет легко обращаться к каждому из четырех
векторов направления, используя число от 0 до 3 (допустимые значения dirHeld). Также
обратите внимание, что весь объявление и определение directions представляет собой одно
выражение, разбитое на две строки (только строка с `// a` заканчивается точкой с запятой,
завершая выражение).
- b. Эта одна строка заменила весь 14-строчный блок switch из листинга кода!  

Если вы попробуете снова запустить игру в Unity, то увидите, что вам удалось сохранить ту же
функциональность, используя гораздо меньше строк кода. Вы будете продолжать использовать
диапазон [0..3] dirHeld таким образом, чтобы упростить код в этой главе.

### Лучший способ обработки клавиш ввода [!toc]

Подобно массиву directions, вы также можете хранить клавиши, которые хотите использовать
для перемещения, в массиве.  

1. Откройте скрипт Dray в Visual Studio и внесите изменения в код:  
            Листинг кода Dray.cs
```c#
public class Dray : MonoBehaviour {
    …
    private Rigidbody2D rigid;

    private Vector2[] directions = new Vector2[] {
        Vector2.right, Vector2.up, Vector2.left, Vector2.down };

    private KeyCode[] keys = new KeyCode[] {
        KeyCode.RightArrow, KeyCode.UpArrow, KeyCode.LeftArrow, KeyCode.DownArrow, KeyCode.D, KeyCode.W, KeyCode.A, KeyCode.S }; // a

    void Awake () { … }

    void Update () { // Note: This is the entire current Update method
        dirHeld = -1;
        // Delete all four "if ( Input.GetKey..." lines that were here
        // if ( Input.GetKey(KeyCode.RightArrow) ) dirHeld = 0;
        // if ( Input.GetKey(KeyCode.UpArrow ) ) dirHeld = 1;
        // if ( Input.GetKey(KeyCode.LeftArrow ) ) dirHeld = 2;
        // if ( Input.GetKey(KeyCode.DownArrow ) ) dirHeld = 3;
        for (int i=0; i <keys.Length; i++) {
        if ( Input.GetKey(keys[i]) ) dirHeld = i % 4; // b
        }

        Vector2 vel = Vector2.zero;
        if (dirHeld > -1) vel = directions[dirHeld];

        rigid.velocity = vel * speed;
    }
}
```

        - a. Этот массив позволяет легко получить доступ к KeyCodes для всех четырех стрелок и WASD.
        - b. Этот цикл for проходит по всем возможным KeyCodes из массива keys и определяет,
удерживается ли какая-либо из них. Оператор % 4 в конце приведет к тому, что клавиша W (i
== 5) установит dirHeld равным 1 (поскольку 5 % 4 равно 1), точно так же, как и стрелка
вверх.  

С новым массивом `KeyCode[]` keys вы снова воспользовались особенностью dirHeld,
принимающей значения от 0 до 3, и сохранили возможность использовать клавиши со стрелками
благодаря более качественному коду. Кроме того, вы также получили управление WASD для тех,
кто его предпочитает.

### Анимация ходьбы Дрея [!toc]

Далее вы свяжете движение Дрея с его анимацией.  

1. Еще раз откройте скрипт Dray в Visual Studio и добавьте код, показанный в листинге.  
        Листинг кода Dray.cs
```c#
public class Dray : MonoBehaviour {
    …

    private Rigidbody2D rigid;
    private Animator anim; // a

    private Vector2[] directions = new Vector2[] {
    Vector2.right, Vector2.up, Vector2.left, Vector2.down };
    …

    void Awake () {
        rigid = GetComponent<Rigidbody2D>();
        anim = GetComponent<Animator>(); // b
    }

    void Update () {
        …
        rigid.velocity = vel * speed;

        // Animation
        if (dirHeld == -1) { // c
            anim.speed = 0;
        } else {
            anim.Play( "Dray_Walk_"+ dirHeld ); // d
            anim.speed = 1;
        }
    }
}
```

        - a. Обязательно добавьте это поле anim.
        - b. Сохраните ссылку на компонент Animator объекта Dray в частном поле anim.
        - c. Если ни одна клавиша направления не удерживается (т. е. dir == -1), то скорость аниматора
anim устанавливается равной 0, что приостанавливает текущую анимацию.
        - d. Если Dray движется в каком-либо направлении, число dirHeld добавляется в конец строки
«Dray_Walk_», что дает вам имя одной из анимаций, которые вы добавили к Dray!  

>Если ваши анимации Dray не работают, проверьте еще раз, правильно ли они названы: Dray_Walk_0, Dray_Walk_1,
Dray_Walk_2 и Dray_Walk_3.  

Функция anim.Play() указывает аниматору anim переключиться на новую анимацию по
имени. Если anim уже показывает указанную анимацию, это не дает никакого эффекта.  

2. Сохраните скрипт Dray и вернитесь в Unity.  

Теперь вы можете запустить игру и увидеть, что Дрей анимируется при перемещении.

### Добавление анимации атаки для Dray [!toc]

Пришло время дать Dray возможность атаковать! Для этого сначала нужно придать ему позу анимации
атаки. (Урон, наносимый атакой Dray врагам, вы реализуете в следующей главе.)

#### Создание анимаций поз атаки [!toc]

Создайте позы атаки, выполнив следующие действия:  

1. Выберите Дрея в иерархии и перейдите на панель «Анимация» (Window > Animation в
панели меню Unity).
2. Создайте новую анимацию с именем Dray_Attack_0:
    - a. С помощью селектора анимации выберите «Создать новый клип» и сохраните новый
клип как вDryaAtck0a папке _Animations.
    - b. Выберите Dray_Atack0 в селекторе анимации.
    - c. Установите количество кадров для Dray_Attack_0 равным 10.
    - d. Выберите спрайт DrayAtack0, расположенный под изображением Dray в папке _Images на панели «Проект».
    - e. Перетащите спрайт DrayAtack0 из панели «Проект» в область временной шкалы окна «Анимация».
3. Повторите шаги 2a–2e еще три раза, чтобы создать анимации с именами Dray_Attack_1,
Dray_Attack_2 и Dray_Attack_3 и назначить для каждой из них соответствующий спрайт.  

Если вы проверите панель «Аниматор», то увидите, что все четыре новые анимации атаки теперь
отображаются в аниматоре для Dray. Теперь вы также должны увидеть восемь анимаций и один
аниматор в папке _Animations на панели «Проект».

### Программирование анимаций атак [!toc]
Чтобы добавить код для другого состояния анимации в класс Dray, вам нужно немного усложнить
класс. Одним из аспектов этого будет различение между dirHeld (направление в настоящее время
удерживаемой клавиши движения) и новым полем facing (направление, в котором смотрит Dray).
На выполнение атаки Dray уйдет определенное время (по умолчанию 0,25 секунды), и пока Dray
атакует, его вращение будет временно заморожено на время атаки. Если в это время игрок изменит
удерживаемую клавишу, dirHeld изменится, но facing останется прежним до завершения
атаки.  

1. Добавьте новый тип перечисления eMode и шесть дополнительных полей для обработки
возросшей сложности. Откройте скрипт Dray в Visual Studio и добавьте код:  
        Листинг кода Dray.cs

```c#
public class Dray : MonoBehaviour {
    public enum eMode { idle, move, attack } // a

    [Header("Inscribed")]
    public float speed = 5;
    public float attackDuration = 0.25f;// Number of seconds to attack
    public float attackDelay = 0.5f; // Delay between attacks


    [Header("Dynamic")]
    public int dirHeld = -1; // Direction of the held movement key
    public int facing = 1; // Direction Dray is facing
    public eMode mode = eMode.idle; // a

    private float timeAtkDone = 0; // b
    private float timeAtkNext = 0; // c

    private Rigidbody2D rigid;
    private Animator anim;

    private Vector2[] directions = new Vector2[] {
    Vector2.right, Vector2.up, Vector2.left, Vector2.down };

    …
}
```

- a. Перечисление eMode и поле mode предоставляют вам расширяемый способ
отслеживания и запроса состояния Dray. Этот тип перечисления можно назвать просто
eMode (в отличие от, например, eDrayMode), поскольку он определяется внутри класса
Dray. Таким образом, если какой-либо другой класс захочет его использовать, он будет
обращаться к нему как к Dray.eMode.
- b. timeAtkDone — это время, к которому должна завершиться анимация атаки.
- c. timeAtkNext — это время, когда Dray сможет начать очередную атаку.  

Поскольку эти новые поля приводят к значительным изменениям в работе метода `Update()`, в
листинге кода приведен весь метод `Update()` класса Dray. Он включает в себя все те же
концепции, что и в предыдущих листингах кода, просто немного перегруппированные.  

2. Полностью замените метод `Update()` в вашем классе Dray кодом из листинга.  
        Листинг Dray.cs  

```c#
public class Dray : MonoBehaviour {
    …
    void Update () {
        // Delete everything that was in Update() prior to this Code Listing

        // Finishing the attack when it’s over
        if (mode == eMode.attack && Time.time >= timeAtkDone) { // a
            mode = eMode.idle;
        }

        //———————————— Handle Keyboard Input in idle or move Modes ————————————
        if (mode == eMode.idle || mode == eMode.move) { // b
            dirHeld = -1;
            for (int i=0; i <keys.Length; i++) {
                if ( Input.GetKey(keys[i]) ) dirHeld = i % 4;
            }

            // Choosing the proper movement or idle mode based on dirHeld
            if (dirHeld == -1) { // c
                mode = eMode.idle;
            } else {
                facing = dirHeld; // d
                mode = eMode.move;
            }

            // Pressing the attack button
            if (Input.GetKeyDown(KeyCode.Z) && Time.time >= timeAtkNext) { // e
                mode = eMode.attack;
                timeAtkDone = Time.time + attackDuration;
                timeAtkNext = Time.time + attackDelay;
            }
        }

        //———————————————————— Act on the current mode ————————————————————
        Vector2 vel = Vector2.zero;
        switch (mode) { // f
            case eMode.attack: // Show the Attack pose in the correct direction
            anim.Play( "Dray_Attack_" +facing );
            anim.speed = 0;
            break;

            case eMode.idle: // Show frame 1 in the correct direction
            anim.Play( "Dray_Walk_" +facing );
            anim.speed = 0;
            break;

            case eMode.move: // Play walking animation in the correct direction
            vel = directions[dirHeld];
            anim.Play( "Dray_Walk_" +facing );
            anim.speed = 1;
            break;
        }

        rigid.velocity = vel * speed;
    }
}
```

        - a. После перехода Dray в режим атаки он остается на месте до завершения атаки (что происходит
через attackDuration секунд [по умолчанию 0,25 секунды]). По истечении этого времени
режим возвращается в eMode.idle.
        - b. Дрей должен реагировать на ввод с клавиатуры только в режимах eMode.idle или
eMode.move. Размещение этой проверки здесь упростит работу над остальной частью
проекта.
        - c. Этот код выбирает между eMode.idle и eMode.move в зависимости от того,
удерживается ли какая-либо клавиша движения (т. е. dirHeld > -1).
        - d. Направление (facing) устанавливается исключительно здесь. Dray меняет направление
только при движении в каком-либо направлении. Это гарантирует, что Dray сохраняет
постоянное направление при атаке. Это также приводит к тому, что Dray продолжает
смотреть в направлении последнего движения, когда стоит на месте.
        - e. Если нажата кнопка атаки (клавиша Z на клавиатуре) и прошло достаточно времени с момента
последней атаки, то mode устанавливается в eMode.attack.
Кроме того, устанавливаются поля timeAtkDone и timeAtkNext, сообщающие экземпляру
Dray, когда ему следует остановить анимацию атаки и когда он сможет атаковать снова.
Это помещается в коде после кода перемещения в `// c`, чтобы нажатие Z имело приоритет над
клавишами движения.
        - f. После того как определен нужный режим для Dray, это оператор switch управляет тем,
что происходит в рамках этого режима. Здесь обрабатываются как anim, так и vel. vel
изначально устанавливается в Vector2.zero, чтобы по умолчанию не было движения, и
изменяется только тогда, когда Dray движется.
Теперь, когда Дрей будет смотреть в нужном направлении и сможет принимать боевую позу,
добавить оружие к атаке будет легко.
