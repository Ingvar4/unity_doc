Вы исправите обе эти проблемы с помощью панели *Animation*.

1. Нажмите на три вертикальные точки ( ⋮ ) в правом верхнем углу панели «Игра».
2. В этом меню выберите «Добавить вкладку» >«Анимация», чтобы открыть панель «Анимация» в
виде вкладки в той же панели, что и окно «Игра» (как показано в нижней части рисунка).
3. Чтобы панель «Анимация» выглядела так, как показано на рис., выберите Dray в
иерархии и раскройте треугольник рядом с Dray : Sprite на панели «Анимация».  

В левом верхнем углу панели «Анимация» находится всплывающее меню, в котором в данный момент
отображается Dray_Walk_0 (обведено красным прямоугольником на рис.). В оставшейся части
этого раздела я буду называть это всплывающее меню «Селектором анимации». Справа от селектора
анимации находится поле для ввода количества кадров (обведено синим прямоугольником на рис.). Параметр «Образцы» задает частоту воспроизведения анимации (это количество кадров,
отображаются каждую секунду). Если вы не видите поле «Samples», щелкните три вертикальные
точки ( ⋮ ) в правой части панели «Animation» (под курсором мыши на рис.) и выберите
«Показать частоту сэмплирования» в появившемся контекстном меню.  

4. Установите для параметра «Samples» значение 10. В результате Дрей будет делать примерно 5 шагов в
секунду.
5. Чтобы увидеть предварительный просмотр этого движения Дрея на панели «Сцена»:
    - a. Переключитесь на панель «Сцена» (щелкните вкладку «Сцена», чтобы отобразить её вместо
панели «Аниматор»).
    - b. Дважды щелкните Dray в иерархии, чтобы выделить его в сцене.
    - c. На панели «Анимация» нажмите кнопку «Воспроизведение анимации» (это серый треугольник,
направленный вправо, расположенный чуть выше селектора анимации).
6. Нажмите кнопку «Воспроизведение анимации» еще раз, чтобы
остановить воспроизведение. Далее вы продолжите этот процесс,
чтобы добавить Дрею больше анимаций.

### Добавление дополнительных анимаций для Dray [!toc]

Вам нужно добавить дополнительные анимации для Dray, чтобы он мог ходить во всех четырех
направлениях.  

1. На панели «Анимация» щелкните меню «Выбор анимации» и выберите «Создать новый клип».
2. Назовите новый клип анимации Dray_Walk_1.anim и сохраните его в папке _Animations.
3. Установите количество сэмплов новой анимации Dray_Walk_1 равным 10.
4. Выберите файлы Dray_Walk_1a и Dray_Walk_1b на панели «Проекты» и перетащите их в область
временной шкалы на панели «Анимация» (где на рисунке видны изображения персонажа
Dray).

В результате Dray_Walk_1 будет выглядеть так же, как на панели «Анимация» на рис., за
исключением того, что теперь в анимации Дрей смотрит вверх (в направлении 1). Вы можете
просмотреть эту анимацию движения вверх в окне «Сцена», нажав кнопку «Воспроизведение
анимации» на панели «Анимация».  

5. Повторите шаги с 1 по 4 этого раздела для Dray_Walk_2 и Dray_Walk_3, используя
соответствующие имена и спрайты для каждого из них и не забывая установить значение
параметра «Сэмплы» равным 10.
6. Сохраните сцену, когда закончите.  

Если вы вернетесь к панели «Animator» (выберите «Window» > «Animation» > «Animator» в панели меню
Unity), то увидите, что здесь для Dray теперь также перечислены четыре состояния (как показано на
рисунке). Этот «Animator» является компонентом GameObject Dray в иерархии и связывает
GameObject Dray с четырьмя анимациями спрайтов Dray_Walk_#.

### Перемещение Dray [!toc] 

Прежде чем перемещать Dray, необходимо добавить к нему Rigidbody 2D.  

1. Выберите GameObject Dray в иерархии.
2. Прикрепите компонент Rigidbody 2D к Dray (Component > Physics 2D > Rigidbody 2D). Вам нужен
Rigidbody 2D вместо стандартного 3D Rigidbody, который мы использовали в других проектах,
потому что Tilemaps в Unity могут сталкиваться только с Rigidbody 2D.
3. В компоненте Rigidbody 2D объекта Dray:
    - a. Установите Gravity Scale на 0 (число ноль). Это аннулирует силу тяжести на этом
GameObject.
    - b. В раскрывающемся треугольнике Constraints установите для параметра Freeze Rotation Z значение
true (флажок установлен).
4. Сохраните сцену.
Теперь добавьте скрипт к Dray, чтобы заставить его двигаться.
5. Создайте скрипт на C# с именем Dray в папке « Scripts».
6. Прикрепите скрипт Dray на C# к объекту Dray в иерархии.
7. Откройте скрипт Dray в Visual Studio и введите код в листинге: 

        Листинг кода Dray.cs
```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class Dray : MonoBehaviour {
    [Header("Inscribed")]
    public float speed = 5;

    [Header("Dynamic")]
    public int dirHeld = -1; // Direction of the held movement key

    private Rigidbody2D rigid;

    void Awake () {
        rigid = GetComponent<Rigidbody2D>();
    }

    void Update () {
        dirHeld = -1;
        if ( Input.GetKey( KeyCode.RightArrow ) ) dirHeld = 0; // a
        if ( Input.GetKey( KeyCode.UpArrow ) ) dirHeld = 1;
        if ( Input.GetKey( KeyCode.LeftArrow ) ) dirHeld = 2;
        if ( Input.GetKey( KeyCode.DownArrow ) ) dirHeld = 3;

        Vector2 vel = Vector2.zero;
        switch (dirHeld) { // b
            case 0:
            vel = Vector2.right;
            break;
            case 1:
            vel = Vector2.up;
            break;
            case 2:
            vel = Vector2.left;
            break;
            case 3:
            vel = Vector2.down;
            break;
        }

        rigid.velocity = vel * speed;
    }

    // void Start() {…} // Please delete the unused Start() method
}
```

        - a. Из-за расположения четырех однострочных условий if в начале функции `Update()`, если
одновременно удерживаются несколько клавиш со стрелками, последняя строка, которая
оценивается как true, переопределяет остальные (например, если удерживаются клавиши вниз и
вправо, Дрей будет двигаться только вниз). Поскольку эта игра очень проста, я решил сделать
так, чтобы она работала именно так, хотя, возможно, вам захочется улучшить это после
завершения данной главы. Однако имейте в виду, что в оригинальной игре Legend of Zelda для
NES Линк не может двигаться по диагонали.
        - b. В следующем разделе весь этот блок switch будет заменен более качественным кодом.  

8. Сохраните скрипт Dray, вернитесь в Unity и нажмите «Play».  

Теперь с помощью клавиш со стрелками вы можете очень просто перемещать Дрея по сцене.
