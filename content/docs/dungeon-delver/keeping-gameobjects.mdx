---
title: Удержание GameObjects в комнате
description: Одним из важнейших применений InRoom станет удержание скелетов и других врагов в пределах комнаты, в которой они появились (без использования для этого коллайдеров).
---

Сейчас мы можем
написать и протестировать код на Дрее, а затем применить его к скелетам после завершения
тестирования. Для этого необходимо добавить в InRoom метод LateUpdate(), который в каждом
кадре проверяет, не вышел ли GameObject за пределы основной зоны комнаты. В каждом кадре Unity
сначала вызывает Update() для всех скриптов MonoBehaviour, прикрепленных к GameObjects, а
затем вызывает метод LateUpdate() для каждого из них. LateUpdate() отлично
подходит для операций очистки, таких как возвращение блуждающих персонажей в комнату, в
которой они должны находиться.  

>Например, если у пяти GameObjects есть метод Update(), а у двух из них есть метод LateUpdate(), то
Update() будет вызван для всех пяти, а затем LateUpdate() будет вызван для тех двух, у которых есть метод
LateUpdate().  

1. Прикрепите скрипт InRoom к объекту Dray в иерархии.
2. Откройте InRoom в Visual Studio и добавьте код.  
        Листинг кода InRoom.cs  

```c#
public class InRoom : MonoBehaviour {
    static public float ROOM_W = 16;
    static public float ROOM_H = 11;
    static public float WALL = 2;

    [Header("Inscribed")]
    public bool keepInRoom = true;
    public float gridMult = 1; // a
    public float radius = 0.5f; // b

    void LateUpdate() {
        if ( !keepInRoom ) return; // c
        if ( isInRoom ) return;

        Vector2 posIR = posInRoom; // d
        posIR.x = Mathf.Clamp(posIR.x, WALL+radius, ROOM_W - WALL - radius); // e
        posIR.y = Mathf.Clamp(posIR.y, WALL+radius, ROOM_H - WALL - radius);
        posInRoom = posIR; // f
    }

    public bool isInRoom { // g
        get {
            Vector2 posIR = posInRoom; // h
            if ( posIR.x < WALL + radius
                || posIR.x > ROOM_W - WALL - radius
                || posIR.y < WALL + radius
                || posIR.y > ROOM_H - WALL - radius ) {
                return false;
            }
            return true;
        }
    }

    // Where is this character in local room coordinates?
    public Vector2 posInRoom { … }
    …
}
```  

    - a. Поле gridMult будет использоваться позже в этой главе.
    - b. Радиус всех врагов в этой главе равен 0.5f, но это общедоступное поле, чтобы вы могли
позже создавать более крупных игровых персонажей, если захотите (например, огромного
босса-дракона в конце подземелья Орла в игре The Legend of Zelda).
    - c. Если keepInRoom не отмечено, то этот метод завершится, не выполняя никаких действий.
Следующая строка заставляет этот метод возвращаться, если данный GameObject все еще
находится в комнате.
    - d. Как свойство, posInRoom пересчитывается каждый раз при обращении к нему. Для большей
эффективности значение posInRoom вычисляется один раз за цикл LateUpdate() и
кэшируется в локальной переменной posIR.
    - e. Метод Mathf.Clamp() принимает значение (posIR.x), которое будет ограничено
диапазоном между минимальным значением (WALL + radius) и максимальным значением
(ROOM_W
- WALL - radius). Это позволяет удержать posIR в пределах стен комнаты (на основе
значения радиуса).
    - f. После завершения проверки на наличие стен комнаты значение posIR присваивается
обратно posInRoom, что приводит к выполнению условия set свойства posInRoom и
перемещению GameObject.
    - g. isInRoom возвращает true, если этот GameObject полностью находится в пределах стен
комнаты.
    - h. Это довольно сложное выражение if проверяет все четыре направления, в которых этот
GameObject может оказаться за пределами комнаты. Если любой из этих четырех случаев
выполняется, isInRoom возвращает false. Поскольку `||` является сокращенным OR, как
только любая из этих проверок дает false, остальные проверки пропускаются.
3. Сохраните скрипт InRoom и вернитесь в Unity, чтобы протестировать его. Теперь, если вы
попытаетесь завести Дрея в дверной проем, ему помешает это сделать функция LateUpdate()
(в других местах ему мешает Tilemap_Collision). (Помните, что для работы ввода с клавиатуры
может потребоваться щелчок в панели Game.)
4. Теперь, когда мы это протестировали, нам нужно разрешить Дрею покинуть комнату, поэтому,
пожалуйста, установите
поле keepInRoom компонента InRoom Дрея в false (не отмечайте).
5. Вам также нужно прикрепить скрипт InRoom к GameObject Skeletos в иерархии:
    - a. Прикрепите скрипт InRoom к объекту Skeletos, перетащив скрипт InRoom из панели «Проект» на
объект Skeletos в иерархии.
    - b. Выберите Skeletos в иерархии и убедитесь, что к нему прикреплен компонент InRoom (Script).
    - c. В компоненте InRoom объекта Skeletos убедитесь, что поле keepInRoom имеет
значение true (отмечено), gridMult равно 1, а radius — 0,5.
6. Нажмите «Play» в Unity и проверьте, что Skeletos действительно остается в пределах комнаты, а
Dray теперь может войти в дверной проем.
7. Остановите воспроизведение и сохраните сцену.  

Как вы увидите в остальной части этой главы, простая, компонентная природа скрипта InRoom
позволит использовать его не только для удержания GameObjects в нужном помещении.
