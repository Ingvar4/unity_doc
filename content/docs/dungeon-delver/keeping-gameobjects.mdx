---
title: Удержание GameObjects в комнате
description: Одним из важнейших применений InRoom станет удержание скелетов и других врагов в пределах комнаты, в которой они появились (без использования для этого коллайдеров).
---

Сейчас мы можем
написать и протестировать код на Дрее, а затем применить его к скелетам после завершения
тестирования. Для этого необходимо добавить в InRoom метод LateUpdate(), который в каждом
кадре проверяет, не вышел ли GameObject за пределы основной зоны комнаты. В каждом кадре Unity
сначала вызывает Update() для всех скриптов MonoBehaviour, прикрепленных к GameObjects, а
затем вызывает метод LateUpdate() для каждого из них. LateUpdate() отлично
подходит для операций очистки, таких как возвращение блуждающих персонажей в комнату, в
которой они должны находиться.
