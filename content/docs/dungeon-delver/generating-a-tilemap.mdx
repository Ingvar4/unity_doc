---
title: Создание карты плиток на основе данных
description: Теперь, когда у вас есть палитра плиток Palette_Visual, карта плиток Tilemap_Visual и текстовый файл DelverLevel_Eagle, в котором указано, какую плитку куда разместить, вы можете объединить их в реальную карту.
---

Для этого вам нужно создать класс MapInfo, который будет анализировать
данные DelverLevel_Eagle, и класс TilemapManager, который будет размещать их в карте плиток
Tilemap_Visual.
