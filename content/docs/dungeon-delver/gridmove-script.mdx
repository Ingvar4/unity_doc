---
title: Скрипт GridMove
description: Вы сможете применить GridMove к любому GameObject с классом, реализующим IFacingMover.
---

1. Создайте новый скрипт на C# с именем GridMove в папке *__Scripts* в разделе «Scripts».
2. Прикрепите скрипт GridMove к объекту Dray.
3. Откройте скрипт GridMove в Visual Studio и введите код.  
        Листинг кода GridMove.cs

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class GridMove : MonoBehaviour {
    private IFacingMover mover;

    void Awake() {
        mover = GetComponent<IFacingMover>(); // a
        if (mover == null) {
            Debug.LogError("Cannot find IFacingMover on " + gameObject.name);
        }
    }

    void FixedUpdate() { // b
        if (!mover.moving) return; // If not moving, nothing to do here
        int facing = mover.GetFacing();

        // If we are moving in a direction, align to the grid
        // First, get the grid location
        Vector2 posIR = mover.posInRoom;
        Vector2 posIRGrid = mover.GetGridPosInRoom();
        // This relies on IFacingMover (which uses InRoom) to choose grid spacing

        // Then move towards the grid line
        float delta = 0; // c
        if (facing == 0 || facing == 2) {
            // If the movement is horizontal, align to posIRGrid.y
            delta = posIRGrid.y - posIR.y;
        } else {
            // If the movement is vertical, align to posIRGrid.x
            delta = posIRGrid.x - posIR.x;
        }
        if (delta == 0) return; // Already aligned to the grid

        float gridAlignSpeed = mover.GetSpeed() * Time.fixedDeltaTime; // d
        gridAlignSpeed = Mathf.Min(gridAlignSpeed, Mathf.Abs(delta));
        if (delta < 0) gridAlignSpeed = -gridAlignSpeed;

        if (facing == 0 || facing == 2) { // e
            posIR.y += gridAlignSpeed;
        } else {
            posIR.x += gridAlignSpeed;
        }

        mover.posInRoom = posIR; // f
    }

    // void Start() {…} // Please delete the unused Start() and Update() methods
    // void Update() {…}
}
```

- a. `GetComponent<IFacingMover>()` находит любой компонент, прикреплённый к данному
GameObject, который реализует интерфейс IFacingMover. В настоящее время этот метод
возвращает ссылку на Dray или Skeletos и будет одинаково хорошо работать с любыми
будущими классами, реализующими интерфейс IFacingMover. Если к данному GameObject
не прикреплён компонент IFacingMover, мы регистрируем ошибку (красное сообщение в
консоли), поскольку это требует устранения.
- b. Перемещение по сетке реализовано как часть FixedUpdate(), так как именно в этот
момент физический движок обновляется и фактически перемещает различные GameObjects.
- c. delta — это величина расстояния от posIR (местоположение GameObject в комнате) до
ближайшей линии сетки, параллельной направлению движения. Если GameObject движется по
горизонтали, то GridMove заставит его также двигаться вверх или вниз до ближайшей линии
сетки по оси Y.
- d. gridAlignSpeed равна скорости движения в направлении к линии сетки, поэтому при
выравнивании по сетке GameObject будет двигаться под углом 45°, пока не выровняется по
сетке. (При выравнивании по сетке GameObject движется с общей скоростью
mover.GetSpeed() × 1.414, чтобы скорость в направлении, выбранном игроком, оставалась
постоянной.)
- e. Движение gridAlignSpeed применяется в направлении, перпендикулярном направлению
facing.
- f. Установка значения mover.posInRoom фактически изменяет положение GameObject.  

4. Сохраните все скрипты в Visual Studio, вернитесь в Unity и нажмите «Play».  

По мере перемещения Dray вы увидите, что он постепенно выравнивается по сетке с шагом в
одну единицу. Это значительно упрощает выравнивание по двери.  

>Если на этом этапе вы получите несколько ошибок NullReferenceException, то, скорее всего, это произошло потому, что вы
не добавили строку `// d` из листинга кода в класс Dray.  

5. Остановите воспроизведение.
6. Выберите Dray и установите значение gridMult в инспекторе InRoom равным 0,5  

Проведите тест еще раз, и вы увидите, что теперь можете перемещаться по полуячейкам, как в The
Legend of Zelda. Эта полуячейка необходима для выравнивания с дверями, которые вы в конечном
итоге встретите в верхних и нижних стенах комнат.  

7. Прикрепите скрипт GridMove к GameObject Skeletos в иерархии.
8. Сохраните сцену и нажмите «Play».  

Если вы посмотрите внимательно, то увидите, что Skeletos теперь перемещается по сетке с шагом в
одну единицу. Если это не очевидно сразу, вы можете использовать инструмент перемещения,
чтобы перетащить Skeletos по комнате и увидеть, как он затем возвращается на сетку. Интерфейс
IFacingMover позволил нам использовать один и тот же код в двух совершенно разных классах:
Dray и Skeletos.
