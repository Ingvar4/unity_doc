## Booleans

Как вы узнали в предыдущей главе, bool - это переменная, которая может принимать значение true или false. Булевы переменные были названы в честь Джорджа Буля, математика, который работал со значениями «true» и «false» и логическими операциями (ныне известными как «булевы операции»). Хотя во время его исследований компьютеров еще не существовало, компьютерная логика в основном основана на его работах, поскольку каждый транзистор в процессоре компьютера может находиться в состоянии «включено» или «выключено» (т. е. «true» или «false»). 

В программировании на C# переменные типа bool используются для хранения простой информации о состоянии игры (например, `bool gameOver = false`) и для управления потоком программы с помощью операторов `if` и `switch`, которые будут рассмотрены далее в этой главе. 

### Булевы операции 
Булевы операции позволяют программистам изменять или комбинировать переменные типа bool с помощью значимых операций.  

#### `!` (Оператор NOT)

Оператор `!` (произносится как «not» или «bang») меняет значение переменной типа bool на противоположное. False становится true, а true становится false: 

```c#
print( !true ); // Output: false
print( !false ); // Output: true
print( !(!true) ); // Output: true (the double negative of true is true)
```

`!` также иногда называют оператором логического отрицания, чтобы отличить его от `~` (оператора побитового отрицания).  

#### `&&`(оператор AND)

Оператор `&&` возвращает true только в том случае, если оба операнда являются true: 

```c#
print( false && false ); // false
print( false && true ); // false
print( true && false ); // false
print( true && true ); // true
```

#### `||` (Оператор OR) 

Оператор `||` возвращает true, если хотя бы один из операндов истинный, а также если оба истинны: 

```c#
print( false || false ); // false
print( false || true ); // true
print( true || false ); // true
print( true || true ); // true
```

#### Операторы логики с ускоренным вычислением и без него (Shorting Versus Non-Shorting)

Стандартные формы операторов AND и OR (`&&` и `||`) являются операторами с сокращением, что означает: как только оператор определил возвращаемое значение, он возвращает его, не выполняя остальную часть кода.  

**Листинг ShortingOperatorTestClass.cs**

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class ShortingOperatorTestClass : MonoBehaviour {
    // Start is called by Unity before the first frame update
    void Start() {
        ShortingOperatorTest(); // This line calls the test method // a
    }

    // This function prints "--true" and returns a true value.
    bool printAndReturnTrue() {
        print( "--true" );
        return ( true );
    }

    // This function prints "--false" and returns a false value.
    bool printAndReturnFalse() {
        print( "--false" );
        return ( false );
    }

    void ShortingOperatorTest() {
        // The first half of this test uses the shorting && and ||
        bool tfAnd = ( printAndReturnTrue() && printAndReturnFalse() ); // b
        print( "Non-Shorted && tfAnd: " + tfAnd );

        bool tfAnd2 = ( printAndReturnFalse() && printAndReturnTrue() ); // c
        print( "Shorted && tfAnd2: " + tfAnd2 );

        bool tfOr = ( printAndReturnTrue() || printAndReturnFalse() ); // d
        print( "Shorted || tfOr: " + tfOr );

        bool tfOr2 = ( printAndReturnFalse() || printAndReturnTrue() ); // e
        print( "Non-Shorted || tfOr2: " + tfOr2 );


        // The second half of this test uses the nonshorting & and |
        bool tfAnd3 = ( printAndReturnFalse() & printAndReturnTrue() ); // f
        print( "Non-Shorting & tfAnd3: " + tfAnd3 );

        bool tfOr3 = ( printAndReturnTrue() | printAndReturnFalse() ); // g
        print( "Non-Shorting | tfOr3: " + tfOr3 );
    }
}
```

a. В Unity метод `Start()` вызывается один раз для каждого GameObject непосредственно перед вызовом первого `Update()` для этого GameObject. При вызове метода `Start()` он вызывает `ShortingOperatorTest()`.  

b. Эта строка выведет `--true` и `--false`, прежде чем установить `tfAnd` в `false`. Поскольку первый аргумент, который оценивает оператор сокращения `&&` оценивает, является `true`, он должен также оценить второй аргумент, чтобы определить, что результат равен `false`.  

c. Эта строка выводит только `--false` перед установкой `tfAnd2` в `false`. Поскольку первый аргумент, который оценивает сокращающий оператор `&&,` равен `false`, он возвращает `false`, вообще не оценивая второй аргумент! В этой строке `printAndReturnTrue()` не выполняется. 

d. В этой строке выводится только `--true` перед установкой `tfOr` в `true`. Поскольку первый аргумент, который вычисляет сокращающий оператор `||`, равен `true`, он возвращает `true`, не вычисляя второй. 

e. Эта строка выводит `--false` и `--true` перед тем, как установить `tfOr2` в `true`. Поскольку первый аргумент, который вычисляет сокращающий оператор `||`, ложен, он должен вычислить второй аргумент, чтобы определить, какое значение возвращать. 

f. Оператор `&` без сокращения вычисляет оба аргумента независимо от значения первого аргумента. В результате в этой строке выводятся `--false` и `--true` перед установкой `tfAnd3` в `false`. 

g. Оператор `|`, не допускающий упрощения, вычисляет оба аргумента независимо от значения первого аргумента. В этой строке выводятся `--true` и `--false`, прежде чем переменная `tfOr3` принимает значение `true`. 

При написании кода полезно знать как о сокращающих, так и о несокращающих операторах. Сокращающие операторы (`&&` и `||`) используются гораздо чаще, но вы можете использовать `&` и `|`, когда хотите гарантировать, что будут вычислены все аргументы булевого оператора. 

### Комбинация булевых операций 

Часто бывает полезно комбинировать различные булевы операции в одной строке: 

```c#
bool tf = true || false && false;
```

Однако при этом нужно быть осторожным, поскольку порядок операций распространяется и на булевы операции. Вы, вероятно, сталкивались с порядком операций в математике, где `×` всегда вычисляется перед `+`, поэтому `1 + 2 × 3` вычисляется как `1 + (2 × 3)`. В C# порядок операций для булевых операций следующий: 

`!` - NOT 

`&` - И без сокращения / побитовое И 

`|` - ИЛИ без сокращения / побитовое ИЛИ 

`&&` - И (сокращающее) 

`||` - ИЛИ (сокращающее)  

Это означает, что предыдущая строка будет интерпретирована компилятором следующим образом:  

>В C#, как и в алгебре, размещение скобок вокруг части выражения приводит к тому, что эта часть вычисляется первой. 

```c#
bool tf = true || ( false && false );
```

Сравнение `&&` всегда выполняется раньше сравнения `||`. Если бы вы не учли порядок операций и прочитали эту строку слева направо, вы могли бы ожидать, что результат будет `false` (например, `(true || false) && false` равняется `false`), но без скобок эта строка на самом деле дает результат `true`!

### Логическая эквивалентность булевых операций 

Удивительная глубина булевой логики выходит за рамки этих статей, но даже с небольшими знаниями булевой логики вы можете добиться очень интересных результатов, комбинируя булевы операции. В приведенных ниже примерах логических правил `a` и `b` являются переменными типа bool. Эти правила верны независимо от того, являются ли `a` и `b` истинными или ложными, и независимо от того, используются ли сокращающие или несокращающие операторы: 

- Ассоциативность: `( a & b ) & c` равно `a & ( b & c )` 
- Коммутативность: `( a & b )` равно `( b & a ) `
- Дистрибутивность AND над OR: `a & ( b | c )` то же что и `( a & b ) | ( a & c )`
- Дистрибутивность OR над AND: `a | ( b & c )` то же что и `(a | b ) & ( a | c )`
- `( a & b )` то же что и `!( !a | !b )`
- `(a | b )` то же что и `!( !a & !b )`
