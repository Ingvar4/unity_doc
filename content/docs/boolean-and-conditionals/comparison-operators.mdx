### == (Is Equal To)

Оператор сравнения на равенство проверяет, эквивалентны ли друг другу значения любых двух переменных или литералов. Результатом этого оператора является значение типа bool: true или false.

```c#
print( 10 == 10 ); // Output: True because 10 == 10
print( 10 == 20 ); // Output: False because 10 != 20
print( 20 == 20 ); // Output: True because 20 == 20
print( 1.23f == 1.23f ); // Output: True because 1.23f == 1.23f // a
print( 1.23f == 3.14f ); // Output: False because 1.23f != 3.14f
print( 3.14f == Mathf.PI ); // Output: False (see the following note b) // b
print( 1.23f == 1.23 ); // Output: False // c
```

**a.** Результат этого выражения почти наверняка будет `true`; однако вы можете получить предупреждение от Visual Studio или Unity о том, что использование оператора сравнения `==` с числами с плавающей запятой иногда неточно (из-за ошибки с плавающей запятой, упомянутой в предыдущей главе). Просто имейте это в виду: если вам нужна крайняя точность в коде, возможно, стоит рассмотреть использование чего-то другого, а не чисел с плавающей запятой. 

**b.** Сравнение в строке дает `false`, поскольку `Mathf.PI` гораздо точнее, чем `3.14f`, а оператор `==` требует, чтобы значения были точно равны. 

**c.** `1.23f` и `1.23` не равны, поскольку `1.23` - это double (т. е. число с плавающей запятой двойной точности), тогда как `1.23f` - обычное число с плавающей запятой, и из-за особенностей хранения значений в каждом формате дробные числа и очень большие числа редко будут считаться равными.

### Приблизительное сравнение чисел с  плавающей запятой [!toc]
Поскольку числа с плавающей запятой иногда бывают неточными, существует метод Mathf для определения приблизительного равенства. 

```c#
print( 0.1f == ( 1.0f/10.0f ) ); // Sometimes true, sometimes false!
print( Mathf.Approximately( 0.1f, (1.0f / 10.0f) ) ); // Always true
```

В Unity указано, что выражение с оператором `==` будет возвращать `true` или `false` в зависимости от обстоятельств, что не идеально. Поэтому предоставляется статический метод `Mathf.Approximately()`, который в данной ситуации всегда вернет `true`. Однако вы не можете контролировать степень приближения `Mathf.Approximately()`, поэтому я предпочитаю другое решение. 

```c#
print( Mathf.Approximately( 3.14f, Mathf.PI ) ); // Still false
print( CloseEnough( 3.14f, Mathf.PI, 0.01f ) ); // true!

bool CloseEnough( float a, float b, float diff ) {
    return ( Mathf.Abs( a - b ) < diff );
}
```

Здесь я написал метод `CloseEnough()`, который вычитает `b` из `a`. Затем проверяет, меньше ли абсолютное значение разности, чем переданное значение `diff`. Этот метод позволяет вам контролировать, насколько близкими должны быть значения.
</Callout>

### Проверка равенства по значению или ссылке [!toc]
Версия C# от Unity сравнивает большинство простых типов данных по значениям. Это означает, что если значения двух переменных одинаковы, они будут считаться эквивалентными. Это работает для всех следующих типов данных: 
- bool
- int
- float
- char
- string
- Vector3
- Color
- Quaternion  

Однако в случае более сложных типов переменных, таких как `GameObject`, `Material`, `Renderer` и т. д., C# проверяет равенство по ссылке. При сравнении по ссылке не сравнивается, равны ли значения двух переменных, а проверяется, ссылки на эти две переменные одинаковы. Другими словами, проверяется, ссылаются ли (или указывают ли) эти две переменные на один и тот же объект в памяти компьютера. В следующем примере сравнения по ссылке мы будем исходить из того, что `boxPrefab` - это уже существующая переменная, которая ссылается на префаб GameObject 

```c#
GameObject go0 = Instantiate<GameObject>( boxPrefab );
GameObject go1 = Instantiate<GameObject>( boxPrefab );
GameObject go2 = go0; // Sets go2 to reference the same object as go0
print( go0 == go1 ); // Output: False
print( go0 == go2 ); // Output: True
```

Несмотря на то, что два `boxPrefab`, присвоенные переменным `go0` и `go1`, имеют одинаковые значения (у них точно такое же положение по умолчанию, поворот и т. д.), оператор `==` рассматривает их как разные, поскольку на самом деле это два разных объекта, и, следовательно, они находятся в двух разных местах в памяти. `go0` и `go2` рассматриваются как равные оператором `==`, поскольку оба ссылаются на один и тот же объект в памяти. Давайте продолжим предыдущий код:

```c#
go0.transform.position = new Vector3( 10, 20, 30 );
print( go0.transform.position ); // Output: (10.0, 20.0, 30.0)
print( go1.transform.position ); // Output: ( 0.0, 0.0, 0.0)
print( go2.transform.position ); // Output: (10.0, 20.0, 30.0)
```

Здесь изменилось положение `go0`. Поскольку `go1` - это другой экземпляр `GameObject`, его положение осталось прежним. Однако, поскольку `go2` и `go0` ссылаются на один и тот же экземпляр `GameObject`, `go2.transform.position` также отражает это изменение. 

Далее мы изменим положение `go1`, чтобы оно совпадало с положением `go0` (который ссылается на тот же `GameObject`, что и `go2`). 

```c#
go1.transform.position = new Vector3( 10, 20, 30 );
print(go0.transform == go1.transform); // Output: false
print(go0.transform.position == go1.transform.position); // Output: true
```

`go0.transform` и `go1.transform` не равны (поскольку трансформации сравниваются по ссылке), но их `transform.positions` эквивалентны, поскольку позиции Vector3 сравниваются по значению.
</Callout>

### != (Not Equal To)

Оператор неравенства возвращает `true`, если два значения не равны, и `false`, если они равны. Он является противоположностью `==`. При сравнении объектов по ссылке `!=` возвращает `true`, когда два объекта указывают на разные места в памяти. (Для остальных сравнений в целях ясности и экономии места вместо переменных будут использоваться литеральные значения.) 

```c#
print( 10 != 10 ); // Output: False
print( 10 != 20 ); // Output: True
print( 1.23f != 3.14f ); // Output: True
print( 1.23f != 1.23f ); // Output: False
print( 3.14f != Mathf.PI ); // Output: True (because Math.PI has more precision)
```

### > (Greater Than) and < (Less Than)

Оператор «больше» ( > ) возвращает true, если значение слева от оператора больше значения справа: 

```c#
print( 10 > 10 ); // Output: False
print( 20 > 10 ); // Output: True
print( 1.23f > 3.14f ); // Output: False
print( 1.23f > 1.23f ); // Output: False
print( 3.14f > 1.23f ); // Output: True
```

Оператор «меньше» ( < ) возвращает значение true, если значение слева от оператора меньше значения справа:

```c#
print( 10 < 10 ); // Output: False
print( 20 < 10 ); // Output: False
print( 1.23f < 3.14f ); // Output: True
print( 1.23f < 1.23f ); // Output: False
print( 3.14f < 1.23f ); // Output: False
```

Символы `<` и `>` также иногда называют угловыми скобками, особенно когда они используются в качестве тегов в таких языках, как HTML и XML, или в общих функциях в C#. Однако, когда они используются в качестве операторов сравнения, их всегда называют «больше» и «меньше». Невозможно сравнивать объекты по ссылке с помощью `>`, `<`, `>=` или `<=`.

### Фигурные скобки, квадратные скобки и круглые  скобки, о боже! [!toc]
Об этом уже упоминалось в других разделах, но сейчас самое время поговорить о названиях различных символов в вашем коде (перечисленных примерно в порядке их распространенности): 

- `( )` - Круглые скобки определяют порядок операций и позволяют
определять или вызывать функции.

- `{ }` - Фигурные скобки заключают код в классы, функции и
условные операторы. Visual Studio автоматически
делает отступы между фигурными скобками.

- `[ ]` - Квадратные скобки позволяют получить доступ к элементам массива, списка или
строки.

- `< >` - Угловые скобки используются для определения типа переменной, которую вы хотите использовать с универсальной функцией (например,
`GetComponent<Transform>()` вернет
компонент Transform объекта GameObject, к которому привязан ваш код).

</Callout>

### `>=` (Greater Than or Equal To) and `<=` (Less Than or Equal To)

Оператор «больше или равно» ( `>=` ) возвращает true, если значение слева больше или равно значению справа:

```c#
print( 10 >= 10 ); // Output: True
print( 10 >= 20 ); // Output: False
print( 1.23f >= 3.14f ); // Output: False
print( 1.23f >= 1.23f ); // Output: True
print( 3.14f >= 1.23f ); // Output: True
```

Оператор «меньше или равно» ( `<=` ) возвращает true, если значение слева меньше или равно значению справа: 

```c#
print( 10 <= 10 ); // Output: True
print( 10 <= 20 ); // Output: True
print( 1.23f <= 3.14f ); // Output: True
print( 1.23f <= 1.23f ); // Output: True
print( 3.14f <= 1.23f ); // Output: False
```
