Если номиналы двух карт отличаются всего на один номер, как в этом случае, мы будем говорить, что
эти карты соседствуют.  

1. Добавьте строки из листинга кода  в метод `CARD_CLICKED()` скрипта Prospector:  

Листинг кода Prospector.cs

```c#
public class Prospector : MonoBehaviour {
    …
    static public void CARD_CLICKED(CardProspector cp) {
        // The reaction is determined by the state of the clicked card
        switch (cp.state) {
            …
            case eCardState.mine:
            // More to come here // a 
            // Clicking a card in the mine will check if it’s a valid play
            bool validMatch = true; // Initially assume that it’s valid

            // If the card is face-down, it’s not valid
            if (!cp.faceUp) validMatch = false;

            // If it’s not an adjacent rank, it’s not valid
            if (!cp.AdjacentTo(S.target)) validMatch = false; // b

            if (validMatch) { // If it’s a valid card

``` 

- a. Красная зачеркнутая строка означает, что вам следует удалить эту строку.
- b. Метод `AdjacentTo()` подчеркнут красным в Visual Studio, потому что мы его еще не
написали. Prospector не скомпилируется, пока вы не выполните код из листинга.  

2. Откройте файл Card в Visual Studio и добавьте новый метод `AdjacentTo()` в конец класса. Этот метод может использоваться в нескольких карточных
играх, поэтому мы добавляем его в класс Card, а не в CardProspector. Как
подкласс Card, CardProspector унаследует этот метод.  

Листинг Card.cs

```c#
public class Card : MonoBehaviour {
    …

    virtual public void OnMouseUpAsButton() { … }

    /// <summary>
    /// Return true if the two cards are adjacent in rank.
    /// If wrap is true, Ace and King are adjacent.
    /// </summary>
    /// <param name="otherCard">The card to compare to</param>
    /// <param name="wrap">If true (default) Ace and King wrap</param>
    /// <returns>true, if the cards are adjacent</returns>
    public bool AdjacentTo(Card otherCard, bool wrap=true) {
        // If either card is face-down, it’s not a valid match.
        if (!faceUp || !otherCard.faceUp) return (false);

        // If the ranks are 1 apart, they are adjacent
        if (Mathf.Abs(rank - otherCard.rank) == 1) return (true);

        if (wrap) { // If wrap == true, Ace and King are treated as adjacent
            // If one Card is Ace and the other King, they are adjacent
            if (rank == 1 && otherCard.rank == 13) return (true);
            if (rank == 13 && otherCard.rank == 1) return (true);
        }

        return (false); // Otherwise, return false
    }
}
```  

3. Сохраните все скрипты в Visual Studio и вернитесь в Unity.  

Если вы нажмете «Play» в Unity, теперь вы сможете правильно разыграть верхний ряд карт,
нажимая на любую карту, соседствующую с целевой картой (или нажимая на колоду, чтобы
заменить целевую карту), и если вам повезет увидеть туза и короля, они будут действовать,
находясь рядом друг с другом.  

Однако, по мере игры, вы заметите, что карты, лежащие лицевой стороной вниз, никогда не
переворачиваются лицевой стороной вверх. Именно для этого используется массив int[]
hiddenBy, который мы создали ранее при разборе JSON_Layout. Значение hiddenBy
каждого слота хранит идентификационные номера других слотов расположения мин, которые
его покрывают.  

Если мы создадим словарь, связывающий идентификационный номер каждого слота
расположения мин с CardProspector, который был в него помещен, а затем установим эти
слоты в null, когда карта в слоте будет разыграна, мы сможем проверить, следует ли
перевернуть какую-либо карту в мине лицевой стороной вверх. Если два слота карт, скрывающих
любую закрытую карту, равны null, то эту карту следует перевернуть лицевой стороной вверх.  

Для этого необходимо добавить код в Prospector в нескольких местах.  

4. Добавьте следующий выделенный жирным шрифтом код по всему скрипту Prospector. Сюда
входит следующее (что вы можете увидеть, отмеченное от `// a` до `// e` в листинге кода):
    - a. Новое поле `mineIdToCardDict` над `Start()`
    - b. Инициализация `mineIdToCardDict` в `LayoutMine()`
    - c. Добавление каждого `slot.id` и `CardProspector` в `mineIdToCardDict` в `LayoutMine()`
    - d. Новый метод `SetMineFaceUps()` между `UpdateDrawPile()` и `CARD_CLICKED()`.
Мы оставим статический метод `CARD_CLICKED()` внизу класса, чтобы отделить его от
нестатических методов.
    - e. Одно дополнение к статическому методу `CARD_CLICKED()`

            mineIdToCardDict.Add(slot.id, cp); // c

    /// This turns cards in the Mine face-up and face-down
    /// </summary>
    public void SetMineFaceUps() { // d
        CardProspector coverCP;
        foreach (CardProspector cp in mine) {

            foreach (int coverID in cp.layoutSlot.hiddenBy) {

                }

            cp.faceUp = faceUp; // Set the value on the card

        …
