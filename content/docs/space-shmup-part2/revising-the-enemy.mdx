---
title: Изменение метода OnCollisionEnter у врага
description: Теперь, когда ваше оружие выпускает снаряды, способные наносить урон разной величины (хотя в данный момент они настроены на нанесение одинакового урона), вам необходимо усовершенствовать метод `OnCollisionEnter()` класса `Enemy`.
---

1. Откройте скрипт Enemy (на языке C#) в Visual Studio и удалите метод `OnCollisionEnter()`.
2. Замените старый метод `OnCollisionEnter()` кодом из листинга.  
  Листинг Enemy.cs

```c#
public class Enemy : MonoBehaviour {
    …
    // void OnCollisionEnter( Collision coll ) { … } // a

    void OnCollisionEnter( Collision coll ) {
        GameObject otherGO = coll.gameObject;

        // Check for collisions with ProjectileHero
        ProjectileHero p = otherGO.GetComponent<ProjectileHero>();
        if ( p != null ) { // b
            // Only damage this Enemy if it’s on screen
            if ( bndCheck.isOnScreen ) { // c
                // Get the damage amount from the Main WEAP_DICT.
                health -= Main.GET_WEAPON_DEFINITION( p.type ).damageOnHit;
                if ( health <= 0 ) { // d
                    // Destroy this Enemy
                    Destroy( this.gameObject );
                }
            }
            // Destroy the ProjectileHero regardless
            Destroy( otherGO ); // e
        } else {
            print( "Enemy hit by non-ProjectileHero: " + otherGO.name ); // f
        }
    }
}
```

    - a. Убедитесь, что вы закомментировали или удалили весь старый метод `OnCollisionEnter()`.
    - b. Если переменная `p` не равна `null`, это означает, что у игрового объекта, столкнувшегося с данным врагом, есть прикрепленный скрипт `ProjectileHero`. Это гораздо более надежный способ определить, является ли объект снарядом героя (`ProjectileHero`), чем проверка по тегу (как мы делали в некоторых других главах). Если `p` равно `null`, сработает блок `else` и пункт // f.
    - c. Враг должен получать урон, только если он находится в пределах видимости на экране.
    - d. Если здоровье врага падает до 0 или ниже, враг уничтожается. При стандартном запасе здоровья врага, равном 10, и уроне бластера (`damageOnHit`), равном 1, для этого потребуется 10 выстрелов.
    - e. Игровой объект `ProjectileHero` уничтожается независимо от того, нанес ли он урон врагу.
    - f. Если с врагом столкнется игровой объект, у которого нет скрипта `ProjectileHero`, в панель Console будет выведено соответствующее сообщение.  

3. Сохраните скрипт Enemy и вернитесь в Unity.
4. Выберите объект _MainCamera в окне Hierarchy и назначьте префаб Enemy_0 элементу 0 массива prefabEnemies в компоненте Main (Script). Благодаря этому вы будете сражаться с врагами типа Enemy_0, а не Enemy_3.
5. Сохраните сцену и нажмите кнопку Play в Unity.  

Теперь при запуске сцены врагов можно уничтожить, однако для устранения каждого из них требуется 10 выстрелов, при этом сложно заметить, что они получают урон.
