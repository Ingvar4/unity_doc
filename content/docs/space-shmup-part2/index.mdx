## Чему вы научитесь [!toc]

В этой главе рассматриваются несколько новых концепций и повторяются уже изученные ранее. К ним относятся:
- Реализация пяти различных типов врагов с использованием наследования классов
- Настройка вероятности появления врагов и выпадения различных бонусов (power-ups)
- Углубленное изучение полей и методов с модификаторами доступа private, protected и public
- Использование AnimationCurve для точного вращения игрового объекта (GameObject) с течением времени
- Реализация двух типов оружия и трех типов бонусов
- Возможность для игрока иметь до пяти единиц оружия каждого типа
- Использование событий на основе многоадресных делегатов C# для активации всего оружия одним вызовом

### Настройка проекта для этой главы [!toc]
Вместо выполнения стандартной процедуры настройки проекта вам нужно будет продолжить работу над проектом из предыдущей главы. Для этого есть два варианта:
    - продолжить работу в папке проекта из предыдущей главы;
    - создать копию папки проекта из предыдущей главы. Иногда - особенно если вы занимаетесь по этой книге в рамках учебного курса и вам нужно сдать задания по этим двум главам по отдельности - бывает полезно сохранить проекты этих глав как разные папки.  

Если для этой главы вам нужна отдельная копия папки проекта, выполните следующие действия:  

1. Перед копированием папки проекта обязательно закройте Unity.
2. Найдите на жестком диске папку проекта из предыдущей главы (используя «Проводник» в Windows или Finder в macOS).
3. macOS: Щелкните правой кнопкой мыши по папке и выберите пункт «Дублировать» (Duplicate). Копия папки появится в том же окне Finder.
Windows: Щелкните правой кнопкой мыши по папке и выберите «Копировать» (Copy). Затем щелкните правой кнопкой мыши на свободном месте в том же окне «Проводника» и выберите «Вставить» (Paste).
4. Щелкните правой кнопкой мыши по новой папке и выберите «Переименовать» (Rename). Назовите новую папку *Space SHMUP Part 2*.
5. Запустите Unity Hub и нажмите кнопку Open (Открыть) в верхней части окна. Перейдите к новой папке проекта и откройте ее.
6. Чтобы избежать путаницы в дальнейшем, следует изменить название проекта. Откройте окно настроек проекта (меню **Edit > Project Settings…**) и выберите вкладку **Player** в левой части окна. Затем измените поле **Product Name** на *Space SHMUP Part 2*.
7. Если вы используете какую-либо систему контроля версий (например, Unity Plastic SCM), необходимо отвязать этот проект от системы контроля версий, использовавшейся для предыдущей главы. Видеоинструкцию по выполнению этой операции можно найти в разделе, посвященном главе 32, на сайте книги: http://book.prototools.net.
