---
title: Расширение выбора оружия
description: Теперь, когда код готов, нужно внести в скрипт _Hero в Unity несколько изменений, чтобы настроить пять возможных видов оружия, которые может нести корабль героя.
---

1. В окне Hierarchy (Иерархия) нажмите на треугольник раскрытия рядом с игровым объектом `_Hero`.
2. Продолжайте раскрывать вложенные элементы, пока не увидите пять дочерних объектов `hardpoint_#` у модели `heroShip`. У объекта `hardpoint_0` уже есть дочерний объект `Weapon`, а для остальных четырех `hardpoint_#` его нужно добавить.
3. Перетащите объект `Weapon` из папки `_Prefabs` в окне Project (Проект) на каждый из четырех оставшихся дочерних объектов `hardpoint_#` (то есть `hardpoint_1`, `hardpoint_2`, `hardpoint_3`, `hardpoint_4`). Это добавит экземпляр `Weapon` в качестве дочернего объекта для каждого `hardpoint_#` (аналогично тому, как это уже сделано для `hardpoint_0`).
4. Убедитесь, что все экземпляры `Weapon`, находящиеся внутри объектов `hardpoint_#`, имеют следующие параметры Transform: P:[ 0, 0, 0 ], R:[ 0, 0, 0 ] и S:[ 1, 1, 1 ].
5. Выберите объект `_Hero` и в окне Inspector (Инспектор) для компонента `Hero (Script)` раскройте список поля `weapons`.
6. Установите значение `Size` (Размер) для массива `weapons` равным 5 и назначьте объекты `Weapon` в пять слотов следующим образом:
    - a. Перетащите `Weapon` из `hardpoint_0` в элемент `Element 0` массива `weapons`.
    - b. Перетащите `Weapon` из `hardpoint_1` в элемент `Element 1` массива `weapons`.
    - c. Перетащите `Weapon` из `hardpoint_2` в элемент `Element 2` массива `weapons`.
    - d. Перетащите `Weapon` из `hardpoint_3` в элемент `Element 3` массива `weapons`.
    - e. Перетащите `Weapon` из `hardpoint_4` в элемент `Element 4` массива `weapons`.

Оружие с индексом 0 располагается в центре корабля, оружие с индексом 1 - в крайнем левом положении, оружие с индексом 2 - в крайнем правом, и так далее. Такое расположение выглядит лучше по мере того, как игрок собирает больше оружия, чем вариант, при котором первое оружие размещается слева, а последующие добавляются по порядку вправо. Дочерние объекты «Героя», отображающие оружие на каждом узле подвески, и комплекс вооружения «Героя».  

7. Выберите объект Weapon, находящийся в иерархии (Hierarchy) под hardpoint_0. В верхней части окна Inspector нажмите кнопку Overrides и выберите пункт Revert All (если такой опции нет, этот шаг можно пропустить). Это позволит задать тип оружия для всех экземпляров Weapon через сам префаб Weapon (вместо того чтобы тип оружия для объекта на hardpoint_0 был переопределен на Blaster).
8. Чтобы оценить возможности игрока, выберите префаб Weapon в папке
_Prefabs и установите поле type компонента Weapon (Script) на Spread. Нажмите
Play. (Оставьте это значение для тестирования в следующем разделе.)
9. Сохраните сцену.

### Настройка влияния бонусов на героя [!toc]
Давайте сделаем так, чтобы подбор бонуса (PowerUp) действительно к чему-то приводил. Для этого нам нужно внести изменения в скрипт героя.  

1. Откройте скрипт Hero и добавьте методы `GetEmptyWeaponSlot()` и `ClearWeapons()` после свойства shieldLevel в нижней части скрипта.  
    Листинг кода Hero.cs

```c#
public class Hero : MonoBehaviour {
    …

    public float shieldLevel { … }

    /// <summary>
    /// Finds the first empty Weapon slot (i.e., type=none) and returns it.
    /// </summary>
    /// <returns>The first empty Weapon slot or null if none are empty</returns>
    Weapon GetEmptyWeaponSlot() {
        for (int i = 0; i < weapons.Length; i++) {
            if (weapons[i].type == eWeaponType.none) {
                return(weapons[i]);
            }
        }
        return(null);
    }

    /// <summary>
    /// Sets the type of all Weapon slots to none
    /// </summary>
    void ClearWeapons() {
        foreach (Weapon w in weapons) {
            w.SetType(eWeaponType.none);
        }
    }
}
```

2. Кроме того, в скрипте Hero заполните блок switch метода `AbsorbPowerUp()` (который вы ранее оставили пустым) кодом в листинге.  
    Листинг Hero.cs

```c#
public class Hero : MonoBehaviour {
    …
    public void AbsorbPowerUp( PowerUp pUp ) {
        Debug.Log("Absorbed PowerUp: " + pUp.type);
        switch (pUp.type) {
            case eWeaponType.shield: // a
            shieldLevel++;
            break;

            default: // b
            if (pUp.type == weapons[0].type) { // If it is the same type // c
                Weapon weap = GetEmptyWeaponSlot();
                if (weap != null) {
                    // Set it to pUp.type
                    weap.SetType(pUp.type);
                }
            } else { // If this is a different weapon type // d
                ClearWeapons();
                weapons[0].SetType(pUp.type);
            }
            break;
        }
        pUp.AbsorbedBy( this.gameObject );
    }
    …
}
```

    - a. Если бонус (PowerUp) относится к типу `eWeaponType.shield`, уровень щита повышается на 1.
    - b. Любой другой тип `eWeaponType` для бонуса означает оружие; это случай, принимаемый по умолчанию.
    - c. Если тип `eWeaponType` бонуса совпадает с типом уже имеющегося оружия, выполняется поиск свободного слота для оружия и предпринимается попытка назначить этому слоту данный тип оружия. Если все пять слотов уже заняты, ничего не происходит.
    - d. Если тип `eWeaponType` бонуса отличается, все слоты для оружия очищаются, а в слот `weapons[0]` устанавливается оружие нового типа, соответствующего подобранному бонусу.

<Callout>
### Примечание [!toc]
«Игра - это череда интересных решений». Именно так Сид Мейер определил понятие игры. Блок `else` в строке `// d` листинга сбрасывает количество орудий до одного всякий раз, когда игрок подбирает новое оружие; это вынуждает его принимать интересное решение. Поскольку мы сделаем так, чтобы бонусы для бластера (Blaster PowerUp) встречались гораздо чаще, чем бонусы для пушки, стреляющей веером (Spread PowerUp), игрок, скорее всего, успеет оснастить свой корабль несколькими бластерами еще до появления первого бонуса Spread. В этот момент перед ним встанет любопытная дилемма: сохранить мощь уже имеющихся бластеров или переключиться на одну пушку Spread - менее мощную, но открывающую путь к получению пяти таких орудий (что дает колоссальную огневую мощь). Это лишь небольшой фрагмент кода, но его влияние на геймдизайн - огромно!
</Callout>

3. Сохраните все скрипты в Visual Studio и вернитесь в Unity.
4. Чтобы проверить, успешно ли теперь подбираются бонусы (PowerUps), выберите бонус в окне Hierarchy и в компоненте PowerUp (Script) в окне Inspector установите тип (в разделе «Dynamic») на Blaster. Обычно тип определяется динамически, но для тестирования его можно задать вручную (хотя при ручной настройке на бонусе не будет отображаться соответствующая буква).
5. Нажмите кнопку Play: игра начнется с того, что у вас будет оружие, стреляющее веером (это результат настройки типа префаба оружия на шаге 8 предыдущего раздела). Если вы подберете бонус (PowerUp), это оружие заменится на обычный бластер. Вы также можете протестировать бонус в сочетании со щитом: при подборе бонуса уровень щита будет повышаться.
