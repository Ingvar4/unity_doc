---
title: Настройки параметров игровых сущностей
description: Теперь пришло время настроить параметры вероятности появления, запаса здоровья и шанса выпадения бонусов для каждого типа врагов.
---

В следующей главе вы узнаете, как создать скрипт на основе ScriptableObject, который позволит собрать все эти настройки в одном месте; однако в рамках данного проекта вы будете настраивать эти значения непосредственно на различных игровых объектах (GameObject).  

Начнем с вероятности появления. Наша цель - сделать так, чтобы самые простые враги (например, Enemy_0) встречались чаще всего, а более сложные (такие как Enemy_4) - реже.  

1. Вероятность появления каждого врага устанавливается путем изменения массива prefabEnemies в
главном (скриптовом) компоненте _MainCamera:
    - a. Выберите _MainCamera в иерархии.
    - b. Установите размер prefabEnemies в главном (скриптовом) инспекторе равным 1. (Размер - это поле,
с числом рядом с заголовком Prefab Enemies; на рисунке показано «16».)

<img src="/unity_doc/images/ex101.jpeg" alt="1" style={{  height: 'auto' }} />

Итоговые переменные для игры: _MainCamera, Enemy_0 и Enemy_1
(Некоторые компоненты сведены вместе, чтобы уменьшить длину этих изображений.)  

    - c. Назначьте префаб Enemy_0 (из папки _Prefabs на панели Project) в качестве элемента Element 0.
    - d. Установите значение Size для массива prefabEnemies равным 7 (в итоге получится семь элементов Enemy_0).
    - e. Замените элемент Element 6 на префаб Enemy_1.
    - f. Установите значение Size для массива prefabEnemies равным 10 (в итоге получится 4 элемента Enemy_1).
    - g. Замените элемент Element 9 на префаб Enemy_2.
    - h. Установите значение Size для массива prefabEnemies равным 13 (в итоге получится четыре элемента Enemy_2).
    - i. Продолжайте этот процесс, пока в массиве prefabEnemies не окажется 16 элементов, как
показано на рисунке 32.11: 6x Enemy_0, 3x Enemy_1, 3x Enemy_2, 3x Enemy_3 и 1x
Enemy_4.
    - j. В верхней части окна Inspector для компонента Main (Script) убедитесь, что для параметра spawnEnemies установлен флажок.  

Если всё это делать, Enemy_0 должны выпадать довольно часто, а Enemy_4 - довольно редко.  

2. Поочередно выберите каждый из префабов Enemy_# и задайте для них параметр powerUpDropChance
следующим образом. Также убедитесь, что все остальные настройки соответствуют тем, что показаны на рисунках.

<img src="/unity_doc/images/102.jpeg" alt="1" style={{  height: 'auto' }} />

Финальные переменные для игры: Enemy_2, Enemy_3 и Enemy_4.  

    - a. Enemy_0: Установите powerUpDropChance = 0.25, boundsType = outset и radius = 2. (Под этим я подразумеваю: выберите Enemy_0 в папке _Prefabs на панели Project и установите
powerUpDropChance в инспекторе врагов (скриптов) на 0.25 (это означает, что
Enemy_0 будет сбрасывать бонус в 25% случаев). Дважды проверьте, что BoundsCheck
boundsType равен outset, а radius равен 2.)
    - b. Enemy_1: Установите powerUpDropChance = 0.5, boundsType = outset и radius =
2.5.
    - c. Enemy_2: Установите powerUpDropChance = 0.75, boundsType = outset и radius = 3.
    - d. Enemy_3: Установить powerUpDropChance = 0.75, boundsType = outset и radius
= 3.
    - e. Enemy_4: Установить powerUpDropChance = 1, boundsType = inset и radius = 8.

3. Сохраните сцену и нажмите Play, чтобы опробовать игру!
