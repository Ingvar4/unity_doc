title: Использование делегированного события для запуска
description: В этом прототипе игры у класса «Герой» будет событие-делегат с именем `fireEvent`, вызываемое для ведения огня из всего оружия, а каждое прикрепленное к нему оружие будет добавлять свой собственный целевой метод `Fire()` в это событие.
---

1. Прежде чем продолжить, пожалуйста, ознакомьтесь с разделом «Delegates». Делегаты - это своего рода псевдонимы для одной или нескольких функций; все эти функции можно вызвать посредством одного-единственного вызова делегата.  

Сначала мы создадим тип делегата с именем `WeaponFireDelegate`, а затем - событие этого типа. Событие представляет собой оболочку для делегата, которая защищает его, разрешая другим классам лишь добавлять свои методы или удалять их (обычный делегат может быть обнулен другим классом, что весьма опасно).  

2. Добавьте в класс Hero код из листинга:  
    Листинг Hero.cs

```c#
public class Hero : MonoBehaviour {
    …
    [Header( "Dynamic" )]
    …
    [Tooltip( "This field holds a reference to the last triggering GameObject" )]
    private GameObject lastTriggerGo = null;
    // Declare a new delegate type WeaponFireDelegate
    public delegate void WeaponFireDelegate(); // a
    // Create a WeaponFireDelegate event named fireEvent.
    public event WeaponFireDelegate fireEvent;

    void Awake() {
        if (S == null) {
            …S = this; // Set the Singleton
        } else {
            Debug.LogError("Hero.Awake() - Attempted to assign second Hero.S!");
        }
        fireEvent += TempFire; // b
    }

    void Update () {
        …

        // Rotate the ship to make it feel more dynamic
        transform.rotation = Quaternion.Euler(vAxis*pitchMult,hAxis*rollMult,0);

        // Allow the ship to fire
        // if ( Input.GetKeyDown( KeyCode.Space ) ) { // c
        // TempFire(); // c
        // } // c

        // Use the fireEvent to fire Weapons when the Spacebar is pressed.
        if (Input.GetAxis("Jump") == 1 && fireEvent != null) { // d
            fireEvent(); // e
        }
    }

    void TempFire() { // f
        GameObject projGO = Instantiate<GameObject>( projectilePrefab );
        projGO.transform.position = transform.position;
        Rigidbody rigidB = projGO.GetComponent<Rigidbody>();
        // rigidB.velocity = Vector3.up * projectileSpeed; // g

        ProjectileHero proj = projGO.GetComponent<ProjectileHero>(); // h
        proj.type = eWeaponType.blaster;
        float tSpeed = Main.GET_WEAPON_DEFINITION( proj.type ).velocity;
        rigidB.velocity = Vector3.up * tSpeed;
    }

    void OnTriggerEnter(Collider other) { … }
    …
}
```

  - a. Несмотря на то, что и тип делегата `WeaponFireDelegate()`, и поле `fireEvent` являются публичными (`public`), они не отобразятся в инспекторе Unity, так как не подлежат сериализации.
  - b. Добавление `TempFire` в `fireEvent` приводит к тому, что `TempFire` будет вызываться каждый раз, когда `fireEvent` вызывается как функция (см. пункт // e).
Обратите внимание: при добавлении `TempFire` в `fireEvent` после имени метода не ставятся скобки. Это связано с тем, что вы добавляете сам метод, а не вызываете его и не передаете возвращаемый им результат (что произошло бы, если бы вы указали скобки после имени метода).
  - c. Обязательно закомментируйте (или удалите) эти три строки.
  - d. Значение `Input.GetAxis("Jump")` равно 1, когда нажата клавиша пробела или кнопка прыжка на контроллере.
Любой делегат или событие, к которому не привязаны методы, имеет значение `null`. Поэтому, если вызвать `fireEvent` без привязанных методов, возникнет исключение `NullReferenceException`. Чтобы этого избежать, перед вызовом проверяется, не равно ли `fireEvent` значению `null`.
  - e. Здесь `fireEvent` вызывается так, словно это функция. Это, в свою очередь, приводит к вызову всех функций, добавленных в делегат/событие `fireEvent` (в данном случае это означает вызов `TempFire()`).
  - f. Теперь `fireEvent` вызывает `TempFire()` для выполнения стандартного выстрела из бластера. Позже, при расширении класса `Weapon`, вы замените `TempFire()` на другой метод.
  - g. Пожалуйста, закомментируйте или удалите эту строку.
h. Этот новый фрагмент кода получает информацию из поля `eWeaponType` класса `ProjectileHero` и использует её для задания скорости игрового объекта `projGO`.

3. Сохраните все изменения в Visual Studio, чтобы убедиться, что все скрипты сохранены, а затем вернитесь в Unity.
4. Нажмите кнопку Play в Unity и попробуйте выстрелить. Вы должны увидеть серию очень частых выстрелов из бластера. В следующем разделе вы добавите класс Weapon, который позволит лучше управлять стрельбой, и замените функцию `TempFire()` на функцию `Fire()` этого класса.
