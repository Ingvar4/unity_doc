- **blaster [B]**: Если текущий тип оружия игрока - не бластер, происходит переключение на бластер, а количество орудий корабля сбрасывается до одного. Если же бластер уже выбран, количество орудий увеличивается.
- **spread [S]**: Если текущий тип оружия игрока - не веерный огонь (spread), происходит переключение на этот режим, а количество орудий корабля сбрасывается до одного. Если же веерный огонь уже выбран, количество орудий увеличивается.
- **shield [O]**: Увеличивает уровень щита игрока на 1.

### Графика для игрового объекта PowerUp [!toc]

Бонусы представляют собой букву, выполненную в виде трехмерного текста, с вращающимся кубом позади нее. (Некоторые из них можно увидеть на рисунке в начале этой главы.) Чтобы создать бонусы, выполните следующие шаги:  

1. Создайте новый объект **3D Text** (выберите в строке меню **GameObject > 3D Object > 3D Text**; этот пункт находится в самом низу списка **3D Object**). В данном случае мы используем именно **3D Text** (а не компоненты **Text**, с которыми вы уже сталкивались в **uGUI**), так как это позволяет тексту существовать в мировом 3D-пространстве, а не в экранном пространстве холста **uGUI Canvas**. (Здесь также можно было бы использовать **TextMeshPro**, но настройки для **3D Text** объяснить проще.)
2. Переименуйте новый объект **Text** в **PowerUp** и задайте ему следующие параметры:
**PowerUp** (3D Text) P:[ 10, 0, 0 ] R:[ 0, 0, 0 ] S:[ 1, 1, 1 ]
3. Установите свойства компонента **Text Mesh** для объекта **PowerUp** в соответствии с данными, показанными на рисунке. Обратите внимание: мы установили параметр **Character Size** (размер символа) равным 0,5, а **Font Size** (размер шрифта) - 38. При значениях **Character Size** = 1 и **Font Size** = 19 размер текста на экране был бы таким же, однако использование большего размера шрифта (**Font Size**) и меньшего размера символа (**Character Size**) заставляет Unity отрисовывать шрифт с более высоким разрешением, благодаря чему он выглядит лучше.

Настройки для PowerUp и дочернего объекта PowerCube перед присоединением каких-либо скриптов.  

4. Добавьте компонент Rigidbody к объекту PowerUp (*Component > Physics > Rigidbody*) и настройте его так, как показано на рисунке.
5. Установите для PowerUp слой физики (Physics Layer) в значение PowerUp.
6. Создайте новый куб (Cube) и сделайте его дочерним объектом PowerUp.
    - a. Переименуйте куб в PowerCube.
    - b. Задайте для PowerCube следующие параметры:  
PowerCube (Cube) P:[ 0, 0, 0 ] R:[ 0, 0, 0 ] S:[ 2, 2, 2 ]
7. Если вы создали PowerCube как дочерний объект PowerUp, он автоматически окажется в слое физики PowerUp; однако, если вы создали его отдельно, а затем сделали дочерним объектом PowerUp, вам необходимо вручную установить слой физики PowerCube в значение PowerUp.
8. Создайте пользовательский материал для куба PowerUp следующим образом:
    - a. Создайте новый материал с именем Mat_PowerUp в папке _Materials.
    - b. Перетащите материал Mat_PowerUp на объект PowerCube (дочерний объект PowerUp).
    - c. Выберите объект PowerCube.
    - d. Установите для материала Mat_PowerUp шейдер ProtoTools > UnlitAlpha (это делается через выпадающее меню в нижней части окна Inspector для объекта PowerCube, как показано на рисунке).
    - e. Нажмите кнопку Select в правом нижнем углу поля текстуры для Mat_PowerUp и выберите текстуру с именем PowerUp на вкладке Assets. Возможно, вам потребуется нажать на треугольник раскрытия в левом нижнем углу компонента Mat_PowerUp в окне Inspector, чтобы увидеть текстуру и другие настройки этого материала.
    - f. Установите для Mat_PowerUp основной цвет (Main Color) - голубой (cyan), что соответствует значениям RGBA: [0, 255, 255, 255]; после этого во вкладке Game можно будет увидеть, как объект PowerUp будет выглядеть с этим цветом.
    - g. Настройте компонент Box Collider объекта PowerCube как триггер (установите флажок рядом с параметром Is Trigger).
9. Еще раз проверьте, соответствуют ли все настройки объекта PowerUp и его дочернего объекта PowerCube тем, что показаны на рисунке, и сохраните сцену.
