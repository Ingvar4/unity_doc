description: Как в примере с циклом while, так и в примере с циклом do…while нам нужно было объявить и определить переменную i, инкрементировать переменную i, а затем проверить условие по переменной i; и каждое из этих действий выполнялось отдельным оператором.
---

Цикл `for` обрабатывает все эти действия в одной строке.

1. Измените код `Start()`, как показано в листинге, а затем сохраните и
запустите его в Unity.

```c#
void Start() {
    for ( int i = 0; i < 3; i++ ) {      //Loop: 0

        print( "Loop: " + i);            //Loop: 1
    
    }                                    //Loop: 2
}
```

Цикл `for` в этом примере выводит в панель Console тот же результат, что и
«более полезный» цикл while, но делает это с
помощью меньшего количества строк кода. Чтобы быть действительным, цикл
`for` должен состоять из блока инициализации, блока условия и блока
итерации. В приведенном выше примере эти три блока выглядят следующим
образом:

- Initialization clause: for `( int i = 0; ... ) {`
- Condition clause: for `( ... i < 3; ... ) {`
- Iteration clause: for `( ... ... i++ ) {`

Условие инициализации `( int i = 0; )` выполняется до начала цикла `for`.
Оно объявляет и определяет переменную, область действия которой
ограничена циклом `for`. Это означает, что `int i` в условии инициализации
перестанет существовать по завершении цикла `for`.  

Условие `( i < 3 )` проверяется перед каждой итерацией цикла `for`, включая
первую итерацию (так же, как условие проверяется перед первой итерацией
цикла `while`). Если условие выполняется, выполняется код, заключенный в
фигурные скобки цикла `for`.  

Условие итерации `( i++ )` выполняется после завершения каждой итерации
кода, находящегося в фигурных скобках цикла `for` (т. е. после каждого
выполнения строк между фигурными скобками `{ }` цикла `for` - в
данном случае это одна строка `print( "Loop: " + i );` -
выполняется оператор `i++`).  

После выполнения условия итерации условие проверяется снова, и если оно по-
прежнему истинно, код между фигурными скобками выполняется снова, а
условие итерации - еще раз. Это продолжается до тех пор, пока условие не
примет значение `false`, после чего цикл `for` заканчивается.  

Поскольку циклы `for` требуют, чтобы все три этих части были включены и
находились в одной строке, при работе с циклами `for` легче избежать
написания бесконечных циклов.

### Использование оператора декремента в предложении итерации

Хотя условие итерации обычно представляет собой оператор инкремента,
такой как `i++`, это не обязательно. В условии итерации можно
использовать любую операцию.  

Одним из наиболее распространенных альтернативных вариантов условия
итерации является обратный отсчет вместо прямой. Для этого используйте
оператор декремента в цикле `for`, как показано в листинге:

```c#
void Start() {
    for ( int i = 5; i > 2; i-) {                //Loop: 5
    
        print( "Loop: " + i );                   //Loop: 4
                              
    }                                            //Loop: 3
}
```

### Любая из трех частей for может быть пустой

Я знаю, что только что сказал вам, что в любом цикле `for` нужны условия
инициализации, сравнения и итерации, но любое из них может быть пустым,
если у вас есть веская причина для этого.  

Вы также можете использовать запятые для разделения связанных
предложений.

```c#
void Start() {
    int reps = 0, ops = 100;
    for ( ; Random.value < 0.8f; reps++, ops-- ) {
        // Nothing here. The body of the for loop can be empty too.
    }

    print( "I did " + reps + " repetitions. ops = " + ops );
}
```
>Random.value - это свойство (метод, который снаружи выглядит как поле), которое возвращает
разное число от 0 до 1 включительно (то есть возвращаемое значение может быть 0, 1 или любым числом с плавающей запятой между ними) при каждом вызове.

Обратите внимание, что по-прежнему присутствует блок инициализации, но он пуст (т. е. перед точкой с запятой ничего нет).  

Каждый раз, когда вы запускаете воспроизведение в Unity, этот код будет
выполнять разное количество повторений перед выходом. В среднем это
должно быть около 8, но количество повторений может варьироваться от 0
до 20 (до того, как вероятность станет слишком низкой).
