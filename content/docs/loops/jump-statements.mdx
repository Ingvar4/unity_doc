Одним из примеров, который уже был рассмотрен, является оператор `break` в конце каждого случая в операторе
`switch`.

### Использование операторов break для выхода из любого цикла

Вы также можете использовать операторы `break` для преждевременного
выхода из любой структуры цикла.

1. Чтобы увидеть пример, измените функцию `Start()`, чтобы она выглядела так, как показано в листинге кода

```c#
void Start() {

    for ( int i=0; i <10; i++ ) {

        print( i ); 

        if ( i == 3 ) { 
            break; 
        }
    }
}
```

Оператор `break` выходит из цикла `for`. Оператор `break` можно также использовать в циклах `while`, `do…while` и `foreach`.

2. Замените строки

```c#
void Start() {

    for ( int i=0; i <10; i++ ) { 
        print( i ); 
        if ( i >= 3 ) { 
            break;                 // a
        }
    }

    int j = 0;
    while (true) {
        print( j ); 
        if ( j > 2 ) break;        // b
        j++; 
    } 

    int k = 3;
    do {                           // c
        print( k ); 
        k--;
        if ( k <= 1 ) break;
    } while ( k > 0 );

    foreach (char c in "Hello") { 
      if ( c == 'l') {             // d
          break;
      }
          print( c );
    }
}
```

**a.** Здесь оператор `break` используется для выхода из цикла `for` до того, как `i` достигнет `10`.  

**b.** Оператор `break` здесь позволяет выйти из бесконечного цикла
`while`, когда `j > 2`. Эта строка также демонстрирует однострочную
версию оператора `if`. Если между фигурными скобками оператора `if`
находится только одна строка, фигурные скобки не требуются.  

**c.** Этот цикл `do…while` выводит только `3` и `2`, потому что во второй
итерации цикла декремент `k--` уменьшает `k` до `1`, после чего условие
оператора `if` оценивается как `true` и цикл прерывается.  

**d.** Когда значение c становится «l» на третьей итерации этого цикла
`foreach`, выражение `if` оценивается как `true`, и цикл
`foreach` завершается.  

Потратьте время на изучение каждого из приведенных выше примеров
циклов и убедитесь, что вы понимаете, почему каждый из них генерирует
показанный вывод. Если какой-либо из них кажется непонятным, попробуйте
использовать отладчик, чтобы поставить точку останова перед циклом, а
затем пройти пошагово каждую итерацию, наблюдая за изменением значений
i, j, k и c. 

### Пропуск оставшейся части итерации с помощью `continue`

С помощью оператора `continue` можно заставить программу пропустить
оставшуюся часть текущего цикла и перейти к следующему. Когда
компьютер выполняет команду `continue`, он пропускает оставшуюся часть текущей
итерации, не выходя из цикла полностью, как показано в листинге:

```c#
void Start() {
    for (int i=0; i <=360; i++) {

        if ( (i % 90) != 0) { 
            continue; 
        } 

        print( i ); 
    }
}
```

В листинге кода всякий раз, когда `(i % 90) != 0` (иными словами,
при делении `i` на `90` остаток отличен от `0`), оператор `continue`
заставляет цикл `for` перейти к следующей итерации, пропуская строку
`print( i
);`. Оператор `continue` также можно использовать в циклах `while`,
`do… while` и `foreach`.

### Оператор модуля [!toc]
Строка листинга кода, содержащая оператор перехода
`continue`, является первым примером использования в этой книге
оператора модуля (`%`).
Оператор модуля (или, как его чаще называют, «mod») возвращает
остаток от деления одного числа на другое. Например, выражение `12
% 5` вернет значение `2`, поскольку остаток от деления 12 на 5 равен 2
(число 5 входит в 12 два раза (5 × 2 = 10), оставляя остаток 2).
Оператор mod можно использовать и с числами с плавающей запятой,
поэтому `12.6f % 1f` вернет `0.6f`, поскольку 1 делит 12 двенадцать
раз, оставляя остаток 0.6.  

Аналогично, выражение `12.6f % 0.5f` даст в результате
`0.1f`, поскольку число 0.5 входит в 12.6 двадцать пять раз (0.5 ×
25 = 12.5), а остаток составляет
остаток 0,1.
Однако из-за неточности вычислений с числами с плавающей запятой
выражение `12.6f % 0.5f` может вернуть `0.1000004f`, что не
равно `0.1f`. Если вы работаете с числами с плавающей запятой и
оператором modulo, я настоятельно рекомендую использовать
приближенные методы сравнения результатов.

### Заключение

Понимание циклов - один из ключевых элементов становления хорошего
программиста. Однако ничего страшного, если сейчас не всё это кажется вам
совершенно понятным. После того как вы начнёте использовать циклы при
разработке реальных прототипов игр, всё станет
для вас более ясным. Просто убедитесь, что вы действительно вводите каждый
пример кода в Unity и запускаете его, чтобы лучше понять материал.  

Также помните, что в своем коде я обычно использую `for` и `foreach`, но
редко или вообще не использую `while` и `do…while` из-за повышенной
вероятности того, что `while` и `do…while` могут привести к бесконечному
циклу.  

В следующей главе вы узнаете о массивах и списках - двух видах
упорядоченных коллекций однородных элементов - и увидите, как циклы
используются для итерации по этим коллекциям. Вы также узнаете о словарях - неупорядоченных коллекциях - и некоторых других коллекциях.
