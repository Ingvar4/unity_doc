---
title: Циклы foreach
description: Цикл foreach — это нечто вроде автоматического цикла for, который можно использовать для всего, что поддается перечислению.
---

В C# большинство коллекций данных поддаются перечислению, включая строки
(которые представляют собой коллекцию символов), а также списки и
массивы. В примере из листинга кода консоль будет выводить по одному символу из строки `str` при каждой итерации цикла `foreach`.

```c#
void Start() {

    string str = "Hello"; 

    foreach( char chr in str )
    {
        print( chr ); 
    } 
}
```

Цикл `foreach` гарантирует, что он будет перебирать все элементы
перечисляемого объекта. В данном случае он перебирает каждый символ в
строке «Hello». Циклы `foreach` будут рассмотрены более подробно в
следующей главе в рамках обсуждения списков и массивов.
