## Цикл while

Цикл `while` — это самая простая структура цикла. Однако это также
означает, что ему не хватает безопасности, которую обеспечивает
использование более современных форм циклов. В своем коде я почти
никогда не использую циклы `while` из-за опасности создания
бесконечного цикла.

### Опасность бесконечных циклов

Бесконечный цикл возникает, когда программа входит в цикл и не может из
него выйти. Давайте напишем один, чтобы посмотреть, что произойдет.

1. Откройте скрипт Loops C# в Visual Studio (двойным щелчком по нему
на панели «Проекты») и добавьте код:

    ```c#
    using System.Collections;
    using System.Collections.Generic;
    using UnityEngine;

    public class Loops : MonoBehaviour {
        // Start is called before the first frame update
        void Start() {
            while ( true ) {
                print( "Loop" );
            }
        }
        // void Update() { } // Please delete the Update method
    }
    ```
2. Сохраните этот скрипт, выбрав *«Файл» > Сохранить* в панели меню
Visual Studio.

приложение, они зависали весь компьютер и требовали перезагрузки.  

Итак, что же произошло, что привело к бесконечному циклу? Чтобы это
выяснить, взгляните на цикл `while`.

```c#
while ( true ) {
    print( "Loop" );
}
```

Все, что находится в фигурных скобках цикла `while`, будет выполняться
повторно, пока условие в скобках равно `true`. В строке 8 условие всегда
равно `true`, поэтому строка `print( "Loop" );` будет повторяться
бесконечно.  

Но вы можете задаться вопросом: если эта строка повторялась бесконечно,
почему вы никогда не видели вывода «Loop» в панели консоли? Отличный
вопрос!  

Хотя функция `print()` вызывалась много раз (вероятно, сотни, тысячи или
даже миллионы раз, прежде чем вы решили принудительно закрыть Unity), вы
так и не смогли увидеть вывод в панели консоли, потому что Unity застрял в
бесконечном цикле while и не мог перерисовать окно Unity (что было бы
необходимо для отображения изменений в панели консоли).

### Более полезный цикл while

Давайте создадим цикл `while`, который не выводит Unity из строя.

1. Откройте скрипт Loops C# в Visual Studio и измените код, показанный в листинге кода:

```c#
void Start() {
    int i = 0;

    while ( i < 3 ) {             //Loop: 0

        print( "Loop: " + i );    //Loop: 1

        i++;                      //Loop: 2
    }
}
```

2. Сохраните код, вернитесь в Unity и нажмите «Play».

На этот раз Unity не зацикливается в бесконечном цикле, поскольку условие
цикла `while` `(i < 3)` в конечном итоге становится ложным.

В строке 10 вызывается `print( "Loop: " + i )` при каждом проходе
цикла `while`. Важно отметить, что условие проверяется перед каждой
итерацией цикла.

<Callout>
### Операторы инкремента и декремента [!toc]
В строке 10 впервые встречается оператор
инкремента (`++`). Оператор инкремента увеличивает значение следующей за ним переменной на `1`. Таким образом, если `i=5`, то оператор `i++;` установит значение `i` равным `6`.  

Существует также оператор декремента (`--`). Оператор декремента
уменьшает значение переменной на `1`.  

Операторы инкремента и декремента можно размещать как перед, так
и после имени переменной, и в зависимости от этого оператор будет
интерпретироваться по-разному (т. е. `++i` и `i++` действуют немного
по-разному). Разница заключается в том, возвращается ли исходное
значение (`i++`) или возвращается ли увеличенное значение (`++i`). Вот
пример для пояснения.

```c#
7 void Start() {
8     int i = 1;
9         print( i );     // Output: 1
10        print( i++ );   // Output: 1
11        print( i );     // Output: 2
12        print( ++i );   // Output: 3
13 }
```
Как видно, в строке 9 выводится текущее значение `i`, равное `1`. Затем,
в строке 10, оператор пост-инкмента `i++` сначала возвращает
текущее значение `i`, которое выводится (в результате получается `1`), а
затем инкрементирует `i`, устанавливая его значение равным `2`.  

В строке 11 выводится текущее значение `i`, равное `2`. Затем в строке 12
оператор пре-инкмента `++i` сначала увеличивает значение `i` с `2` до
`3`, а затем возвращает его в функцию `print`, которая выводит `3`.

</Callout>

>В большинстве примеров в этой главе используемая переменная
итерации будет называться `i`. Имена переменных `i`, `j` и `k` часто
используются программистами в качестве переменных итерации (т.
е. переменных, которые инкрементируются в цикле), и в результате
они редко используются в каких-либо других ситуациях в коде.
Поскольку эти переменные так часто создаются и уничтожаются в
различных циклах, вам следует избегать использования имен переменных `i`, `j` или
`k` для чего-либо еще.
