1. В сцене `_Scene_Collections` создайте новый скрипт C# с именем `ListEx` прикрепите его к
`Main Camera`.
2. Дважды щелкните скрипт `ListEx` на панели Project, чтобы открыть его в Visual
Studio, и добавьте выделенный жирным шрифтом код, показанный в листинге
кода. Комментарии в стиле `// a` в крайней правой части листинга кода
являются ссылками на пояснения, приведенные после кода.

```c#
using System.Collections;                             // a
using System.Collections.Generic;                     // a
using UnityEngine;                                    // a

public class ListEx : MonoBehaviour {
    public List<string> sList;                        // b

    void Start () {
        sList = new List<string>();                   // c
        sList.Add( "Experience" );                    // d
        sList.Add( "is" );
        sList.Add( "what" );
        sList.Add( "you" );
        sList.Add( "get" );
        sList.Add( "when" );
        sList.Add( "you" );
        sList.Add( "don’t" );
        sList.Add( "get" );
        sList.Add( "what" );
        sList.Add( "you" );
        sList.Add( "wanted." ); // This quote is from my professor, Dr. Randy Pausch (1960-2008)

        print( "sList Count = "+sList.Count );        // e
        print( "The 0th element is: "+sList[0] );     // f
        print( "The 1st element is: "+sList[1] );
        print( "The 3rd element is: "+sList[3] );
        print( "The 8th element is: "+sList[8] );

        string str = "";
        foreach (string sTemp in sList) {             // g
            str += sTemp+" ";
        }
        print( str );
    }
}
```

**a.** Это стандартный порядок, в котором вы увидите три строки `using`.
Помните, что вы должны включить `using
System.Collections.Generic;`, чтобы `List<T>` существовали в
вашем скрипте.  

**b.** Здесь объявляется `List<string> sList`. Все типы данных обобщенных
коллекций имеют имя, за которым следуют угловые скобки `<>`, заключающие
указанный тип данных. В данном случае List представляет собой список строк.
Однако преимущество обобщенных типов заключается в том, что их можно
использовать для любого типа данных. Вы с такой же легкостью можете создать
`List<int>`, `List<GameObject>`, `List<Transform>`, `List<Vector3>` и
т. д. Вы должны указать тип списка во время объявления.  

**c.** Объявление `sList` делает `sList` именем переменной, которая
может содержать список строк, но значение `sList` равно `null` (т. е. у него
нет значения), пока вы не инициализируете `sList`. До этой
инициализации любая попытка добавить элементы в `sList` привела бы к
ошибке. При инициализации списка необходимо повторить тип списка в
операторе `new`. Вновь инициализированный список не содержит элементов и
имеет счетчик (Count) равный нулю.  

> Хотя, как правило, все списки следует инициализировать перед использованием, утверждение о том,
что в данном случае инициализация обязательна, с технической точки зрения неверно. Поскольку
sList является общедоступным полем данного скрипта, он фактически инициализируется
инспектором Unity, поэтому в этом конкретном случае можно обойтись без 9-й строки в листинге
кода  

**d.** Функция `Add()` списка добавляет элемент в список. Это вставит строковый
литерал `"Experience"` в 0-й элемент списка.  

**e.** Свойство `Count` списка возвращает целое число, представляющее
количество элементов в списке. Вывод (т. е. вывод в консоль из этой строки):

```c#
sList Count = 12
```

**f.** Данные строки демонстрируют использование доступа через скобки
(например, `sList[0]`). Доступ через скобки использует скобки `[]` и целое
число для ссылки на конкретный элемент в списке или массиве. Целое число
между скобками называется "индексом". Вывод:

```
The 0th element is: Experience
The 1st element is: is
The 3rd element is: you
The 8th element is: get
```

**g.** `foreach` (представленный в предыдущей главе) часто используется со
списками и другими коллекциями. Так же, как строка представляет собой
коллекцию символов, `List<string> sList` представляет собой коллекцию
строк. Переменная string `sTemp` имеет область действия, ограниченную
оператором `foreach`, поэтому она перестанет существовать после завершения
цикла `foreach`. Поскольку списки являются статически типизированными (т.
е. C# знает, что `sList` является `List<string>`), элементы `sList` можно
присваивать переменной string `sTemp` без какого-либо преобразования. Это
одно из основных преимуществ типа List перед нетипизированным типом
ArrayList. Вывод:

```
Experience is what you get when you don’t get what you wanted.
```

3. Как всегда, не забудьте сохранить скрипт в Visual Studio после завершения
редактирования.
4. Вернитесь в Unity и выберите *Main Camera* в панели *Hierarchy*. Убедитесь, что
ListEx прикреплен в качестве компонента к *Main Camera*. Если нет, сделайте это сейчас.  

Теперь вы можете увидеть, что `List<string> sList` отображается в компоненте
`ListEx` (Script) на панели "Инспектор". Если запустить сцену Unity, можно щелкнуть
треугольник раскрытия рядом с sList в "Инспекторе" и увидеть значения, которые в
него входят. Массивы и списки отображаются в "Инспекторе", а словари — нет.

### Важные свойства и методы `List<T>` [!toc]

Для списков доступно множество свойств и методов, но наиболее часто
используются следующие. Все эти примеры методов относятся к следующему
`List<string> sL` и не являются кумулятивными. Другими словами,
каждый пример начинается со списка `sL`, как он определен в следующих
нескольких строках, без изменений, внесенных другими примерами.

```c#
List<string> sL = new List<string>();
sL.Add( "A" ); sL.Add( "B" ); sL.Add( "C" ); sL.Add( "D" );
// Resulting in the List: [ "A", "B", "C", "D" ]
```

**Свойства**: позволяют получить доступ к информации о списке.  
- `sL[2]` (доступ с помощью скобок) — возвращает элемент списка по
индексу, указанному в параметре (`2`). Поскольку `C` является вторым
элементом, `sL[2]` возвращает `C`.
- `sL.Count` — возвращает количество элементов, находящихся в
данный момент в списке. Поскольку длина списка может меняться со
временем, Count очень важен. Последний действительный индекс в
списке всегда равен `Count-1`. Значение `sL.Count` равно `4`, поэтому
последний действительный индекс равен `3`.  

**Методы**: функции, позволяющие изменять список.
- `sL.Add("Hello")` — добавляет "Hello" в конец sL. В этом
случае sL становится: [ "A", "B", "C", "D", "Hello" ].
- `sL.Clear()` — удаляет все существующие элементы из sL,
возвращая его в пустое состояние. sL становится пустым: `[ ]`.
- `sL.IndexOf("A")` — Находит в sL самое раннее вхождение
параметра "A" и возвращает индекс этого элемента. Поскольку "A"
является 0-м элементом sL, этот вызов возвращает 0. Если переменная
не существует в списке, возвращается -1.
- `sL.Insert(2, "Ba")` — вставляет второй параметр ("Ba") в список
sL по индексу, указанному первым параметром (2). При этом
последующие элементы списка сдвигаются вправо. В данном случае
список sL примет вид [ "A", "B", "Ba", "C", "D" ].

Допустимые значения индекса для первого параметра находятся в диапазоне от 0
до sL.Count. Любое значение вне этого диапазона вызывает ошибку
выполнения.  

- `sL.Remove("C")` — удаляет указанный элемент из списка. sL
становится [ "A", "B", "D" ]. Если бы в списке оказалось два
элемента "C", удалился бы только первый.
- `sL.RemoveAt(1)` — удаляет из списка элемент с указанным индексом.
Поскольку "B" является первым элементом списка, sL становится [
"A", "C", "D" ].
