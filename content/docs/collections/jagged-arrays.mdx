---
title: Неравномерные массивы
description: Неравномерный массив - это массив массивов.
---

Он похож на многомерный массив,
но позволяет подмассивам иметь разную длину. Вы создадите неравномерный
массив, содержащий следующие данные:

```
|A|B|C|D|
|E|F|G|
|H|I|
|J|_|_|K|
```

Как видно, 0-я и 3-я строки содержат по четыре элемента, тогда как 1-я и 2-я строки
содержат соответственно три и два элемента. Обратите внимание, что допускаются
нулевые элементы, как показано в 3-й строке. Фактически, вся строка может быть
нулевой. Выполните следующие шаги, чтобы создать этот неравномерный массив:  

1. Создайте новый скрипт C# с именем `JagedArayEx` и прикрепите его к *Main Camera*.
2. Откройте `JagedArayEx` в Visual Studio и введите код:

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class JaggedArrayEx : MonoBehaviour {
    public string[][] jArray;// a

    void Start() {
        jArray = new string[4][];// b

        jArray[0] = new string[4];// c
        jArray[0][0] = "A";
        jArray[0][1] = "B";
        jArray[0][2] = "C";
        jArray[0][3] = "D";

        // The following lines use single-line Array initialization syntax // d
        jArray[1] = new string[] { "E", "F", "G" };
        jArray[2] = new string[] { "H", "I" };

        jArray[3] = new string[4];// e
        jArray[3][0] = "J";
        jArray[3][3] = "K";

        print( "The Length of jArray is: " + jArray.Length );// f
        // Outputs: The Length of jArray is: 4

        print( "The Length of jArray[1] is: " + jArray[1].Length); // g
        // Outputs: The Length of jArray[1] is: 3

        string str = "";
        foreach ( string[] sArray in jArray ) {// h

            foreach ( string sTemp in sArray ) {
                if ( sTemp != null ) {
                    str += "|" + sTemp; // "|" is a pipe
                } else {
                    str += "|_"; // "|_" is a pipe and underscore
                }
            }
        str += "|\n";
        }

        print( str );
    }
}
```

**a.** В строке 6 `jArray` объявляется как неравномерный массив (т. е. массив
массивов). Если `string[]` представляет собой набор строк, то `string[][]`
представляет собой набор массивов строк (или string[]s).  

**b.** В 9-й строке `jArray` инициализируется как неравномерный массив длиной 4.
Обратите внимание, что вторая пара скобок пока пуста, что означает, что
подмассивы могут иметь любую длину; однако после того, как их длины будут
заданы, они станут фиксированными и их будет сложно изменить.  

Другими словами, мы инициализируем `jArray` с длиной `4`, но каждый
массив `string[]` внутри `jArray` ещё не инициализирован, поэтому его
длина ещё не задана.  

**c.** В строке 11 0-й элемент `jArray` определяется как подмассив строк длиной `4`. В
строках 12–15 в этот подмассив вставляются элементы: первый набор скобок
(`[0]`) используется для доступа к 0-му подмассиву `jArray`, а второй - для
вставки строки в каждый из четырех элементов этого подмассива.  

**d.** В строках 18 и 19 используется однострочная форма инициализации массива
для определения значений `jArray[1]` и `jArray[2]`. Поскольку элементы
массива определены между фигурными скобками, длину массива не нужно
указывать явно (отсюда пустые скобки в `new string[] { "E", "F", "G" };` ).  

**e.** В строках 21–23 третий элемент `jArray` определяется как `string[]`
длиной `4`, а затем заполняются только 0-й и 3-й элементы этого `string[]`,
оставляя элементы 1 и 2 нулевыми.  

**f.** В строке 25 выводится "Длина jArray: 4". Поскольку `jArray` - это
массив массивов (а не многомерный массив), `jArray.Length` учитывает
только количество подмассивов (и не учитывает, сколько элементов в каждом
подмассиве).  

**g.** В строке 28 выводится "Длина jArray[1] равна: 3". Поскольку
`jArray` представляет собой массив массивов, длину первого подмассива
([ "E", "F", "G"]) можно легко определить.  

**h.** В неравномерных массивах `foreach` работает отдельно с массивом и
подмассивами. `foreach` на `jArray` проходит по четырем элементам
`string[]` (массив строк) неравномерного массива `jArray`, а `foreach`
на любом из этих `string[]` проходит по строкам внутри этого отдельного
подмассива. Обратите внимание, что `sArray` - это `string[]` (массив
строк), а `sTemp` - строка.  

3. Сохраните скрипт `JagedArayEx` , вернитесь в Unity и нажмите «Play».

```c#

|A|B|C|D|
|E|F|G|
|H|I|
|J|_|_|K|
```

4. Остановите выполнение Unity, нажав кнопку «Play» еще раз (чтобы она не была
синей). Как я упоминал ранее, в строке 33 возникнет ошибка
`NullReferenceException`, если одна из строк `jArray` была бы `null`. В этом
случае `sArray` был бы `null`, и попытка выполнить оператор `foreach` в строке
33 на переменной `null` привела бы к ошибке `NullReferenceException`
(попытка обратиться к элементу объекта, который является `null`). Оператор
`foreach` будет пытаться получить доступ к данным `sArray`, таким как
`sArray.Length` и `sArray[0]`. Поскольку переменные с нулевым значением не
имеют элементов или значения, попытка доступа к таким элементам, как
`null.Length`, вызывает ошибку.  

>Если вы хотите увидеть эту ошибку самостоятельно, вы можете закомментировать строку 19 (которая
определяет `jArray[2]`) и запустить проект снова. Тогда будет сгенерирована ошибка
`NullReferenceException`.

### Использование циклов for вместо foreach для неровных массивов.

Вы также можете использовать циклы `for`, основанные на длине массива и
подмассивов.  

1. Если вы хотите попробовать это, откройте файл `JaggedArrayEx` в Visual Studio
и замените цикл `foreach` в строках 32–41 листинга кодом:

```c#
void Start() {
 …
    string str = "";
    for (int i=0; i <jArray.Length; i++) {
        for (int j=0; j <jArray[i].Length; j++) {
            if (jArray[i][j] != null) {
                str += " | " +jArray[i][j];
            } else {
                str += " | ";
            }
        }
        str += " | \n";
    }
…
}
```

Этот код дает точно такой же результат, как и циклы foreach, показанные
ранее. Выбор между for и foreach будет зависеть от конкретной ситуации.  

2. Выберите *Main Camera* и с помощью инспектора отключите компонент *JagedArayEx (Script)*.
