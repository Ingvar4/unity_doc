```c#
using UnityEngine;
using System.Collections;
using System.Collections.Generic;
```

Каждая из этих строк `using` загружает библиотеку кода и дает скрипту
возможность использовать код внутри этой библиотеки. Порядок этих строк не
имеет значения, и порядок по умолчанию на самом деле менялся на протяжении
многих лет. Я расположил их в таком порядке, чтобы было проще их обсуждать.  

`using UnityEngine;` - это самая важная библиотека в программировании
Unity, так как она предоставляет этому скрипту на C# доступ ко всем стандартным
объектам Unity, включая такие, как MonoBehaviour, GameObject, Rigidbody,
Transform и т. д.  

`using System.Collections;` позволяет скрипту использовать несколько
нетипизированных коллекций, таких как ArrayList (которые вы видите в некоторых
старых учебниках по Unity). Поскольку это нетипизированные коллекции, они могут
содержать любой тип данных в каждом элементе (например, строку в одном элементе и
изображение или песню в другом). Такая гибкость может привести к неаккуратности, что может значительно усложнить отладку и написание кода, поэтому я
настоятельно не рекомендую использовать коллекции без типов. Однако
`System.Collections` также включает интерфейс IEnumerator, который
позволяет работать корутинам, поэтому нам нужно включить его (и просто
игнорировать коллекции без типов, которые он поддерживает).  

`using System.Collections.Generic;` имеет решающее значение для этой
главы, поскольку он включает несколько обобщенных коллекций, в том числе List и
Dictionary. Обобщенная коллекция может содержать данные любого одного типа,
который указывается с помощью угловых скобок `<>`. Примеры объявлений общих коллекций включают:

>Может показаться странным, что «общая» коллекция может содержать только один тип данных. Слово
generic используется здесь для обозначения возможности (через `<T>`) создавать тип данных, такой как List,
общим образом, который может быть статически типизирован для любого типа данных. Написание общих
классов, таких как List, выходит за рамки этой книги, но вы можете поискать в Интернете «C# generic», чтобы узнать больше.  

- `public List<string> sList;` объявляет список строк.
- `public List<GameObject> goList;` объявляет список объектов GameObject.
- `public Dictionary<char, string> acronymDict;` - объявляет
словарь строк, в котором в качестве ключей используются символы (например,
символ «o» может использоваться для доступа к строке «Okami»).
