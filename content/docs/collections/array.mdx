Массивы встроены в ядро языка C#, поэтому для их использования не требуется импортировать какие-либо
библиотеки (с помощью оператора using). Кроме того, массивы могут быть
многомерными и иметь неравномерную структуру, что может оказаться весьма
полезным.  

Массивы имеют фиксированную длину, которая должна быть определена при их
создании. Начнем с создания простого линейного массива:

1. Создайте новый скрипт C# с именем `ArrayEx` и прикрепите его к *Main Camera*.
2. Дважды щелкните скрипт C# `ArayEx` на панели "Проект", чтобы открыть его в
Visual Studio, и введите код, показанный в листинге

```c#
using UnityEngine;                                            // a

public class ArrayEx : MonoBehaviour {
    public string[] sArray;                                   // b

    void Start () {
        sArray = new string[10];                              // c

        sArray[0] = "These";                                  // d
        sArray[1] = "are";
        sArray[2] = "some";
        sArray[3] = "words";

        print( "The length of sArray is: "+sArray.Length );   // e

        string str = "";
        foreach (string sTemp in sArray) {                    // f
            str += "|"+sTemp;
        }
        print( str );
    }
}
```

**a.** В отличие от списков и словарей, для работы массивов не требуется
`System.Collections.Generic`. Однако для работы класса
MonoBehaviour по-прежнему требуется UnityEngine.  

**b.** Кроме того, в отличие от списка (List) или словаря (Dictionary), массив в C# на
самом деле не является отдельным типом данных (поэтому слово "array" в
этом разделе всегда пишется со строчной буквы и никогда не выделяется
жирным шрифтом в коде); скорее это коллекция, формируемая из любого
существующего типа данных путем добавления скобок после имени типа. Тип
sArray объявлен не как string, а как `string[]` — коллекция
нескольких строк. Примечание: Хотя sArray объявлен как массив в этой
строке, его длина не задана до тех пор, пока он не будет инициализирован (в
строке // c).  

**c.** Здесь `sArray` инициализируется как `string[]` длиной 10. При
инициализации массива его элементы заполняются значениями по умолчанию
для данного типа данных. Для `int[]` или `float[]` значением по умолчанию
будет `0`. Для `string[]` и любых сложных типов данных, таких как
`GameObject[]`, каждый элемент массива заполняется значением `null` (что
указывает на отсутствие присвоенного значения).  

**d.** В отличие от списков, где используется метод `Add()`, стандартные массивы
используют доступ через скобки как для присвоения значений, так и для
извлечения значений из массива.  

Изменение длины массива после его инициализации невозможно  

>Метод `System.Array.Resize()` фактически позволяет изменить размер массива, но на самом
деле он 1) создает новый массив новой длины, 2) копирует все элементы из старого массива в новый
и 3) заменяет старый массив новым. https://docs.microsoft.com/en-us/dotnet/api/system.array.resize —
доступ 16 августа 2021 г.  

**e.** Вместо использования Count, как в обычных коллекциях C#, массивы используют свойство Length. Важно отметить (как видно из приведенного выше кода), что Length возвращает всю длину массива, включая как определенные элементы (например, sArray[0] — sArray[3] в предыдущем коде), так и пустые элементы (т. е., все еще имеющие свое значение по умолчанию, неопределенное, как sArray[4] — sArray[9] в предыдущем коде).
Вывод:  

```
The length of sArray is: 10
```

**f.** `foreach` работает с массивами так же, как и с другими коллекциями C#.
Единственное отличие заключается в том, что массив может содержать пустые
или нулевые элементы, и foreach все равно будет перебирать их. Как и в
примере с `List<string>` выше, здесь sTemp — это строка, которой цикл
foreach временно присвоит значение каждого элемента sArray. Вывод:

```
|These|are|some|words||||||
```

3. Сохраните скрипт `ArayEx`, вернитесь в Unity и нажмите "Play".
4. При запуске кода убедитесь, что в панели Hierarchy выбрана Main Camera. Это
позволит вам открыть треугольник раскрытия рядом с sArray в компоненте
ArrayEx (Script) панели Inspector и увидеть элементы sArray.

```
The length of sArray is: 10
|These|are|some|words||||||
```

### Пустые элементы в середине массива

Одна из возможностей массивов, недоступная в списках Lists, — это наличие
пустого элемента в середине массива. Это может пригодиться в игре, если у вас
есть, например, шкала очков, где у каждого игрока есть свой маркер, но между
маркерами могут быть пустые ячейки. Чтобы добавить пустые элементы между
строками в массиве, выполните следующие действия:  

>Добавление нулевого элемента в список, в результате чего в середине появляется пустой элемент,
технически возможно, но я сам никогда этим не пользовался  

1. Измените строки скрипта `ArrayEx`:

```c#
…
sArray[0] = "These";
sArray[1] = "are";
sArray[3] = "some";
sArray[6] = "words";
…
```

2. Сохраните скрипт `ArayEx`, вернитесь в Unity и нажмите "Play".

Вывод кода из последней строки метода `Start()` теперь будет выглядеть следующим
образом:

```
|These|are||some|||words|||
```

Как видно из вывода, массив sArray теперь имеет пустые элементы по
индексам 2, 4, 5, 7, 8 и 9.  

3. Не выходя из режима воспроизведения Unity, выберите Main Camera и
раскройте треугольник рядом с sArray (под компонентом ArrayEx (Script)),
чтобы увидеть структуру `sArray` в инспекторе.  

Пока индекс (например, 0, 1, 3 и 6 в данном случае) присваиваемого значения
находится в допустимом диапазоне массива, вы можете использовать доступ через
квадратные скобки, чтобы поместить значение в любую точку массива, и цикл
`foreach` будет корректно обрабатывать его.  

Попытка присвоить значение индексу, выходящему за пределы заданного диапазона
массива (например, sArray[10] = "oops!"; или sArray[99] =
"error!";), приведет к следующей ошибке выполнения:

```
IndexOutOfRangeException: Index was outside the bounds of the array.
```

Попытка доступа к несуществующему индексу массива также приведет к той же
ошибке выполнения. Например, print( sArray[20] ); также вызовет
исключение IndexOutOfRangeException.  

Как и в случае с любой ошибкой выполнения, IndexOutOfRangeException
завершит работу скрипта, вызвавшего ее, пропустив все остальные строки в
скрипте.  

4. Верните код в исходное состояние

```c#
sArray[0] = "These";                               
sArray[1] = "are";
sArray[2] = "some";
sArray[3] = "words";
```

### Пропуск нулевых элементов массива с помощью `foreach`

Иногда вам может понадобиться выйти из цикла при первом достижении нулевого
элемента массива (например, массив длиной 1000, в котором есть только несколько
элементов в начале и нет нулевых элементов между ними). Вот один из способов
сделать это:

1. Запустите проект еще раз и посмотрите на вывод, который вернулся к прежнему
состоянию:

```
|These|are|some|words||||||
```

Оператор `str += "|"+sTemp;` объединяет (т. е. добавляет)
вертикальную черту (`|`) в конец str перед каждым элементом массива.
Несмотря на то, что `sArray[4]–sArray[9]` по-прежнему имеют значение по
умолчанию `null`, они учитываются циклом `foreach` и проходят итерацию. Это
хорошая возможность использовать оператор перехода break для досрочного
выхода из цикла `foreach`.

2. Добавьте новую строку в цикл в коде, как показано в листинге кода

```c#
…
foreach (string sTemp in sArray) {
      str += "|"+sTemp;
      if (sTemp == null) break;
}
…
```

3. Сохраните скрипт `ArayEx`, вернитесь в Unity и нажмите "Play".

```
|These|are|some|words|
```

Когда в C# выполняется итерация по `sArray[4]`, в конец `str` по-прежнему
добавляется `"|" + null`, но затем проверяется `sArray[4]`, обнаруживается, что
он равен `null`, и цикл `foreach` прерывается, что не позволяет выполнить
итерацию по элементам `sArray[5]–sArray[9]`.

### Важные свойства и методы массивов [!toc]

Из всех свойств и методов, доступных для массивов, перечисленные в
этой панели используются чаще всего. Все они относятся к
следующему массиву и не являются кумулятивными.

```c#
string[] sA = new string[] { "A", "B", "C", "D" }; // Note braces {} 
// Creates the new array sA: [ "A", "B", "C", "D" ]

```

Здесь вы видите выражение инициализации массива, которое позволяет
объявить, инициализировать и заполнить массив в одной строке (в отличие от
оператора инициализации массива `sArray = new string[10];`,
который просто задает длину). Обратите внимание, что при использовании
этой формы выражения инициализации массива длина массива
подразумевается по количеству элементов между фигурными скобками и не
требует указания; более того, если вы используете фигурные скобки для
определения массива, вы не можете использовать число между скобками в
объявлении массива для указания длины, отличной от количества элементов
между фигурными скобками.  

**Свойства**  

- `sA[2]` (доступ через квадратные скобки): возвращает элемент массива
с индексом, указанным в параметре (2). Поскольку "C" является
вторым элементом sA, возвращается: "C".
Если параметр индекса находится за пределами допустимого диапазона
массива (допустимый диапазон для sA составляет от 0 до 3), будет
сгенерирована ошибка выполнения IndexOutOfRangeException.
- `sA[1] = "Bravo"` (доступ с помощью скобок, используемый для
присваивания): присваивает значение, находящееся справа от оператора
присваивания =, указанной позиции в массиве, заменяя предыдущее
значение. sA станет [ "A", "Bravo", "C", "D" ].
Если параметр индекса находится за пределами допустимого диапазона
массива, будет сгенерирована ошибка выполнения
IndexOutOfRangeException.
- `sA.Length`: Возвращает общий размер массива. Элементы
учитываются независимо от того, были ли они присвоены или по-
прежнему имеют значения по умолчанию. Возвращает 4.  

**Статические методы**

Статические методы, представленные здесь, являются частью класса
`System.Array` (определенного библиотекой System) и могут
действовать на массивы, придавая им некоторые возможности списков.
Здесь вы увидите, что вместо импорта всего System (с помощью using
System;) я явно указываю на Array как System.Array, что говорит C#
конкретно обращаться только к классу Array библиотеки System. Это
связано с тем, что в библиотеке System есть некоторые классы (такие как
Random), имеющие те же имена, что и классы в UnityEngine, поэтому
импорт всей библиотеки System вызвал бы несколько мелких неудобств.

- `System.Array.IndexOf( sA, "C" )`: Находит первый экземпляр
элемента "C" в массиве sA и возвращает индекс этого элемента.
Поскольку "C" является вторым элементом sA, возвращается 2.
Если переменная не существует в массиве, возвращается -1. Это часто
используется для определения того, содержит ли массив конкретный
элемент.
- `System.Array.Resize( ref sA, 6 )`: Это метод C#, который
изменяет длину массива. Первый параметр — это ссылка на экземпляр
массива в памяти (поэтому требуется ключевое слово ref), а второй —
новая длина. После этого sA станет [ "A", "B", "C", "D",
null, null ].  

Если второй параметр указывает длину, меньшую, чем у исходного
массива, лишние элементы будут удалены.
`System.Array.Resize( ref sA, 2 )` приведет к тому, что sA
станет [ "A", "B" ]. System.Array. Resize() не работает с
многомерными массивами, описанными далее в этой главе.
