Одним из основных
преимуществ словаря является постоянное время доступа. Это означает, что
независимо от того, сколько элементов вы вставите в словарь, на поиск элемента
уйдет одинаковое количество времени. Сравните это со списком или массивом, где
вам приходится поочередно проходить по каждому элементу линейной коллекции;
по мере увеличения размера списка или массива время, необходимое для поиска
конкретного элемента, также увеличивается, особенно если искомый элемент
оказывается последним в коллекции.  

Словари связывают ключ и значение. Ключ используется для доступа к значению.  

1. Создайте новый скрипт C# с именем `DictionaryEx` и прикрепите его к *Main Camera*.
2. Откройте скрипт в Visual Studio и введите код

```c#
using System.Collections;
using System.Collections.Generic;                                         // a
using UnityEngine;

public class DictionaryEx : MonoBehaviour {
    public Dictionary<string,string> statesDict;                          // b

    void Start () {
        statesDict = new Dictionary<string, string>();                    // c

        statesDict.Add( "MD", "Maryland" );                               // d
        statesDict.Add( "TX", "Texas" );
        statesDict.Add( "PA", "Pennsylvania" );
        statesDict.Add( "CA", "California" );
        statesDict.Add( "MI", "Michigan" );

        print("statesDict contains " + statesDict.Count + " elements.");  // e

        foreach (KeyValuePair<string,string> kvp in statesDict) {         // f
            print( kvp.Key + ": " + kvp.Value );
        }

        print( "MI is " + statesDict["MI"] );                             // g

        statesDict["BC"] = "British Columbia";                            // h

        foreach (string k in statesDict.Keys) {                           // i
            print( k + " is " + statesDict[k] );
        }
    }
}
```

**a.** Для использования Dictionary необходимо включить библиотеку
`System.Collections.Generic`. Библиотека `System.Collections`
также включена, поскольку это стандартная настройка Unity, но она не
используется классом DictionaryEx.  

**b.** Словарь объявляется с указанием типов ключа и значения в операторе,
подобном приведенному ниже. В данном словаре и ключ, и значение
являются строками, но вы можете использовать любой тип данных для любого из них.  

**c.** Как и List, Dictionary не готов к использованию, пока не будет
инициализирован с помощью оператора, подобного этому.  

**d.** При добавлении элементов в словарь необходимо передать как ключ, так и
значение для каждого элемента. Эти пять операторов `Add()` добавляют в
словарь почтовые индексы и названия штатов, в которых я жил в течение
своей жизни.  

**e.** Как и в случае с другими коллекциями C#, вы можете использовать
`Count`, чтобы определить, сколько элементов находится в словаре.
Результат:

```
statesDict contains 5 elements.
```

**f.** Вы можете использовать `foreach` со словарями, но тип итерируемого
значения - это `KeyValuePair<TKey,TValue>`. Два типа
`KeyValuePair<TKey,TValue>` должны совпадать с типами словаря
(например, `<string,string>` в данном случае). Вывод:

```
MD: Maryland
TX: Texas
PA: Pennsylvania
CA: California
MI: Michigan
```

**g.** Если вы знаете ключ, вы можете использовать его для доступа к значению в
словаре с помощью скобок. Результат:

```
MI is Michigan
```

**h.** Другой способ добавить значения в словарь - использовать доступ с
помощью скобок, как показано здесь. Я также недолго жил в Британской
Колумбии.

**i.** Список `Dictionary.Keys` также можно проходить с помощью цикла
`foreach`. Хотя порядок здесь совпадает с порядком, в котором я добавлял
элементы словаря, этот порядок никогда не гарантируется. Результат:

```
MD is Maryland
TX is Texas
PA is Pennsylvania
CA is California
MI is Michigan
BC is British Columbia
```

3. Сохраните скрипт `DictionaryEx` в Unity и нажмите "Play". (Если ничего не
происходит, возможно, вам нужно прикрепить скрипт `DictionaryEx` к *Main
Camera*.)  

Вы должны увидеть результат, как описано в предыдущих примечаниях. Помните,
что словари не отображаются в инспекторе Unity, поэтому, даже если `statesDict`
является общедоступной переменной, вы не увидите её в инспекторе.

### Важные свойства и методы словарей [!toc]

Для словарей также доступно множество свойств и методов, но те, что
перечислены в этой панели, используются чаще всего. Все эти
примеры относятся к следующему` Dictionary<int, string> dIS` и
не являются кумулятивными. Другими словами, каждый пример начинается
со словаря `dIS` в том виде, в каком он определен в следующих строках, без
изменений, вносимых другими примерами.

```c#
Dictionary<int,string> dIS;
dIS = new Dictionary<int, string>();
dIS[0] = "Zero";
dIS[1] = "One";
dIS[10] = "Ten";
dIS[1234567890] = "A lot!";
```

Другой способ написания того же объявления и определения словаря:

```c#
dIS = new Dictionary<int, string>() {
    { 0, "Zero" },
    { 1, "One" },
    { 10, "Ten" },
    { 1234567890, "A lot!" }
};
```

Такое совмещенное объявление и определение словаря - один из редких
случаев, когда в конце пары фигурных скобок встречается точка с запятой.  

**Свойства**

- `dIS[10]` (доступ через квадратные скобки) - возвращает элемент
массива словаря по индексу, указанному в параметре (10). Поскольку
"Ten" является элементом с ключом 10, dIS[10] возвращает:
"Ten". Если вы попытаетесь получить доступ к элементу с
несуществующим ключом, вы получите ошибку выполнения
KeyNotFoundException, которая приведет к сбою вашего кода.
- `dIS.Count` - возвращает количество пар "ключ/значение",
находящихся в данный момент в словаре. Поскольку длина словаря
может меняться со временем, Count очень важен. В данном случае
dIS.Count возвращает 4.  

**Методы**

- `dIS.Add(12, "Dozen")` - добавляет значение "Dozen" в словарь
под ключом 12.
- `dIS[13] = "Baker's Dozen"` - добавляет значение "Baker's
Dozen" в словарь под ключом 13. Если вы используете доступ через
квадратные скобки для установки значения уже существующего ключа,
оно будет заменено. Например, dIS[0] = "None" заменит значение
"Zero" под ключом 0 на "None".
- `dIS.Clear()` - удаляет все существующие пары ключ/значение из
dIS, оставляя его пустым.
- `dIS.ContainsKey(1)` - Возвращает true, если ключ 1 находится в
словаре. Это очень быстрый вызов, поскольку словарь разработан для
быстрого поиска элементов по ключу. Ключи в словаре являются
эксклюзивными, поэтому для каждого ключа может быть только одно
значение.
- `dIS.ContainsValue("A lot!")` - Возвращает true, если значение
"A lot!" присутствует в словаре. Это медленный вызов, поскольку
словарь оптимизирован для поиска элементов по ключу, а не по
значению. Значения также не являются эксклюзивными, что означает, что
несколько ключей могут содержать одинаковые значения.
- `dIS.Remove(10)` - удаляет из словаря пару "ключ/значение" с
ключом 10.
</Callout>

Иногда бывает желательно настроить в Инспекторе нечто, эквивалентное словарю. В
этом случае я часто создаю список (List) класса или структуры, который включает
как ключ, так и значение.  

4. Прежде чем переходить к массивам, убедитесь, что воспроизведение Unity
остановлено, а затем снимите флажок рядом с именем компонента *DictionaryEx (Script)* на
панели инспектора, чтобы сделать скрипт DictionaryEx неактивным.
