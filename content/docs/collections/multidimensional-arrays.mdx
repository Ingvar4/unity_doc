---
title: Многомерные массивы
description: Создание многомерных массивов, имеющих два или более индексов, возможно и часто бывает полезно.
---

Это означает, что вместо одного индекса в скобках массив
может использовать два или более. Это может быть полезно для создания
двумерной сетки, в которой в каждой ячейке может находиться один элемент. Для
создания многомерного массива выполните следующие действия:

1. Создайте новый скрипт C# с именем `Aray2dEx` и прикрепите его к *Main Camera*.
2. Откройте файл `Array2dEx` в Visual Studio и введите код

```c#
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class Array2dEx : MonoBehaviour {
    public string[,] sArray2d;

    void Start() {
        sArray2d = new string[4, 4];

        sArray2d[0, 0] = "A";
        sArray2d[0, 3] = "B";
        sArray2d[1, 2] = "C";
        sArray2d[3, 1] = "D";

        print( "The Length of sArray2d is: " + sArray2d.Length );
    }
}
```

3. Сохраните код, вернитесь в Unity и нажмите "Play".

```
The Length of sArray2d is: 16
```

Как видите, 2 по-прежнему является лишь одним целым числом, хотя это и
многомерный массив. Длина здесь теперь представляет собой просто общее
количество элементов в массиве, поэтому программист должен самостоятельно
отслеживать каждое отдельное измерение массива.  

Теперь давайте создадим красиво отформатированный вывод значений из массива
sArray2d. В результате он должен выглядеть примерно так (с 0-й строкой вверху и
0-й колонкой слева):

```
|A|_|_|B|
|_|_|C|_|
|_|_|_|_|
|_|D|_|_|
```

Как видите, A находится в 0-й строке, 0-м столбце ([0,0]), B — в 0-й строке, 3-м столбце
([0,3]) и т. д. Создание такого красивого визуального представления сложных
данных часто называют "красивой печатью".

4. Чтобы создать эту "красивую" распечатку `sArray2d`, добавьте строки в конец метода `Start()`, как показано в листинге
кода:

```c#
    void Start() {
    …

        // Pretty-print sArray2d
        string str = "";
        for ( int i=0; i <4; i++ ) {                // a

            for ( int j=0; j <4; j++ ) {
```

**a.** Строки 20 и 21 демонстрируют использование двух вложенных циклов
`for` (с итераторами `i` и `j` соответственно) для перебора многомерного
массива.  

**b.** В строках 22–26 проверяется, имеет ли строка в `sArray[i,j]` значение,
отличное от `null`. Если да, то к `str` добавляются вертикальная черта и
содержимое` sArray2d[i,j]`. Если значение равно `null`, к `str`
добавляются вертикальная черта `|` и один подчеркивающий символ `_`.  

**c.** Эта строка выполняется после всех итераций цикла `for j`, но перед
следующей итерацией цикла `for i`. Символ `"\n"` — это символ новой
строки, который добавляет разрыв строки в строку. Результатом выполнения
строки 28 является добавление символа вертикальной черты и символа новой
строки в конец `str`, что придаёт выводу удобное форматирование: по одной
строке для каждой итерации `i`.  

Давайте пройдемся по строкам 20–28 вложенных циклов for и посмотрим, как они
работают.

1. Начинается с `i=0 `
2. Проходит по всем значениям `j` от 0 до 3 

    когда `j=0`, тогда `[i,j] = [0,0]` и `str` теперь равен `"|A"`

    когда `j=1`, тогда `[i,j] = [0,1]` и `str` теперь равен `"|A|_"`

    когда `j=2`, тогда `[i,j] = [0,2]` и `str` теперь равен `"|A|_|_"`

    когда `j=3`, то `[i,j] = [0,3]` и `str` теперь равен `"|A|_|_|B"`

    `"|\n"` добавляется в конец строки. `str` теперь равен `"|A|_|_|B|\n"`

3. Увеличение `i=1` 

4. Выполняет итерацию по всем значениям `j` от 0 до 3.

    `j` снова итерируется от 0 до 3, поэтому `[i,j]` варьируется от `[1,0]` до `[1,3]`  

    `str` теперь равен `"|A|_|_|B|\n|_|_|C|_|\n"` 

5. Увеличение `i` до `2`

6. Производится итерация по значениям `j` от `0` до `3`; `[i,j]` принимает значения от `[2,0]` до `[2,3]`

    `str` теперь равен `"|A|_|_|B|\n|_|_|C|_|\n|_|_|_|\n"` 

7. Увеличение `i` до `3`

8. Происходит итерация по значениям `j` от `0` до `3`; `[i,j]` варьируется от `[3,0]` до `[3,3]`

    `str` теперь равен `"|A|_|_|B|\n|_|_|C|_|\n|_|_|_|\n|_|D|_|_|\n "`  

Эта вложенная структура цикла for перемещает код по многомерному массиву
упорядоченным образом. Если остаться при примере с сеткой, она проходит по всем
элементам в строке (увеличивая j от 0 до 3), а затем переходит к следующей
строке, увеличивая i до следующего значения.
