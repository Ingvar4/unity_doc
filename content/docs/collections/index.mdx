## Коллекции в C#

Коллекция - это группа объектов, на которые ссылается одна переменная. В
обычной жизни коллекциями могут быть такие вещи, как группа людей, прайд
львов, парламент грачей или стая ворон. Так же, как и эти термины, обозначающие
группы животных, коллекции, которые мы будем использовать в C#, могут
содержать только один тип данных класса (например, вы не сможете
включить тигра в прайд львов). Тип массива встроен в C# на низком уровне, тогда
как другие типы коллекций, описанные здесь, для работы полагаются на
библиотеку кода System.Collections.Generic, как описано далее в этой главе. См. «Что такое общая коллекция?».

<Callout>
### Что такое обобщенная коллекция? [!toc]

Помимо массива, все остальные типы коллекций, которые вы увидите в
этой главе, являются частью библиотеки кода System.Collections.Generic.
Генерическая коллекция в C# - это коллекция, предназначенная для
работы с любыми типами данных, определяемыми программистом. В
случае с генерическим типом тип, с которым он будет работать, указывается
в угловых скобках `<>`. Например:

- `List<string> stringList;` - объявляет список строк
- `List<GameObject> goList;` - объявляет список объектов GameObject  

В документации по C# и в этой главе вы увидите, что типизированные
коллекции описываются с использованием `<T>` в качестве типа. В данном
случае *T* является заменителем любого типа, который вы решите
использовать в любом написанном вами коде.  

Обобщения C# также используются в нескольких других местах, одним из
наиболее распространенных примеров в Unity является запрос компонента,
прикрепленного к GameObject. Метод `GetComponent()` описывается в
документации как gameObject. `GetComponent<T>()`. Так же, как и в
случае с коллекциями, `<T>` здесь является заменителем любого типа
компонента, который вы хотите запросить. Например, `gameObject.
GetComponent<Rigidbody>()` запрашивает компонент Rigidbody,
прикрепленный к gameObject.
</Callout>

### Часто используемые коллекции

Ниже приводится краткий обзор некоторых наиболее часто используемых
коллекций. Типы array, List и Dictionary будут рассмотрены гораздо подробнее
далее в этой главе и будут использоваться на протяжении всей книги. Я включаю Q
ueue и Stack, чтобы вы знали о них, но они не используются в других местах этой
книги.

- **array:** Массив — это индексированный упорядоченный список объектов. Длина
массива должна быть задана при его определении и не может быть изменена,
что отличает его от более гибкого типа List. Слово «array» будет писаться с
заглавной буквы только при упоминании класса C# Array, который
представляет собой набор инструментов для работы с примитивными
массивами данных, описанными в этой главе. Как самый примитивный тип
коллекции, массивы имеют мало специальных функций класса. Однако
массивы поддерживают числовой доступ через скобки, что означает, что
объекты можно сохранять в массиве и считывать из него, используя имя
массива и `[]`, например:

    - `string[] stringArray = new string[2];` - Объявляет и инициализирует массив, который может содержать две строки.
    - `stringArray[0] = "Hello";` - Присваивает "Hello" нулевому элементу массива stringArray.
    - `stringArray[1] = "World";` — Присваивает "World" первому элементу stringArray
    - `print( stringArray[0]+" "+stringArray[1] );` — Вывод: "Hello World"
---
- `List<T>`: Списки похожи на массивы, за исключением того, что они имеют
гибкую длину и работают немного медленнее. В этой книге слово List будет
писаться с заглавной буквы при упоминании типа C#, чтобы отличать его от
обычного использования слова «список». List — это наиболее часто
используемая коллекция в этой книге, и списки могут использовать числовой
доступ через скобки, как массивы. Списки также включают следующие
методы:

    - `List<T> myList = new List<T>()` — Объявляет новый список типа T
    - `myList[0]` — возвращает 0-й элемент myList
    - `myList.Add(foo)` — добавляет объект `foo` в конец списка `myList;` чтобы это сработало, foo должен быть типа `T`
    - `myList.Clear()` — удаляет все объекты из списка myList
    - `myList.Contains(foo)` — Возвращает значение `true`, если объект `foo` находится в списке `myList`
    >Здесь стоит отметить, что .Contains() использует сравнение на равенство, поэтому числа с
плавающей запятой не всегда могут давать точные результаты при использовании
.Contains() в любой коллекции из-за неточностей арифметики с плавающей запятой.
    - `myList.Count` — свойство, возвращающее количество объектов в списке myList.
    > Свойство — это функция, которая используется как переменная, поэтому Count —
единственное из перечисленных здесь, за которым не следуют скобки
    - `myList.IndexOf(foo)` — возвращает числовой индекс места, где объект foo находится в myList; если объект foo отсутствует в myList, возвращается 21
    > Подобно `.Contains()`, `.IndexOf()` и `.Remove()` используют сравнение на равенство, поэтому
числа с плавающей запятой не всегда могут давать точные результаты из-за неточностей арифметики
с плавающей запятой.
    - `myList.Remove(foo)` — удаляет объект foo из myList
    - `myList.RemoveAt(0)` — удаляет объект, находящийся по индексу 0, из myList

### Списки и массивы имеют нулевую индексацию [!toc]
Типы коллекций списков и массивов имеют нулевую индексацию, что означает: то,
что вы считаете «первым» элементом, на самом деле является элементом
`[0]`.  

В этих примерах мы рассмотрим псевдокод коллекции `coll`. Псевдокод —
это код, не относящийся к какому-либо конкретному языку
программирования, но используемый для более наглядной иллюстрации
концептуального момента.

```
coll = [ "A", "B", "C", "D", "E" ]
```

Количество элементов в массиве `coll` равно 5, а допустимые индексы
для элементов — от `0` до `coll.Count-1` (то есть 0, 1, 2, 3 и 4).

```
print( coll.Count );    // 5
print( coll[0] );       // A
print( coll[1] );       // B
print( coll[2] );       // C
print( coll[3] );       // D
print( coll[4] );       // E
print( coll[5] );       // Index Out of Range Exception!!!
```

Если вы попытаетесь использовать доступ через скобки для доступа к индексу,
который находится вне диапазона, появятся следующие ошибки выполнения:  

Для массивов:

```
IndexOutOfRangeException: Index was outside the bounds of the array.
```
Для списков:

```
ArgumentOutOfRangeException: Index was out of range. Must be nonnegative and less than the size of the collection.
```

Важно помнить об этом при работе с любыми коллекциями в C#.
</Callout>

- `Dictionary<TKey,TValue>`: Словари хранят связанные пары
«ключ/значение», где объект-значение хранится на основе определенного
ключа. Реальным примером этого является библиотека, где ключ по системе
Деви позволяет читателям получить доступ к значению — самой книге. В
отличие от всех других коллекций в этой главе, словари объявляются с двумя
типами (тип ключа и тип значения). Значения можно добавлять в словарь и
считывать из него с помощью доступа в скобках вокруг ключа (например, `dict[key]`). Словарь
может иметь только одно значение, связанное с каждым ключом. Словари
включают следующие методы:

    - `Dictionary<TKey,TValue> myDict = new Dictionary<TKey, TValue>()` — объявляет и инициализирует новый словарь с типами ключа и значения (Tkey — тип ключа, а Tvalue — тип значения)
    - `myDict.Add(key, value)` — добавляет объект value в myDict с ключом key
    - `myDict.Clear()` — удаляет все пары «ключ/значение» из myDict
    - `myDict.ContainsKey(key)` — Возвращает true, если ключ key присутствует в myDict
    - `myDict.ContainsValue(value)` — Возвращает true, если значение value находится в myDict
    - `myDict.Count` — Свойство, возвращающее количество пар «ключ/значение» в myDict
    - `myDict.Remove(key)` — удаляет значение, связанное с ключом key, из myDict
---
- `Queue<T>` — Как коллекция, упорядоченная по принципу «первым пришел — первым вышел» (FIFO), очередь
похожа на ту, в которой вы могли бы стоять в парке аттракционов: первый человек в очереди получает право прокатиться первым. Объекты добавляются в конец очереди с помощью `Enqueue()` и удаляются из начала очереди с помощью `Dequeue()`. Очереди включают следующие методы:

    - `Queue<T> myQ = new Queue<T>()` — объявляет и инициализирует новую очередь типа T
    - `myQ.Clear()` — удаляет все объекты из myQ
    - `myQ.Contains(X)` — Возвращает true, если X находится где-либо в myQ
    - `myQ.Count` — свойство, возвращающее количество объектов в myQ
    - `myQ.Dequeue()` — удаляет и возвращает объект, находящийся в начале myQ
    - `myQ.Enqueue(X)` — Добавляет объект X в конец myQ
    - `myQ.Peek()`— возвращает объект, находящийся в начале myQ, не удаляя его
---
- `Stack<T>` — Как коллекция, упорядоченная по принципу «первым вошел — последним вышел» (FILO), стек
похож на колоду карт: первая карта, помещенная в стопку, — последняя вытянутая.
Объекты добавляются на вершину стека с помощью метода `Push()` и удаляются с вершины стека с помощью метода `Pop()`. Стеки включают следующие методы:

    - `Stack<T> myStack = new Stack<T>()` — объявляет и инициализирует новый стек типа T
    - `myStack.Clear()` — удаляет все объекты из myStack
    - `myStack.Contains(X)` — возвращает true, если X где-то находится в myStack
    - `myStack.Count` — свойство, возвращающее количество объектов в myStack
    - `myStack.Peek()` — Возвращает объект, находящийся на вершине myStack, не удаляя его
    - `myStack.Pop()`— удаляет и возвращает объект, находящийся на вершине myStack
    - `myStack.Push(X)` — добавляет объект X в начало myStack

Поскольку списки являются наиболее часто используемым типом коллекций в этой
книге, мы начнём наше подробное изучение с них, а затем рассмотрим словари и
массивы.
